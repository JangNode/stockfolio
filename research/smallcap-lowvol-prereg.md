승인 범위: 사전등록 커밋 → 백테스트 1회. 재실행 금지. 결과를 본 뒤 정의·기준·변형·선택 규칙 변경 금지. 다음 라운드 자동 시작 금지. B(공매도·신용잔고) 수집은 하지 않는다.
브랜치 claude/ma-v3-portfolio-cap-run (병합 금지). 외부 요청 0건, DB 쓰기 0, psql 금지. 주가 Parquet은 기존 디스크 캐시 엄격 게이트(17개 연도 파일)를 따름.
시도 번호: M1 = 126, M2 = 127, M3 = 128, 홀드아웃 실행 시 +1.

## 사용자 문안 (원문)

[리밸런싱] 분기: 3·6·9·12월 마지막 거래일 신호, 다음 거래일 종가 체결. 지연 변형은 그다음 거래일 종가. 동일가중, 비중 변화분만 거래. 보유 중 폐지는 기존 규칙대로 청산하고 현금은 다음 리밸런싱까지 보유.
[비용] 편도 수수료 0.015% + 슬리피지 0.2% + 매도 시 연도별 증권거래세.
[변형]

[기간] 학습 2010-04-01~2016-12-31(첫 신호 2010-03 말), 확인 2017-01-01~2021-12-31, 홀드아웃 2022-01-01~끝.

[추가 검증, 홀드아웃까지 전부 O일 때만, 전 기간 2010-04~끝]

 R2 상위 사건 제거: SEW 대비 초과 수익이 가장 큰 1개 분기를 SEW 수익으로 바꿔도 CAGR ≥ SEW + 2.0%p.

## 구현 세부 (결과를 보기 전에 고정하는 해석 — 사용자 문안에 없는 부분)
1. **엔진·비용**: research/foreign-flow-tilt-prereg.md 구현 세부 1(엔진)·2(달력·신호일·체결일)·3(평가 구간)·7(지표)과 같은 엔진(scripts/research-foreign-flow-tilt.ts): 수정주가(적용된 분할·병합 조정), 일별 종가 재평가, 폐지 강제 청산(마지막 행이 데이터 끝−14일 이전이고 해당일 이전이면 마지막 종가로 청산하고 매도 비용을 낸 뒤 현금 보유, 다음 리밸런싱에서 다시 투자), 현금 이자 0, 체결일에 행이 없는 종목은 목표에서 빼고 남는 비중은 현금(재정규화 없음), 비중 변화분만 거래(비용 = 매수금액×매수율 + 매도금액×매도율, 체결일 가치에서 일괄 차감 후 비중을 (V−C)/V배). 데이터는 2010년부터 데이터 끝까지 로드한다. 비용률: 매수 = (1 + 0.002)(1 + 0.00015) − 1, 매도 = 1 − (1 − 0.002)(1 − 0.00015 − 거래세율(체결일)) (슬리피지 0.2%·수수료 0.015%·연도별 거래세, 거래세율은 lib/transactionCost.ts getSecuritiesTaxRate).
2. **유니버스 SMALL(d)**: research/signal-scan-smallmid-prereg.md 구현 세부 2와 같다 — d에 행이 있고, 직전 행 시총 ≥ 1,000억 그리고 < 5,000억, d 당일 행 직전 20거래일 평균 거래대금 ≥ 2억 원, d 당일 행 원본(조정 전) 종가 ≥ 1,000원, 직전 행이 있어야 함. SEW = SMALL(d) 전 종목 동일가중.
3. **VOL**: 달력 CAL = 2010-01-01 이후 전 종목 거래일 합집합. d의 CAL 인덱스 c, 창 길이 N(기본 60)에서 창 = CAL[c−N+1..c]. c−N+1 < 0이면 결측. 주가 있는 날 = 그 종목 행이 있고 수정주가 종가 > 0. 주가 있는 날 수 < ceil(N×2/3)(N=60 → 40; R1의 40 → 27, 90 → 60)이면 제외. 일수익률 = 창 안에서 연속한 두 CAL 거래일 모두 주가가 있는 날의 수정주가 종가 비율 − 1이며 표본표준편차(n−1)를 VOL로 쓴다(수익률이 2개 미만이면 제외). VOL이 작을수록 좋다.
4. **SOP**: research/signal-scan-prereg.md 구현 세부 4의 분기 정의 — dart_quarterly_fundamentals status='ok', off_cycle=false, rcept_date 있음, rcept_date ≥ 분기 말(1분기 FY-03-31, 반기 06-30, 3분기 09-30), 1~3분기 행만(4분기 파생 없음). d에서 rcept_date ≤ d이고 d − rcept_date ≤ 150일인 가장 최근 분기 행(접수일 같으면 (FY, 분기) 큰 쪽). SOP = (op_income_q − op_income_prev_q) ÷ |op_income_prev_q| (둘 다 non-null이고 prev ≠ 0일 때만, 아니면 SOP 없음). SOP는 클수록 좋다.
5. **신호일·체결일**: 신호일 d = 3·6·9·12월의 월 마지막 거래일(다음 CAL 거래일의 연월이 다른 날, 마지막 달이 끝나지 않았으면 제외) 중 2010-03-31 이상. 체결일 e = d 다음 CAL 거래일(지연 변형은 그다음 CAL 거래일). R1의 월간 변형은 모든 월말을 신호일로 한다. 첫 체결일(2010-04-01)에 초기 진입하며 그날 일 수익률은 어느 창에도 넣지 않는다.
6. **변형별 선정**(SMALL(d) 중 VOL이 있는 종목 n개를 VOL 오름차순, 동점 코드 오름차순으로 정렬해 i번째(0-기준)로 부른다): M1 = floor(i×3/n) = 0인 종목(= 앞쪽 ceil(n/3)개). M2 = 앞쪽 min(50, n)개. M3 = floor(i×2/n) = 0인 종목(앞쪽 ceil(n/2)개) 중 SOP가 있는 종목 m개를 SOP 내림차순(동점 코드 오름차순)으로 정렬해 j번째 중 floor(j×2/m) = 0인 종목(앞쪽 ceil(m/2)개)이며, 그 개수가 30 미만이면 그 분기는 M1의 선정으로 대체하고 대체 횟수를 보고한다(대체 횟수 = 그 변형이 계산한 신호일 중 대체된 신호일 수 / 전체 신호일 수, 창별로 보고). 선정 종목은 동일가중(1/개수).
7. **지표**: CAGR = `computeCagrPct`, MDD = `computeCumulativeAndMdd`, 연변동성 = 일 수익률 % 표본표준편차×√252, 샤프 = 일 수익률 % 평균×252 ÷ (표본표준편차×√252)(무위험 0). 분기 평균 회전율 % = 창 안 체결일별 (매수금액+매도금액)/2/체결 직전 가치의 합 ÷ (창 연수×4) ×100. 누적 비용 % = 창 안 일별 (비용/직전 가치)의 합 ×100. 평균 보유 종목 수 = 창 안 매 거래일 종가 후 보유 종목 수의 평균. 보유 종목 20일 평균 거래대금 중앙값 = 창 안에 체결일이 있는 모든 신호일의 선정 종목에 대해 신호일 당일 행의 직전 20거래일 평균 거래대금(원)을 모은 값의 중앙값(억원 표기). 폐지 청산 건수 = 창 안 강제 청산 건수. 지연 CAGR = 같은 변형의 지연 경로의 같은 창 CAGR, G4의 하락 = 기본 − 지연.
8. **비교 기준**: SEW는 같은 신호일·체결일·비용·엔진(전체 SMALL 동일가중, 분기 리밸), B&H = etf_daily_prices.adj_close 069500을 첫 체결일 종가에 매수해 보유(비용 없음, 하루짜리 튐 정제는 research/etf-allocation-prereg.md e0219298 규칙), 참고로 KOSDAQ·KOSPI = DB 지수 종가 일 수익률(beta_price_history). 모든 비교는 같은 창에서 계산한다.
9. **단계**: 학습 창에서 M1~M3와 SEW를 같은 경로 규칙으로 학습 끝(2016-12-31)까지 계산한다. 선택은 학습 값만 쓴다((CAGR − SEW CAGR) 최대, 동률이면 분기 평균 회전율이 낮은 쪽). 선택이 있으면 선택 변형·SEW·지연 변형을 데이터 끝까지 계산해 확인·홀드아웃 창으로 자른다. 선택되지 않은 변형은 2016-12-31 이후 경로를 계산하지 않는다.
10. **추가 검증**(홀드아웃까지 G1~G4 전부 O일 때만, 선택 변형만, 전 기간 = 2010-04-01~데이터 끝): R1 = (a) VOL 창 40일 (b) 90일 (c) 분기 대신 매월 리밸런싱(나머지 동일, VOL 창 60일)의 기본 경로 전 기간 CAGR이 셋 다 ≥ SEW(분기 리밸 SEW) 전 기간 CAGR + 2.0%p이면 O. R2 = 달력 분기(YYYY-Q)별 수익률(그 분기 일 수익률 복리)의 전략 − SEW(%p)가 가장 큰 1개 분기의 일 수익률 전부를 같은 날 SEW 일 수익률로 바꾼 계열의 전 기간 CAGR ≥ SEW 전 기간 CAGR + 2.0%p이면 O. R3 = 각 신호일마다 실제 전략의 선정 종목 수와 같은 수를 SMALL(d) 전체(VOL·SOP 유무와 무관)에서 비복원 무작위로 뽑아(Fisher–Yates 부분 셔플, mulberry32, 시드 20261020, 1,000회, 신호일 순서대로 같은 난수열) 동일가중으로 같은 엔진·비용의 전 기간 경로를 계산하고, 전략 전 기간 CAGR 이상인 무작위 경로 수 ÷ 1,000 ≤ 5%이면 O. 최종 통과 = 홀드아웃까지 G1~G4 전부 O + R1~R3 전부 O.
11. 상수는 lib/smallcapLowvolConfig.ts(및 lib/signalScanConfig.ts, lib/foreignFlowTiltConfig.ts, lib/etfAllocationConfig.ts, lib/seasonalityConfig.ts)에 둔다.
