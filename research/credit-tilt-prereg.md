## 구현 세부 (2017년 이후 신용잔고 값과 결과를 보기 전에 고정하는 해석 — 사용자 문안에 없는 부분)
1. **엔진**: research/midcap-lowvol-sop-prereg.md(5238523) 구현 세부 2의 엔진(수정주가 일별 재평가, 폐지 강제 청산 후 현금, 체결일에 행 없는 종목은 목표에서 빼고 남는 비중은 현금(재정규화 없음), 비중 변화분만 거래·비용 일괄 차감, 첫 체결일 일 수익률 제외)과 지표(CAGR, MDD, 샤프, 연변동성, 분기 평균 회전율, 누적 비용, 평균 보유 종목 수, 지연 CAGR)를 그대로 쓴다. 비용률은 매수 = `computeEffectiveBuyPrice(1) − 1`, 매도 = `1 − computeEffectiveSellPrice(1, 체결일, "KR")`. 신호일 = 3·6·9·12월 마지막 거래일(2010-03-31 이상), 체결일 = 다음 거래일, 지연 = 그다음 거래일.
2. **유니버스**: PIT 적격(직전 행 시총 ≥ 5,000억 + 당일 20일 평균 거래대금 ≥ 5억, 수정주가 기준) 중 신호일 당일 행 시총 내림차순(동점 코드 오름차순) 상위 100 = POOL, 나머지 = MID(스캔 3회차와 같음).
3. **C1**: 신용잔고 정리본(research/credit_balance_clean, 2009~2016 파일 + 수집 완료 후 추가되는 2017~2026 파일, deal_date 기준) whol_loan_rmnd_rate. 신호일 CAL 인덱스 c에서 j = c−2, 그 종목의 deal_date = CAL[j] 행이 있으면 그 값, 없으면 직전 행을 j−5 이상일 때만 이어 쓰고 아니면 결측.
4. **3등분**: 유니버스 구성원 중 C1이 있는 종목 n개를 C1 내림차순(동점 코드 오름차순)으로 정렬해 floor(i×3/n) = 0 → 상위(신용 많음), 1 → 중간, 2 → 하위(신용 적음). C1이 없는 종목은 중간 그룹. n = 0이면 모두 중간.
5. **변형 가중**: 시총 = 신호일 당일 행 시총. CR1 = 시총 × 배수(하위 1.5, 중간 1.0, 상위 0.5)를 합 1로 정규화. CR2 = 상위 그룹을 뺀 나머지(중간·하위)를 시총가중. CR3 = MID에서 상위 그룹을 뺀 나머지를 동일가중. POOL = 상위 100 시총가중, MEW = MID 전부 동일가중(모두 같은 신호일·체결일·비용·엔진).
6. **선택**: 학습 G1~G4 전부 O인 변형 중 (CAGR − 자기 비교 기준 CAGR) 최대 1개, 동률이면 분기 평균 회전율이 낮은 쪽, 그래도 같으면 CR1 < CR2 < CR3. 선택된 변형·그 비교 기준·지연 변형만 데이터 끝까지 계산해 확인·홀드아웃 창으로 자른다. 비교 기준(POOL·MEW)과 B&H·KOSPI·KOSDAQ는 학습 표에 모두 싣는다.
7. **추가 검증**(선택 변형만, 전 기간 2010-04-01~데이터 끝, G1 기준 = 그 변형의 G1 여유폭과 비교 기준의 전 기간 CAGR): R1 (a) C1 대신 C3 = whol_loan_rmnd_amt(j) ÷ 신호일 당일 행 시총(같은 이어쓰기 규칙), (b) 매월 마지막 거래일 리밸런싱(비교 기준은 분기 리밸 그대로), (c) 4등분: C1 내림차순 floor(i×4/n) = 0 → 상위 1/4, 3 → 하위 1/4, 1·2 → 중간(CR1 배수: 하위 1.5, 중간 1.0, 상위 0.5; CR2·CR3는 상위 1/4 제외). 각각 전 기간 CAGR ≥ 비교 기준 전 기간 CAGR + G1 여유폭이면 O. R2 = 달력 분기별 (전략 − 비교 기준) 수익 차가 가장 큰 1개 분기의 일 수익률을 비교 기준 일 수익률로 바꾼 전 기간 CAGR ≥ 비교 기준 + 여유폭. R3 = 매 신호일 유니버스 구성원(C1 유무 무관)에 실제와 같은 크기의 상위·중간·하위 그룹을 무작위 배정(Fisher–Yates, mulberry32, 시드 20261021, 1,000회, 신호일 순서대로 같은 난수열)한 뒤 같은 가중 규칙으로 계산, 전략 전 기간 CAGR 이상인 무작위 경로 수 ÷ 1,000 ≤ 5%이면 O.
8. **B&H·지수**: 069500 adj_close(정제 규칙 e0219298), KOSPI·KOSDAQ = DB 지수 종가. 모든 비교는 같은 창.
9. 상수는 lib/creditTiltConfig.ts(및 기존 설정 파일)에 둔다.
