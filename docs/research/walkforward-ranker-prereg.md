# 연구 WFR — 워크포워드 랭킹 모델 (M1 = 시도 248, M2 = 249, M3 = 250) 사전등록

작성 2026-10-28(사용자 지정). **이 문서는 시험 실행 전 사전등록이며 실행 전에 커밋한다(커밋 해시는 보고에 기록).** 국내 주식과 현금만 쓴다(ETF 매매 금지, 069500은 신호·기준선으로만 쓴다). 모든 구간 성적은 개발 데이터 내 성적이다. 연구 브랜치 claude/ma-v3-portfolio-cap-run에서만 작업하고 main에는 병합하지 않는다. 통과해도 운영 적용·PR은 하지 않는다. 누적 시도: 247에서 이어서 **250**, 우연 통과 기대 건수 **250 × 0.05 = 12.5**.

## 1. 목적

수작업으로 정한 단일 규칙(이동평균, 거래대금·갭 이벤트, 모멘텀, 공시 등) 247건이 기준(069500 + 낙폭 개선 등)을 모두 넘지 못했다. 규칙 하나하나를 사람이 고르는 방식에서, **데이터가 여러 신호를 조합하는 방식**(매년 과거 자료만으로 다시 학습하는 LightGBM 랭킹 모델)으로 옮긴다. 학습·예측을 연 1회 확장 윈도우로 고정하고 하이퍼파라미터 튜닝·특성 선택·조기 종료는 하지 않는다.

## 2. 중복 확인 결과 (읽기 전용, 저장소 scripts/·lib/·docs/research/·research/ 검색)

머신러닝(LightGBM, 그래디언트 부스팅, 랜덤 포레스트 등) 랭킹 모델을 시험한 기록은 **없다**. 동일한 시험이 없어 세 후보 모두 새로 시험하고 계수한다. 부분적으로 겹치는 것은 아래와 같다.

| 기존 | 정의 | 이번 시험과의 차이 |
|---|---|---|
| 연구 W (w-walkforward-prereg.md, 166~167) | 해마다 과거 데이터로 규칙의 설정(이동평균·손절 등 격자)을 다시 고르는 워크포워드 | 선택 대상이 규칙 파라미터 격자이고 모델이 없다. 이번에는 매일 종목 순위를 학습 모델이 낸다 |
| 신호 스캔 1·2·3회차 (research/signal-scan-*.md) | 단일 신호와 미래 수익률의 순위상관(IC) 스캔, 학습 구간(~2016)만 | 신호를 하나씩 보는 진단이며 신호를 결합하지 않고 거래 규칙도 없다 |
| 연구 guru 복합 점수 (guru-composite-prereg.md), factor-strategies | 사람이 정한 가중으로 여러 지표를 합친 복합 점수 | 가중이 손으로 정해졌다. 이번에는 가중(비선형 포함)을 데이터로 학습 |
| 연구 LE·LM (momentum-ensemble-prereg.md 등) | 수익률 3구간 백분위 평균 순위 앙상블 | 고정된 3개 입력의 평균 순위. 이번에는 23~25개 특성의 학습 모델 |
| 연구 N (n-book-canon-prereg.md) | 서적 기반 규칙 + 수급 필터 | 규칙 기반이며 학습 모델 없음 |

## 3. 데이터 누수 방지 조치

1. **특성은 모두 종가 d까지의 정보만** 쓴다(그 종목 행 기준, 수정주가). 라벨만 d+1 이후 가격을 쓴다. 횡단면 순위 정규화는 같은 날 종목들끼리만 계산한다(미래 날짜의 분포를 쓰지 않음).
2. **라벨**: d 종가 신호 → d+1 종가 매수 → d+1+H 종가 매도 수익률(비용 제외)을 같은 날 유니버스 안에서 횡단면 순위(0~1)로 변환.
3. **퍼지(purge)**: 연 1회(매년 첫 거래일) 재학습하며, 예측 연도 첫 거래일 순번을 F라 할 때 학습 행은 판단일 d ≤ F − H − 2인 것만 쓴다(= 예측 연도 직전 H+1거래일을 학습에서 제외; 학습 라벨의 매도일 d+1+H ≤ F − 1이라 예측 연도 첫날 종가 판단 시점에 모두 완성돼 있다). H = 20(M1·M2)이면 2014 예측 모델의 학습 마지막 판단일은 2013-11-28, H = 5(M3)면 2013-12-19이다. 연도별 경계는 사전 점검 로그(run 40615998334)에 있다.
4. **확장 윈도우**: 학습 구간은 항상 2011-01-04부터 퍼지 경계까지. 첫 예측 연도는 2014(학습 2011~2013), 마지막은 2026(2026-10-26까지 부분 연도).
5. 모델·특성·규칙은 결과를 본 뒤 바꾸지 않는다. 연도별 모델은 해당 연도 이후의 자료를 전혀 보지 않는다.

## 4. 사용자 지정 규칙 (그대로 옮김)

- **데이터·평가 구간**: 코스피 보통주 K200P PIT(기존 정의: 우선주·스팩·리츠 제외, 월말 구성 + 당일 시총, 20일 평균 거래대금 5억 이상). 모델 학습은 2011-01-04부터. 평가(수익 집계)는 2014-01-02부터. 구간: 학습 2014~2016 / 확인 2017~2021 / 보류 2022~. 기준선 069500(보조 파일 포함)은 2014-01-02 시작으로 새로 계산.
- **특성**(고정): 수익률 1·5·10·20·60·120·250일, 12-1개월(마지막 20일 제외), 변동성 20·60일, 최대낙폭 60일, 거래대금(종가×거래량) 20일 평균 대비 당일 비율, 거래대금 규모(로그), 시총(로그), 종가의 20·60·200일 이동평균 대비 비율, 52주 고가 대비 비율, 일중 종가 위치((종가−저가)/(고가−저가)) 5일 평균, 갭(시가/전일 종가 −1) 5일 평균, 069500 대비 상대수익률 20·60일, 업종 대비 20일 상대수익률. M2·M3는 추가로 외국인·기관 순매수 금액을 거래대금으로 나눈 비율의 5·20일 합. 수급이 없는 종목-일은 결측 그대로(대체 금지, 결측률 보고). 매일 횡단면 순위 정규화.
- **라벨**: 3절 2. M1·M2는 H = 20, M3는 H = 5(M2 특성).
- **모델**(조정 금지): LightGBM 회귀, objective L2, num_leaves 15, learning_rate 0.05, n_estimators 300, min_data_in_leaf 200, feature_fraction 0.8, bagging_fraction 0.8, bagging_freq 1, lambda_l2 10, seed 1, 나머지 기본값. 연 1회 확장 윈도우 재학습, 다음 해 전체 예측.
- **매매**(조정 금지): 매일 종가에서 점수 순위 확정, 체결은 다음 거래일 종가. 상위 10위 안 종목을 동일가중(종목당 10%) 보유. 보유 종목은 순위가 30위 밖으로 밀려야 매도(상위 10위 밖~30위 안은 유지하고 빈 슬롯은 현금 대신 순위 높은 신규 종목으로 채움). 비용 0.015%/편도 + 매도세, 슬리피지 0.1%. 상장폐지 강제 청산. 국내 주식 + 현금, 항상 투자(시장 필터 없음).
- **게이트** A~H 기존 정의(G 100건 완화 금지, B 세 구간 중 2개 이상). 게이트 D 이웃: 보유 종목 수 7/15, 청산 순위 20/40, 모델 시드 2/3(가능한 항목만 CAGR ≥ 069500이면 통과). 게이트 F: 같은 날 유니버스에서 무작위 10종목을 뽑아 같은 청산 규칙으로 운용한 1,000회 분포 대비 백분위. 게이트 H 기준선: 069500과 L3(참고).

## 5. 구현 정의 (사용자 정의를 바꾸지 않는 해석, 실행 전 고정)

기준값은 `lib/walkforwardRankerConfig.ts`(특성 목록·창·모델 파라미터·이웃·시드), 코드는 `scripts/wfr-export.ts`(특성·라벨) → `scripts/wfr_train.py`(학습·예측) → `scripts/research-walkforward-ranker.ts`(시뮬레이션·게이트)에 있다.

1. **수급 특성은 외국인만 쓴다 — 사용자 지정(외국인·기관)에서 벗어난 점.** 수급 캐시(`research-flow-subset-20261028`)에는 외국인 순매수 금액(`frgn_ntby_amt`) 열만 있고 기관(`orgn_ntby_amt`)은 없다. 사용자가 이번 작업에서 Supabase Storage 읽기를 월말 목록 정도로 제한했으므로 정리본을 다시 읽을 수 없어, M2·M3의 수급 특성은 **외국인 (순매수 금액 ÷ 거래대금) 5일 합(frgn5)·20일 합(frgn20) 2개**뿐이다(사용자 지정 4개 중 기관 2개 제외). 따라서 M2·M3는 "외국인 수급" 모델이며 기관 수급의 기여는 시험하지 못한다. 일별 비율 = 그 종목-일 순매수 금액 ÷ (원 종가 × 거래량), 창 안에서 값이 있는 날 수가 창 길이의 2/3(올림: 5일 → 4, 20일 → 14) 미만이면 결측(연구 foreign-flow-tilt·신호 스캔의 2/3 규칙), 그렇지 않으면 있는 날의 합. 금액 단위는 횡단면 순위 정규화로 사라지므로 단위 확인이 필요 없다. 수급 캐시의 종목 수는 552개라 그 밖의 종목-일은 결측이다. 결측률은 사전 점검 로그(2011~2013 약 11.5%, 2014 약 8%, 2015 이후 0.1% 안팎, 2026 약 3%)와 실행 로그에 있다.
2. **계산 단위**: 모든 이동평균·수익률·변동성은 종목 자신의 수정 종가 **행** 기준이다(거래정지일은 행이 없음). 시장 대비 상대수익률의 069500 수익률은 달력(거래일) 기준 20·60일 가격 수익이다. 상대수익률은 같은 날 모든 종목에서 같은 값을 빼므로 횡단면 순위로는 20·60일 수익률(ret20·ret60)과 같다(고정된 사양대로 둔다).
3. 정의 세부: ret(k) = 종가[i] ÷ 종가[i−k] − 1. 12-1 = 종가[i−20] ÷ 종가[i−250] − 1. 변동성 N = 직전 N개 일수익률(행 기준)의 표본표준편차. 최대낙폭 60 = 직전 60행 종가의 고점 대비 최대 하락률. 거래대금 비율 = 당일 ÷ 직전 20행 평균(당일 제외); 거래대금 규모 = ln(직전 20행 평균). 시총(로그) = ln(당일 행 시총). 이동평균 비율 = 종가 ÷ N행 단순평균 − 1. 52주 고가 비율 = 종가 ÷ 직전 252행(있는 만큼, 200행 미만이면 결측) 최고 종가. 종가 위치 5일 = 5행의 (종가−저가)÷(고가−저가) 평균(고가 = 저가인 행이 있으면 결측). 갭 5일 = 5행의 (시가 ÷ 전일 종가 − 1) 평균. 업종 대비 20일 = ret20 − 같은 KSIC 2자리 업종 K200P 소속 종목 ret20의 중앙값(업종 종목이 3개 미만이거나 업종 미분류면 결측).
4. **횡단면 순위 정규화**: 그날 K200P 소속 종목 중 값이 있는 것만 평균 순위(동률은 평균)를 (순위 − 1) ÷ (개수 − 1)로 [0,1]에 변환(1개뿐이면 0.5). 결측은 NaN으로 두고 LightGBM이 처리한다.
5. **라벨 결측과 상장폐지**: d+1 또는 d+1+H에 그 종목 행이 없으면 라벨 결측(학습에서 제외). 단 d+1+H에 행이 없고 종목이 상장폐지로 끝났으면(마지막 행 < d+1+H이고 데이터 끝 일정 기간 이전) 마지막 종가를 매도가로 쓴다(엔진의 강제 청산과 같음).
6. **학습 입력**: M1은 가격 특성 23개, M2·M3는 가격 23개 + 외국인 수급 2개. 행 = (판단일, K200P 소속 종목), 2011-01-04 이후. 연도별 모델은 해당 연도 이후 자료를 보지 않으며, 같은 변형의 연도별 점수를 이어 붙여 하나의 점수열로 쓴다.
7. **매매 엔진**: 기존 일별 슬롯 시뮬레이터(연구 L~PEAD와 같음). 판단일 c에 보유 종목 점수 순위 > 30이거나 그날 점수가 없으면(K200P 소속 이탈) 매도 신호(사유 "순위 밖" / "유니버스 이탈"), 체결은 c+1 종가. 진입 후보는 점수 순위가 높은 순으로 보유하지 않은 종목, 슬롯 수만큼. **엔진 관습**: 매도 신호가 난 종목은 체결일까지 슬롯을 차지하고, 비는 슬롯은 체결 뒤 다음 판단일에 채워진다(이 규칙은 기존 연구 전부와 같고 비용·현금 비중에 반영됨). 평가 첫 판단일은 2014-01-02(2014년 모델 사용)이고 직전 거래일 2013-12-30은 현금 대기이며, 수익률 집계는 2014-01-02부터(첫날 수익 0).
8. **게이트 F 무작위 대조의 해석**: 실제 실행의 진입 판단일·진입 수와 같게 그날 K200P에서 무작위 종목을 뽑고, 보유 중 매일 확률 q로 이탈한다. q = (실제 실행의 순위 이탈 청산 건수 ÷ 실제 실행의 보유 거래일 합) — 실제와 같은 평균 보유 기간을 갖게 한 "무작위 순위" 대조다(매일 독립 무작위 순위를 매기면 거의 매일 거래해 대조가 무의미하게 약해지므로). 1,000회, 기존 연구와 같은 시드. 다중시험 참고선 1 − 0.05 ÷ 3.
9. **게이트 D 이웃**: 보유 종목 수 7·15(진입 상위 N, 청산 순위 30 고정), 청산 순위 20·40(보유 10 고정), 모델 시드 2·3(LightGBM `seed` 파라미터, 매년 모델 전체 재학습). 이웃 통과 = 전 기간 CAGR ≥ 069500 새 기준선.
10. **게이트 H**: 069500으로 판정(조건1 CAGR ≥ 기준선 + 1%p, 조건2 MDD ≤ 기준선 − 3%p ∧ CAGR ≥ 기준선 − 1%p; 연구 PEAD와 같음). L3(시총 상위 5 편입·10위 밖 매도, 5종목; 같은 엔진으로 재계산)와 PE4(기록값; 평가 시작이 2017-04-04라 구간이 같지 않음)는 참고 열.
11. **라벨 셔플 대조**(진단): 학습 라벨을 각 날짜 횡단면 안에서 무작위로 섞고(시드 20261028) 같은 절차·같은 매매 규칙으로 한 번 돌린다(후보별). 판정에 쓰지 않는다.
12. **IC 진단**: 날짜별 스피어만 상관(예측 점수 vs d+1→d+21 종가 수익률), 연도별 평균. 상위 10종목의 20일 평균 실제 수익과 같은 날 유니버스 평균을 함께 본다. 특성 중요도는 연도별 모델의 게인 합 비중. 판정에 쓰지 않는다.
13. **재현성**: LightGBM은 기본값(스레드 수 포함)으로 돌며 비결정적 요소가 있을 수 있으나 재실행하지 않는다. 환경: Python 3.12.3, **lightgbm 4.7.0**, numpy 2.5.4(사전 점검 run 40615998334에서 pip로 설치·기록; 정식 실행은 같은 명령으로 설치하므로 버전이 달라지면 결과에 기록한다), GitHub Actions ubuntu-latest 4 코어.

## 10. 경고 문구

- **홀드아웃 오염**: 보류 구간(2022~)은 이미 여러 번 본 데이터이고, 학습·확인 구간도 앞선 연구들에서 반복해 본 구간이다. 특성·규칙(상위 10/30위)은 이전 연구 결과를 본 뒤 정한 것이다.
- **우연 통과**: 누적 시험 250번 중 실력이 없어도 5% 수준 기준 하나를 우연히 넘는 후보가 평균 250 × 0.05 = **12.5개** 나올 것으로 기대된다(시험들이 독립이 아니므로 근사).
- **재무 데이터 미사용**: 가격·거래량·시총·외국인 수급만 쓴다(재무·공시 특성 없음).
- **기관 수급 제외**: 사용자 지정과 달리 기관 순매수 특성이 없다(5절 1). M2·M3는 사용자 의도(외국인·기관)의 부분 검증이다.
- **학습 구간 단축**: 첫 예측 연도 모델의 학습 자료는 2011~2013(약 3년, 약 14만 행)뿐이고 2015년까지 외국인 수급 특성 결측률이 높다(2011~2013 약 11%).
- **과적합 위험**: 25개 특성, 300 트리, 연 12~13회 재학습에서 변형 12개를 돌린다. 학습 구간 성능과 평가 구간 성능이 같지 않을 수 있고, 같은 단일 경로를 평가한다. 라벨 셔플 대조로 최소한의 점검을 한다.
- **종가 판정·체결 이상화**, 슬리피지 가정, 현금 이자 0, 배당락 미조정, 단일 경로 in-sample, 유니버스(K200P) 월말 구성 + 당일 시총, 엔진 관습(매도 체결 뒤 다음 판단일에 슬롯 채움).
- **상위 10종목 동일가중·30위 유지 규칙의 회전율**: 점수가 날마다 바뀌면 회전율과 비용이 커질 수 있다(비용 합계와 연 회전율을 보고한다).
