판정·추천 없이 숫자와 표만 보고한다. 브랜치 `claude/ma-v3-portfolio-cap-run`, main 병합·변경 없음, DB 읽기만(쓰기 0), 외부 요청 0건, psql 직접 연결 없음, 캐시 엄격 게이트(17개 연도 파일). 실행 1회, 재실행 금지. 누적 시도 **87 → 93**(아래 6개).

## 1. 사용자 지정 정의 (원문)

### 공통
- 가격: 조정 가격(pit_adjusted), 상장폐지 포함, PIT 유니버스(시총 5천억 이상 + 20일 평균 거래대금 5억 이상), 월말 구성원 갱신. D4(유니버스 시총가중)는 research/baseline-decomposition-prereg.md의 D4 구현을 그대로 재사용.
- 비용: fee 0.015%/편, 세금 날짜별, 슬리피지 0.1%/편. 월말 구성원 변경 거래와 추세 전환 거래 모두에 적용. 현금 수익 0.
- 체결: 신호일 종가(기본), 지연 변형은 다음 거래일 종가.
- 이동평균: 단순이동평균 N일 종가, 종가 > SMA(N)이면 통과. N ∈ {224, 200}.
- 평가 기간: 학습 2010-01-01~2018-12-31, 확인 2019-01-01~데이터 끝, 전체. SMA가 정의되지 않는 초기 구간 때문에 각 N의 첫 정의일 이후 같은 날짜 범위에서 D4·KOSPI·유니버스 동일가중·v3·POOL(시총 상위 100 시총가중)을 다시 계산해 나란히 놓는다.

### 후보 6개
- T1(N): D4 지수 타이밍. D4의 일별 누적 수익 지수가 자신의 SMA(N) 위이면 D4 보유, 아니면 전량 현금. 전환은 일 종가 판정.
- T2(N): 종목별 추세 필터, 제외분 현금. D4 시총 목표비중 w_i를 쓰되 종가가 자기 SMA(N) 위인 종목만 w_i 보유, 아래인 종목의 비중은 현금(재분배 없음).
- T3(N): 종목별 추세 필터, 재분배. 통과 종목끼리 시총 비중을 다시 정규화(통과 종목이 없으면 전량 현금).
- N ∈ {224, 200}이므로 후보는 T1(224), T1(200), T2(224), T2(200), T3(224), T3(200) 6개.

### 판정 기준 (기계적 O/X, 종합 판정 문장 없음)
- 학습 기준(전부 충족해야 "확인 진행" 표시): TR1 CAGR ≥ D4 − 2.0%p, TR2 MDD ≤ 0.80 × D4 MDD, TR3 CAGR÷MDD > D4의 CAGR÷MDD.
- 확인 기준(후보별 1회, 학습 불통과 후보의 확인 수치도 계산해서 보고하되 통과 표시는 하지 않음): CF1 CAGR ≥ D4 − 2.0%p, CF2 MDD ≤ 0.80 × D4 MDD, CF3 CAGR÷MDD > D4의 CAGR÷MDD, CF4 신호 +1거래일 지연 시 CAGR 하락 ≤ 1.0%p.
- 정보용(기준 아님): 같은 구조의 N=224와 N=200 차이(|ΔCAGR|, |ΔMDD|), 연간 전환 횟수, 연간 회전율, 비용 차감 누적, 연도별 수익률, POOL 대비 CAGR·MDD.

## 2. 구현 정의 보충 (실행 전에 고정, 사용자 정의를 바꾸지 않는 해석)

1. **데이터·유니버스**: `scripts/research-baseline-decomposition.ts`와 같은 파이프라인(`loadSeries()` → `buildCtx`로 Sk 생성, 적격 판정 = 직전 행 시총 ≥ 5000억 + 당일 행 `avgTv`(직전 20거래일 평균 거래대금) ≥ 5억, 순위·가중에 쓰는 시총 = 리밸런싱일 당일 행 `market_cap_eok`). 거래일 캘린더 = 전 종목 거래일 합집합 중 2010-01-01 이후. 월말 = 월 마지막 거래일(마지막 달이 끝나지 않았으면 제외).
2. **D4**: `scripts/research-audit-peg.ts`의 `simulateD4`를 import해 수익률 계열을 그대로 쓴다(기준선 분해 진단의 D4와 같은 구현). 거래비용 누적 계열만 이 연구의 엔진(아래 3항)이 D4 규칙으로 따로 계산하고, 두 수익률 계열의 최대 절대 일 수익률 차이를 출력한다(일치 확인용, 중단 조건 아님).
3. **엔진**(후보·POOL 공통): 일별로 보유 종목을 종가로 재평가하고, 마지막 행이 해당일 이전이며 데이터 끝−14일 이전이면 마지막 종가로 청산(`simulateD4`와 동일). 체결 거래의 비용은 `computeEffectiveBuyPrice(1)−1`(매수), `1−computeEffectiveSellPrice(1, 날짜, "KR")`(매도)를 체결 금액에 곱한 값. 전체 재조정은 목표 거래금액 기준 총비용 C를 V에서 차감하고 목표 비중을 (V−C)/V배로 축소(`simulateD4`와 같은 근사). 현금 이자 0. 일별 비용 비율 = 그날 비용 ÷ 전일 평가액이고, 보고하는 "거래비용 누적" = 구간 내 일별 비용 비율의 합(%).
4. **시작일 S_N**: 각 N의 첫 정의일 = 2010-01-01 이후 거래일 캘린더의 N번째 거래일(0-기준 인덱스 N−1). D4 지수가 그날 처음으로 SMA(N)을 갖는다. 후보는 S_N부터 시작하고(그 전에는 계산하지 않음) 시작 시점에 포트폴리오는 전량 현금이다. 평가 구간은 모두 S_N 이후 같은 날짜 범위로 자른다: 학습 = S_N~2018-12-31, 확인 = 2019-01-01~데이터 끝, 전체 = S_N~데이터 끝. D4·POOL·KOSPI·동일가중·v3는 2010-01부터 이어진 단일 실행의 일 수익률을 같은 날짜 범위로 잘라 재계산(재시작 아님). CAGR은 `computeCagrPct(총수익률, 구간 시작일, 구간 끝일)`(끝일은 데이터 끝 또는 구간 끝), MDD는 `computeCumulativeAndMdd`(구간 안에서 100으로 시작하는 곡선), 연변동성 = 일 수익률(%) 표본 표준편차 × √252.
5. **통과 정의**: 종목 자신의 종가 시계열 기준 SMA(N)(해당 종목 행 N개 필요). 종가 > SMA(N)(엄격 부등호)이면 통과. 종목 행이 N개 미만이면 SMA 미정의이며 **통과하지 못한 것으로 본다**(T2는 현금, T3은 정규화 대상에서 제외). 그날 행이 없는 종목(거래정지 등)은 직전 판정을 유지한다.
6. **T1(N)**: D4 일 수익률 계열(위 2항, 비용 포함)에서 누적 지수 level_k(첫 거래일부터 복리)를 만들고 k ≥ N일 때 level_k > SMA_N(level)이면 "보유" 신호. 신호가 바뀌는 날(신호일 종가 판정)에만 전환 거래: 보유→현금 = 전 종목 매도, 현금→보유 = 그날 D4 목표 비중(월말 적격 규칙을 그날 일자에 적용한 시총가중)으로 전량 매수. 보유 중 월말에는 D4 목표 비중으로 전체 재조정. 현금일 때 수익률 0. 신호 지수는 지연 여부와 무관하게 D4 단독 실행에서 만든 것을 쓴다.
7. **T2(N)**: 기준 비중 w_i = 직전 월말(또는 S_N 첫날)에 확정한 D4 목표 비중. (a) 월말(및 S_N 첫날): 통과 종목에 w_i, 나머지는 현금으로 전체 재조정. (b) 월말이 아닌 날 통과 집합이 직전 체결 집합과 달라지면 **바뀐 종목만** 거래: 탈락 종목은 전량 매도, 신규 통과 종목은 `min(w_i × V, 현금/(1+매수비용률))`만큼 매수. 나머지 종목은 드리프트에 맡긴다. 재분배 없음.
8. **T3(N)**: 기준 비중 w_i는 T2와 같고, 목표 = 통과 종목의 w_i ÷ Σ(통과 종목 w). 통과 종목이 없으면 전량 현금. 월말(및 S_N 첫날)과 통과 집합이 직전 체결 집합과 달라진 날 모두 **전체 재조정**(드리프트 포함 전 종목 목표 비중으로).
9. **지연 변형(CF4, 정보 표 (e))**: 신호일 d의 판정(T1 신호, T2·T3의 통과 집합·월말 여부·기준 비중)을 다음 거래일 d+1 종가 가격으로 체결(d+1에 행이 없는 종목은 그날 대상에서 제외). 신호 계산 자체는 변하지 않는다. CF4의 하락 = (기본 확인 구간 CAGR) − (지연 변형 확인 구간 CAGR) ≤ 1.0%p. 지연 변형은 6개 후보 전부 계산한다.
10. **POOL**: 월말 적격 종목 중 당일 시총 상위 100, 시총 비례, 월말 전체 재조정(같은 엔진, S_N 이전부터 이어진 단일 실행에서 자름). **유니버스 동일가중**: `simulateUniverseMonthlyRebalance`(적격 판정 = 당일 행 시총 ≥ 5000억 + 당일 `avgTv` ≥ 5억), 이전 연구와 동일 호출. **KOSPI**: `getIndexPriceSeries("KOSPI")` 일 수익률(가격지수). **v3**: 기준선 분해 진단과 같은 구현(50/200 골든크로스 + 52주 고가 −18.29% 이내 필터, 데드크로스 청산, `accumulateStockDailyReturns`의 일별 동일비중 집계)을 그대로 복사해 재계산하고, 재현 값(6.36 / 53.31 / 2,335건, 2010~ 전체)을 한 줄로 출력한다(중단 조건 아님, 비교용).
11. **정보용 지표 정의**: 연간 회전율 % = 구간 내 체결일별 (매수금액+매도금액)/2/V의 합 ÷ 구간 연수(구간 일수/365.25) × 100. 연간 전환 횟수: T1 = 보유↔현금 전환 체결 횟수 ÷ 연수, T2·T3 = 통과 집합 변화로 인한 종목 단위 진입·청산 건수(월말 재조정은 제외) ÷ 연수. 연도별 수익률은 달력 연도의 일 수익률 복리(후보는 S_N 이후만 포함하므로 2010년은 부분 연도), 2026은 데이터 끝까지. N=224와 N=200의 차이는 두 N의 공통 구간(S_224 이후 같은 날짜 범위의 학습/확인/전체)에서 각각 재계산한 값의 절대 차이. POOL 대비 = (후보 − POOL) CAGR %p, MDD %p(같은 구간).
12. **학습 기준 구현**: TR1 `cagr ≥ D4.cagr − 2.0`, TR2 `mdd ≤ 0.80 × D4.mdd`, TR3 `cagr/mdd > D4.cagr/D4.mdd`(MDD > 0일 때). D4는 같은 N의 같은 구간 값. 확인 구간도 CF1~CF3은 같은 식. "확인 진행/통과" 표시는 학습 TR1~TR3 전부 O인 후보에만 붙이고, 그 후보의 CF1~CF4가 모두 O이면 "확인 통과"로 표기. 학습 불통과 후보는 CF 수치와 O/X는 보고하되 표시란에 "-".
