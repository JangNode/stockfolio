# 저평가 후속 사전등록 (VB1F 314 · DS14 315: 시장 필터, 코어 + 모멘텀 + 가치 위성)

연구 브랜치 `claude/ma-v3-portfolio-cap-run` 전용. main 병합·변경·운영 적용·PR 없음. 연구 DB 쓰기 0, 외부 호출 0(저장된 자료만), 키 값 출력 없음, 데이터 파일 artifact 없음(저장소 공개). 사용자 지정 2026-11-21. 이 문서는 **첫 시험 전에** 커밋한다. 등록 후 정의 변경 금지, **이 2개만 시험하고 추가 변형·재시험 금지(누적 315에서 종료)**. 구현의 논리 결함만 사유를 기록하고 고친다.

## 0. 선택 편향 고지 (문서 첫머리)
**이 가설은 VB1(311), VB1C(313), RM1, DS13 결과를 모두 본 뒤 만든 것이며 선택 편향이 매우 크다.** VB1이 069500보다 CAGR은 높았지만 MDD가 64%로 관문 A·B에서 탈락한 것(주로 2017~2021 구간)과 VB1C가 A에서만 탈락한 것을 본 뒤, "시장 필터로 하락을 줄이거나(VB1F)", "코어 + 모멘텀 + 가치로 분산(DS14)"하는 형태를 시험한다. 통과해도 **포워드 확인 대상일 뿐 확정이 아니다.** 시험 구간은 이미 반복해서 본 오염된 구간이다. 누적 시험은 313 → 315, 실력이 없어도 5% 기준 하나를 우연히 넘는 후보 기대는 315 × 0.05 = 15.75건(근사).

## 0.1 사전 확인 결과 (중복 시험 여부, 2026-11-21)
`docs/` 전체에서 "시장 필터", "200일 이동평균", "가치 위성", "코어 + 모멘텀 위성" 등을 찾았다. **VB1 + 시장 필터**와 **코어 + RM1 + VB1(저PBR) 위성**과 같은 정의는 기록에 없다.
- 가장 가까운 것: RM1F·RT1F·LR1F·PF1F(같은 시장 필터를 RM1·RT1·LR1·PF1에 덧씌움, batch5-prereg·rt1-prereg), DS13M·DS13L(코어 + RM1 + 저위험 위성, ds13-prereg), VB1C(코어 40% + 위성 60% = VB1, value-prereg).
- 정의가 다르므로 두 시험 모두 진행한다. 정책: 공시는 **정기 재무로 PBR을 만드는 용도로만** 쓰고 접수일 < 신호일(다음 거래일부터 반영)이다(value-prereg §0.1). 이벤트 반응형은 쓰지 않는다.

## 1. 공통 데이터·정의 (VB 시험과 같은 것은 그대로)
- 자본 자료·PBR·유니버스·제외 조건·신호일·체결·비용·슬리피지·벤치마크·소멸 처리: **value-prereg.md §0.2·§1과 같다**(자본총계 분모, 접수일 < 신호일, 경과 400일 초과 제외, 자본잠식 제외, BS1 적격 유니버스, 소멸은 마지막 종가 청산하되 직전 20거래일 중 거래정지 5일 이상이거나 마지막 종가 1,000원 미만이면 전액 손실). 한계(자본총계 사용, 정정 전 원본 없음, 관리종목 이력 없음)도 같다.
- **데이터 표준**: K200P 17건 보정 적용(`PRICE_CORRECTION=k200p17`), 의심 종목-일 0% 처리(`ZERO_SUSPECT=1`, 앞선 점검 810건 정의, K200P 보정 표준에서 793건). **같은 시험을 처리 없이 돌린 결과는 정보용**(시험 번호 없음, 판정 불사용).
- **기간**: VB 시험과 같다. 첫 신호일 2011-05-31, 수익률 집계 2011-06-01~2026-10-26. 연속 전체 + 3구간(구간 1 2011-06-01~2016-12-29 / 구간 2 2017-04-04~2021-12-31 / 구간 3 2022-01-01~2026-10-26). 069500도 같은 구간 기준선. **DS14의 모든 하위 계좌(코어·RM1·VB1)는 같은 첫 신호일 2011-05-31에서 시작한다**(RM1 단독의 첫 신호일은 2011-01-31이지만 이번에는 2011-05-31부터 돌린다).
- 사용자 지정 목표 정의와 구현의 같은 부분: 가치 위성 = VB1(`VB1_P0`: 하위 PBR 30종목 동일 비중, 하위 90위 안이면 유지) 그대로, 위성 안 비중 × 0.3은 하위 계좌 배분 0.3으로 구현한다.

## 2. 시험 314 — VB1F (VB1 + 시장 필터)
- VB1 정의 그대로 + **월말 신호일에 069500 종가(원주가 일수익률로 만든 지수 수준, `bL`)가 그날까지 200일 단순이동평균(당일 포함) 미만이면 주식 비중 50%(보유 종목 비례 축소, 종목당 1/60), 이상이면 100%(종목당 1/30).** 판단은 월말 신호일에만 하고 월중에는 바꾸지 않는다(체결 다음 거래일 종가). 종목 선정·유지 규칙(하위 90위)은 필터와 무관하게 VB1 그대로. 현금 이자 0. 필터 정의는 batch5-prereg의 RM1F·LR1F·PF1F와 같은 코드(`filterMult`, 배수 `B5_FILTER_LOW` = 0.5, 엄격 부등호)를 쓴다.
- **D 이웃값**: 이동평균 150일, 250일(2개). (VB1의 종목 수·경과일 이웃은 이번에 쓰지 않는다.)

## 3. 시험 315 — DS14 (코어 + 모멘텀 위성 + 가치 위성)
- **하위 계좌 3개**(초기·목표 비중 40 / 30 / 30, `V2_W`): ① **코어 40%** = DS6 코어 정의 그대로(월말 K200P 시총 상위 2종목, 5거래일 연속 밖일 때 교체, `coreOf(2, …)`) ② **모멘텀 위성 30%** = RM1 정의 그대로(`B5_RM_P0`: K200P 069500 회귀 잔차 모멘텀, 점수 상위 20종목 동일 비중, 순위 40위 안이면 유지, 월 1회) ③ **가치 위성 30%** = VB1 정의 그대로(위성 안 비중 × 0.3 = 하위 계좌 배분).
- **재조정**: 첫 신호일 종가에 40/30/30으로 배분(비용 없음), **매월 마지막 거래일 종가의 하위 계좌 평가액으로 40/30/30 목표 금액을 계산하고 다음 거래일 종가에 고정 금액을 옮긴다**(이동 금액 × 0.25% `CS_MOVE_COST`, DS13과 같은 `combineN`).
- **겹치는 종목**: 같은 종목이 여러 하위 계좌에 있어도 각 하위 계좌가 독립으로 보유하고 각자 비용을 낸다(계좌 기준 비중은 합산된다). DS13과 같은 방식.
- **D 이웃값(한 번에 하나씩, 7개)**: 위성 배분(모멘텀/가치) 20/40, 40/20 · 코어 비중 30%(35/35), 50%(25/25) · **PBR 보고서 최대 경과일 300, 500**(가치 위성만).

## 4. 관문 A~H (기존 정의·구현 그대로, 기계 판정, `scripts/researchGates.ts`; **F는 백분위 95 이상**)
A 연속 전체에서 069500 대비 CAGR +2%p 이상 ∧ MDD가 069500과 같거나 작음. B 3개 구간 중 2개 이상에서 069500을 이긴다(구간별 CAGR이 크고 MDD가 같거나 작음, `SAT_MDD_EPS` 허용). C 하루 지연(진입·청산·재조정 체결 +1거래일)에서 연속 전체 CAGR 하락 ≤ 1%p ∧ MDD 악화 ≤ 2%p. D 이웃값 모두 연속 전체 CAGR ≥ 069500 CAGR. E 손익 상위 3개 보유 구간을 069500 수익률로 대체해도 연속 전체 CAGR ≥ 069500(DS14는 두 위성의 닫힌 거래 중 계좌 기준 손익 상위 3개를 대체, 코어는 실제 그대로 — DS13과 같음). F 무작위 진입일(같은 신호 건수·보유 기간 분포, 같은 유니버스에서 PBR 있는 종목 무작위, 1,000회, 시드 20261022) 백분위 ≥ 95(DS14는 모멘텀·가치 위성 각각 무작위 대조를 실제 코어와 40/30/30 합성). G 진입 건수 ≥ 100(DS14는 코어 + 두 위성 진입 합). H 069500 대비 CAGR +1%p 이상, 또는 (MDD 개선 3%p 이상 ∧ CAGR ≥ −1%p). 통과 = 전부 통과, 게이트는 완화하지 않는다. F 참고선: 1 − 0.05 ÷ 2 = 97.50(판정 기준 자체는 95).

## 5. 보고 항목 (구현 후 출력과 대조한다)
- **R1** 연속·3구간 CAGR/MDD/최악 12개월/샤프, **R2** 관문별 판정(탈락이면 기준과의 차이), **R3** 연도별 승패(069500 대비 · DS6 대비 · DS13L 대비), **R4** 연 회전율·비용, **R5** 같은 데이터·같은 구간(2011-06~) 기준 나란히 비교 표: DS6, DS13L, DS13M, VB1, VB1C, RM1C, VB1F, DS14, 069500.
- **정보용**: **I1** VB1·RM1·DS13L·DS14 사이 일간 수익률 상관계수(VB1F·069500 포함), **I2** VB1의 MDD 구간(고점일·저점일)과 그 구간의 069500·KOSPI·KOSDAQ 등락, **I3** VB1 보유 종목의 삼성전자·SK하이닉스 보유 여부, **I4** VB1의 2025~2026년 손실이 어느 업종(KSIC 2자리, 업종 미상 비중 함께)·시장에서 났는지, **I5** VB1F의 필터 가동 비율·필터 기간 손익 기여, **I6** DS14 손익 분해(코어·모멘텀·가치), **I7** DS14 삼성전자·SK하이닉스 평균 비중, **I8** 하루 지연(C)에서의 CAGR·MDD 변화, **I9** 의심 종목-일 처리 유무 비교(정보용), **I10** 누적 시험 횟수와 우연 통과 기대 건수.
- 모든 관문을 통과하면 "통과(선택 편향 큼, 포워드 확인 필요)"로 표시하고 포워드 도구에 추가하는 데 필요한 작업만 제안한다(구현 금지).
