# 변동성 목표화 2변형 사전등록 (누적 시도 117 → 119, 홀드아웃 실행 시 +1)

승인 범위: 사전등록 커밋 → 백테스트 1회. 재실행 금지. 결과를 본 뒤 정의·기준·변형·선택 규칙 변경 금지. 다음 라운드 자동 시작 금지.
브랜치 claude/ma-v3-portfolio-cap-run (병합 금지). 외부 요청 0건, DB 읽기만·쓰기 금지.
기존 사전등록 문서에 "069500 단일 자산의 실현 변동성으로 주식 비중을 정하는 규칙"이 있는지 확인함 — 없음(비슷한 항목: etf-allocation-prereg.md:20 A4는 세 위험자산의 역변동성 비례, allocation-goals-prereg.md:25 E1은 세 자산 역변동성 비례, new-strategies-prereg.md:20 S-B는 개별 종목 저변동성 선택으로 모두 다른 규칙).

## 데이터·비용
research/seasonality-prereg.md(2f69f8ed)와 같은 데이터·정제·비용 규칙: 069500(주식), 114260(국고채3년), 수정주가, 편도 수수료 0.015% + 슬리피지 0.05%, 매도세 없음, 세금 미반영.

## 규칙
- 매월 마지막 거래일 종가에 σ = 069500 최근 N거래일 일수익률 표준편차 × √252 계산.
- 목표 비중 w = min(1, 0.15 ÷ σ). 나머지 1 − w는 114260.
- |w − 현재 비중| ≥ 0.10일 때만 그날 종가에 목표 비중으로 리밸런싱, 아니면 그대로 둠(월중 비중 변동은 가격 따라 자연 변동).
- 지연 변형: 같은 신호를 다음 거래일 종가에 체결.
  - V1: N = 20
  - V2: N = 60

## 기간
학습 2010-01-01~2016-12-31, 확인 2017-01-01~2021-12-31, 홀드아웃 2022-01-01~데이터 끝.
비교 기준 B&H = 069500 보유. 참고로 114260 보유, KOSPI 표시.
첫 신호는 2009-12-30(N일 데이터가 부족하면 가능한 첫 월말부터, 그 전은 069500 100%로 두고 보고).

## 기준 (각 관문 공통) (계절성과 동일)
- G1 CAGR ≥ B&H CAGR − 1.0%p
- G2 샤프(무위험 0, 연환산 평균 일수익 ÷ 연환산 표준편차) > B&H 샤프
- G3 CAGR÷MDD > B&H
- G4 지연 시 CAGR 하락 ≤ 1.0%p

## 절차
학습 G1~G4 전부 O인 것 중 학습 샤프 최대 1개 선택(없으면 종료) → 확인(하나라도 X면 종료, 홀드아웃 미계산) → 홀드아웃(전부 O일 때만 최종 통과). 선택 안 된 변형의 확인·홀드아웃은 계산·보고 금지.

## 구현 세부 (결과를 보기 전에 고정하는 해석 — 사용자 문안에 없는 부분)
1. 데이터·정제·달력·월말·실행 시작일은 seasonality-prereg.md 구현 세부 1·2와 같다(달력 = 두 자산 정제 후 거래일 교집합, 월말 = 다음 거래일의 연월이 달라지는 날, 실행 시작일 s0 = 2009년 마지막 거래일, 단일 실행에서 창을 잘라 쓰며 창은 s0 다음 거래일부터, 초기 진입 비용은 창 밖).
2. σ = 069500(정제) 결정일까지 최근 N개 일수익률의 표본표준편차(n−1) × √252 (결정일 포함, 달력 거래일 기준). N개 일수익률이 갖춰지지 않은 결정일(달력 인덱스 < N)은 신호 없음. 신호가 없는 구간은 s0부터 069500 100%로 둔다(초기 진입 포함). σ = 0이면 w = 1.
3. s0의 결정: 신호가 있으면 s0 종가에 목표 비중으로 진입(임계 검사 없음, 지연 변형도 s0 진입), 없으면 069500 100%. 그 이후 결정일(월말)마다 현재 비중 = 결정일 종가 기준(그날 평가절하 후, 체결 전) 069500 평가액 ÷ 포트폴리오 가치. 신호가 있고 |w − 현재 비중| ≥ 0.10이면 리밸런싱을 확정한다. 무지연: 그날 종가에 w로 체결. 지연: 같은 결정일의 w를 다음 거래일 종가에 체결(임계 검사는 결정일 기준으로만 하고, 체결일에 다시 검사하지 않음).
4. 체결: 주식·채권 평가액을 목표 비중(w, 1−w)에 맞춰 매수/매도, 비용 = (매수액+매도액)×(0.015%+0.05%), 체결일 가치에서 차감. 보유 평가액은 일별 수익률로 평가절하(드리프트). 연 리밸런싱 횟수 = 창 내 체결일(s0 제외) 수 ÷ 창 연수. 누적 비용 = 창 내 체결 비용/체결 직전 가치의 합(%). 평균 주식 비중 = 창 내 일별 종가 기준 069500 평가액 ÷ 가치의 평균. 연도별 평균 주식 비중 = 해당 연도 일별 값의 평균.
5. 지표(CAGR, MDD, 샤프, CAGR÷MDD, 연변동성, G4의 CAGR 하락 = 무지연 − 지연)·B&H·114260 보유·KOSPI(DB 지수 종가 일수익률, 2010-01-05부터)·선택 동률(연 리밸런싱 횟수가 적은 쪽)은 seasonality-prereg.md 구현 세부 6과 같다.
6. 상수는 lib/volTargetConfig.ts(및 직전의 lib/seasonalityConfig.ts, lib/etfAllocationConfig.ts)에 둔다.
