# 목표별 3계열(R·D·E) 자산 배분 사전등록 (누적 시도 106 → 112, 홀드아웃 실행 1건마다 +1)

승인 범위: 레버리지 ETF(122630) 일봉 수집 1회 → 사전등록 커밋 → 백테스트 실행 1회. 재실행 금지. 결과를 본 뒤 정의·기준·변형·선택 규칙·정제 규칙 변경 금지.
브랜치 claude/ma-v3-portfolio-cap-run (병합 금지). DART·KRX 0건. DB 읽기만, 쓰기 금지(수집 단계의 etf_daily_prices 122630 행 추가는 완료된 별도 단계).

## 공통 (직전 research/etf-allocation-prereg.md e0219298과 동일한 부분)
- 가격 etf_daily_prices.adj_close, 같은 하루짜리 튐 정제 규칙(122630은 같은 날 069500 수익률 부호가 같고 크기가 절반 이상이면 실제 변동으로 보고 유지).
- 매월 마지막 거래일 종가에 결정·체결, 지연 변형은 다음 거래일 종가. 편도 0.015% + 슬리피지 0.05%, 세금 미반영(한계로 기록). 현금 미사용.
- 기간: 학습 2013-01-01~2018-12-31, 확인 2019-01-01~2022-12-31, 홀드아웃 2023-01-01~데이터 끝. B&H = 069500 단순 보유. 샤프 = 연환산 평균 일수익 ÷ 연환산 표준편차(무위험 0).
- 10개월 이동평균 = 최근 10개 월말 종가 평균(당월 포함). 60일 변동성 = 최근 60거래일 일수익률 표준편차.

## R 계열(수익 우선)
- R1 069500 월말 종가 > 10개월 이동평균이면 122630 100%, 아니면 114260 100%.
- R2 122630 50% + 148070 50%, 매월 말 재조정.
- 기준(각 관문): RG1 CAGR > B&H CAGR, RG2 MDD ≤ B&H MDD + 10.0%p, RG3 지연 시 CAGR 하락 ≤ 1.0%p.
- 선택: 학습 전부 O인 것 중 학습 CAGR 최대.

## D 계열(낙폭 우선)
- D1 069500 40% + 114260 30% + 132030 30%, 매월 말 재조정.
- D2 069500 월말 종가 > 10개월 이동평균이면 069500 100%, 아니면 114260 50% + 132030 50%.
- 기준: DG1 MDD ≤ 0.50 × B&H MDD, DG2 B&H CAGR > 0이면 CAGR ≥ 0.70 × B&H CAGR, B&H CAGR ≤ 0이면 CAGR ≥ B&H CAGR, DG3 지연 시 CAGR 하락 ≤ 1.0%p.
- 선택: 학습 전부 O인 것 중 학습 MDD 최소.

## E 계열(효율 우선)
- E1 069500·114260·132030을 60일 변동성 역수 비례로, 매월 말.
- E2 069500·114260·132030 각 1/3, 매월 말 재조정.
- 기준: EG1 샤프 > B&H 샤프, EG2 CAGR÷MDD > B&H, EG3 지연 시 CAGR 하락 ≤ 1.0%p.
- 선택: 학습 전부 O인 것 중 학습 샤프 최대.

## 절차 (계열마다 독립)
학습 선택 → 없으면 "선택 없음" 종료 → 선택 1개만 확인 → 하나라도 X면 "통과 아님" 종료(홀드아웃 미계산) → 확인 전부 O면 홀드아웃 → 전부 O일 때만 최종 "통과". 선택되지 않은 변형의 확인·홀드아웃은 계산·보고하지 않는다.

## 구현 세부 (결과를 보기 전에 고정하는 해석 — etf-allocation-prereg.md의 "구현 세부 1~9"를 그대로 따르되 아래만 다르다)
1. 자산 5개: 069500, 114260, 148070, 132030, 122630. 달력 = 5개 자산(정제 후) 거래일의 교집합. 정제는 각 자산 자체 계열에서 원자료 수익률로 탐지·원자료 이웃 가격 기하평균으로 동시 치환하고, 069500의 면제는 같은 날 KOSPI(없으면 면제 없음), 122630의 면제는 같은 날 069500의 원자료 일수익률(없으면 면제 없음).
2. 월말·첫 결정일(2012-12 말)·단일 실행에서 창 자르기·초기 진입 비용 처리·체결·비용·회전율·누적 비용·B&H·KOSPI·D4·연도별 수익률 정의는 직전 사전등록과 같다. 월별 결정일 수가 달라지지 않도록 달력 교집합에서 월말을 정의한다.
3. 샤프 = (일수익률 % 평균 × 252) ÷ (일수익률 % 표본표준편차 × √252), 창 안의 일수익률로 계산. CAGR÷MDD는 MDD>0일 때.
4. 지연 CAGR 하락 = 무지연 CAGR − 지연 CAGR(같은 창). 학습 선택 동률은 연 회전율이 낮은 쪽.
5. 상수는 lib/allocationGoalsConfig.ts(및 직전의 lib/etfAllocationConfig.ts)에 둔다.
