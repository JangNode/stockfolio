# 52주 신고가 근접 사전등록 (HM1 323 · HM1C 324)

연구 브랜치 `claude/ma-v3-portfolio-cap-run` 전용. main 병합·변경·운영 적용·PR·pg_cron 등록 없음. **가격 데이터만 사용**(재무·공시 미사용). 연구 DB 쓰기 0, 외부 호출 0, 키 값 출력 없음, 데이터 파일 artifact 없음. 사전 점검 전에 이 문서를 먼저 커밋하며, **이후 정의·값·변형·재시험을 바꾸거나 추가하지 않는다**(구현의 논리 결함만 사유를 기록하고 고친다). 구현은 `scripts/research-batch5.ts`(ALLOC_MODE `hpre`·`htest`·`hinfo`), 기준값은 `lib/high52Config.ts`.

## 0. 선택 편향 고지 (문서 첫머리)
**이 가설은 앞선 모멘텀(RM1)·52주 신고가 돌파(TS1)·코어-위성(DS 계열) 시험 결과를 본 뒤 만든 것이며 선택 편향이 있다.** 통과해도 **포워드 확인 대상일 뿐 확정이 아니다.** 시험 구간(2011~2026)은 이미 반복해서 본 오염된 구간이다. 누적 시험 322 → **324**, 우연 통과 기대 324 × 0.05 = **16.20건**(근사).

## 1. 공통 정의 (사용자 지정)
- **유니버스**: K200P(PIT) = 신호일 기준 코스피 시가총액 상위 200(월말 시장 구분·제외 규칙 적용, `rank200`).
- **신호(HM1)**: 점수 = 신호일 종가 ÷ 직전 252거래일 최고 종가(당일 제외). 높을수록 상위. 종가는 앞선 시험과 같은 **수정 종가**(`al`, 분할·배당 조정)를 쓴다.
- **포트폴리오**: 매월 말 종가 기준 상위 **20종목 동일 비중(1/20)**, 기존 보유는 **순위 40위 이내면 유지**, 빈자리만 점수 순으로 채움. **현금 없이 전량 투자**(후보가 20개 미만이면 있는 만큼만, 남은 비중은 현금).
- **체결**: 신호일 다음 거래일 종가. 비용·슬리피지·세금은 앞선 시험과 같은 공통 규칙(수수료 0.015%/편도, 매도세 시기별, 슬리피지 신호일 K200P 구성원 0.1%·그 밖 0.2%, 현금 이자 0, 수정주가, 벤치마크 069500 원주가).
- **HM1C(324)**: DS6 코어 40%(같은 코드·같은 캐시) + HM1 60%, **월 리밸런스**(월말 종가에 목표 금액 계산 → 다음 거래일 종가에 이동, 이동 비용 `CS_MOVE_COST` 0.25%). 이는 앞선 VB1C·RM1C·QV1C의 **일별 40:60 재조정과 다르다**(사용자 지정, DS13의 `combineN` 월 1회 재조정과 같은 규칙). 비교 표의 VB1C·RM1C는 일별 재조정 기록 그대로임을 표기한다.
- **데이터 표준**: K200P 17건 보정(`correct=k200p17`) + 의심 종목-일 0% 처리 794건(`zero=1`), 처리 없음 결과는 정보용. 소멸 종목 처리는 VB·VL·Q 시험과 같은 관례(마지막 종가 청산하되 직전 20거래일 중 거래정지 5일 이상이거나 마지막 종가 1,000원 미만이면 전액 손실, `vbVanishLoss`).

## 2. 이 사전등록에서 구현상 정한 값 (사용자 지정에 없던 부분, 결과 전 고정)
- **유효 조건**: 신호일 종가 행이 있고, 직전 `lookback`거래일 중 종가 행이 `lookback × 0.8`개(252일 기준 202개) 이상이며 최고 종가가 양수인 종목만 점수 대상. 계산 불가 종목은 제외(대체 없음).
- **동점**: K200P 시총 순위(작은 쪽 우선).
- **게이트 D 이웃값 4개**(한 번에 하나만 변경): 종목 수 15(유지 순위 30)·30(유지 순위 60), 룩백 189거래일·315거래일(최소 유효 비율 0.8 유지). 모두 연속 전체 CAGR ≥ 069500이어야 D 통과(기존 정의).
- **시작**: 첫 유효 월말 신호일(룩백 252거래일 확보 후, 앞선 RM1과 같은 `startOf` 규칙), 수익 집계는 그 다음 거래일부터. 3구간은 `windowsFor`(구간 1 시작일~2016-12-29 / 구간 2 2017-04~2021-12 / 구간 3 2022-01~2026-10-26). 기준선 069500·DS6·DS13L도 같은 구간·같은 시작일로 비교(앞선 RM1 시험과 동일).
- **게이트 F**: 기존 무작위 진입일 대조, 백분위 95 이상, 참고선 1 − 0.05 ÷ 2 = 97.50.

## 3. 평가·판정
관문 A~H는 기존 정의·구현 그대로(기계 판정). 연속 + 3구간 CAGR/MDD, 069500 원주가 기준, DS6·DS13L·VB1C·RM1C 나란히 비교, 탈락이면 부족한 폭 표기. 이 두 가지만 시험하고 추가 변형·재시험 금지(누적 324에서 종료).

## 4. 정보용 보고 항목 (판정 불사용)
연도별 069500·DS6·DS13L 대비 승패, 승률·손익비·거래당 기대값, 연 회전율·비용 합계, 상위 10개 거래 손익 비중, 삼성전자·SK하이닉스 보유 여부와 평균 목표 비중, RM1과의 일간 수익률 상관계수(그 밖에 VB1·DS13L·069500), VB1 MDD 구간(2018-01-29~2020-03-23)에서 HM1·HM1C 구간 수익·낙폭, 하루 지연(C)에서의 CAGR·MDD 변화, 의심 종목-일 처리 없음 비교, 누적 시험 횟수와 우연 통과 기대 건수. 모든 관문 통과 시 "통과(선택 편향 큼, 포워드 확인 필요)"와 포워드 도구 추가 여부만 제안(구현 금지). 통과 후보가 없으면 같은 가설의 재시험은 하지 않는다.
