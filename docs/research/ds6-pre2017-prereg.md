# 연구 DS6 2017 이전 구간 독립 확인 (시도 272) 사전등록

작성 2026-11-03(사용자 지정). **이 문서는 시험 실행 전 사전등록이며 후보 실행 전에 커밋한다(커밋 해시는 보고에 기록).** 국내 주식과 현금만 쓴다(ETF 매매 금지, 069500은 기준선으로만 쓴다). 모든 구간 성적은 개발 데이터 내 성적이다. 통과해도 운영 적용·PR은 하지 않고 보고만 한다. 탈락하면 원인을 파고들지 않고 결과만 보고한다. 브랜치 `claude/ma-v3-portfolio-cap-run`, main 병합 금지. 공시(DART) 데이터는 쓰지 않는다. 시도 번호는 정식 소진한다(누적 271 → 272, 우연 통과 기대 건수 272 × 0.05 = 13.60).

## 1. 목적

연구 DS5·DS6(`docs/research/ds5-prereg.md`)에서 DS6(코어 40% + 위성 60% LV1 단독)은 2017-04 이후 구간에서 15.65 / 39.15로 B·A는 통과하고 C(하루 지연의 MDD 악화)에서 탈락했다. 같은 정의를 **2011-01-04~2016 말의 구간**에 정의를 바꾸지 않고 한 번만 적용해, DS4 계열(코어 40% + 위성) 구조가 그 이전 구간에서도 069500을 이기는지 본다. 후보·규칙·숫자·게이트 해석은 이 문서에서 고정하고 결과를 본 뒤 바꾸지 않는다.

## 2. 사용자 지정 사항과 구현상 확정한 값 (결과를 보기 전에 고정)

- **정의 변경 금지 (DS6 그대로)**: 코어 40% = 월말 K200P 구성 안 당일 시총 상위 2종목을 시총가중(순위 밖 5거래일 연속일 때만 교체), 위성 60% = LV1 단독, 이동액 0.25% 비용, 일별 목표 비중 리밸런싱.
- **평가 시작**: 가격 Parquet의 가장 이른 날은 2010-01-04이고 월말 시장 구분은 2010-01-29부터 있다. LV1은 250거래일 워밍업이 필요하므로 **평가 시작 판단일(초기 배분 종가) 2011-01-03(달력 순번 251), 수익률 집계 2011-01-04~**이다(연구 LE·LV·L 계열의 평가 시작과 같다).
- **평가 끝**: 지정된 2016-12-30은 **연말 휴장일이라 거래일이 아니다**(사전 점검 첫 실행이 이 때문에 시작 직후 중단, 결과 없음). 그 날짜 이하의 마지막 거래일 **2016-12-29**에서 달력과 모든 시뮬레이션을 자른다.
- **3분할(약 2년씩, 기준일 결과 전 고정)**: 구간 1 2011-01-04~2012-12-31, 구간 2 2013-01-01~2014-12-31, 구간 3 2015-01-01~2016-12-30 지정(실제 마지막 거래일 2016-12-29). 평가 구간 전체 = 2011-01-04~2016-12-29.
- **벤치마크**: 069500 원주가(해당 구간 가격 수익, 보조 파일).
- **게이트 A~H 같은 정의**, 이웃값은 DS6과 같게 코어 비중 30%·50%, 코어 1종목·3종목(DS6의 위성 변동성 창 이웃 2개는 구성요소가 LV1 하나뿐이라 기준과 값이 같은 퇴화 이웃이므로 사용자 지정대로 쓰지 않는다).

## 3. 선택 편향·독립성 사전 고지 (보고에도 반드시 넣는다)

- **DS4 계열 결과를 본 뒤에 정한 구간 시험**이다. 사용자 설명은 "이 구간 데이터는 DS4 설계에 쓰이지 않았다"이다. **DS4·DS6의 후보 정의와 숫자(코어 40%, 2종목, 교체 5거래일, 이동 비용 0.25%, 일별 리밸)를 정할 때 이 구간의 성적을 본 적은 없다는 의미로는 맞다.** 다만 아래 때문에 이 구간은 **구성요소 수준에서는 독립이 아니다**:
  - **위성 LV1(LE2 + 변동성 목표화)은 연구 LE·LV에서 2011~2016을 "학습" 구간으로 포함해 정의하고 고른 후보**다. LV1 단독의 이 구간 성적은 이미 기록돼 있다(`docs/research/le2-voltarget-prereg.md`: 학습 2011~2016 LV1 1.59 / 38.84, 같은 구간 069500 −0.87 / 27.85. 이번 구간 끝이 2016-12-29로 하루 짧아 완전히 같지는 않다).
  - **코어의 대형주 집중 발상**은 연구 L 계열(2011~ 시작)에서 나왔고 그 학습 구간(2011~2016)에서 상위 5종목 단순 보유 L3가 069500보다 나빴다는 결과를 이미 봤다(`docs/research/megacap-momentum-prereg.md` 등).
  - 따라서 **새로운 것은 "코어 40% + LV1 60%를 일별 목표 비중으로 합성한 조합"이 이 구간에서 어떻게 되는가**뿐이다.
- **누적 272회 기준 우연 통과 기대 건수 272 × 0.05 = 13.60**(시험들이 독립이 아니라 근사).
- **삼성전자 의존**: 사전 점검에서 시총 1위가 구간 전체 거래일의 100.00%에서 삼성전자였고, 코어(N=2) 안 삼성전자 비중은 구성 이력상 75~88%다(10절). 코어를 뺀 위성 단독 성적이나 삼성전자를 뺀 코어는 진단에서 따로 본다.
- 기준선 069500은 이 구간에서 낮다(사전 점검 표: 전체 −0.87 / 27.85). 기준선이 낮아 A·H·D가 쉽게 통과될 수 있다는 점을 해석에 감안한다. G(진입 건수 ≥ 100)는 구간이 약 6년으로 짧아 **건수 때문만으로 탈락할 수 있고, 완화하지 않는다**.
- 이 구간 데이터는 이미 앞선 연구들에서 반복해 본 구간이다(오염).

## 4. 입력과 재현

기존 Actions 캐시와 069500 보조 파일, 월말 시장 목록만 쓴다. Storage 읽기는 월말 시장 목록 0.21 MiB뿐이다(캐시 미적중이면 중단). `parquet-snapshot-20261026`(2010~2026 17개 파일 SHA-256 대조; 2017 이후 연도 파일도 스냅샷 통째로 대조·복원하지만 시뮬레이션 달력은 2016-12-29에서 자른다), `research-aux-069500-20261026`, `research-alloc-returns-40627267099`(LV1 일별 순수익 앞부분 대조용). PE4·W3 입력은 읽지 않는다. DART 호출·키 사용 없음. 하네스는 종목코드↔이름 매핑으로 `dart_corp_codes` 테이블을 읽기만 한다(이름 표시와 스팩·리츠 이름 규칙용, 공시 내용은 읽지 않음).

- **미래 데이터 차단**: 달력을 2016-12-29에서 잘라 신호·체결·청산·기간 끝 평가가 모두 그 날짜까지의 데이터만 쓴다. 조정주가는 이전 연구와 같이 적용된 조정 이벤트 전체로 만든 수정주가를 쓴다(이후 분할 등이 과거 주가에 곱해지는 상수 배율이라 일수익률은 바뀌지 않는다. 20일 평균 거래대금 문턱 계산에 쓰인다는 점은 모든 이전 연구와 같은 한계다).
- **LV1 재현 확인**: 자른 달력에서 다시 돌린 LV1 일별 순수익이 이전 연구 전체 기간 캐시의 같은 날짜 앞부분과 1e-9 이내로 같고, 캐시 파일 SHA-256이 연구 ALLOC 사전등록 해시와 같아야 한다. 아니면 중단하고 보고한다.

## 5. 정의 (DS6, 조정 금지)

- **코어 40%**: 판단일 d의 월말 K200P 구성(PIT, 코스피, 제외 규칙) 안 당일 시총 상위 2종목을 시총 비율로 보유. 신호는 d 종가, 체결은 d+1 종가. 보유 종목이 상위 2위 밖으로 나간 날을 1일로 세어 연속 5거래일째에만 교체(상위 2위 안의 비보유 종목 중 시총 최대로, 돌아오면 카운트 리셋). 처음 편입은 2011-01-03 종가 신호로 2011-01-04 종가에 매수. 비중은 처음 편입과 구성 변경 체결일에만 신호일 시총 비율로 맞추고 그 사이에는 되돌리지 않는다. 비용 = 수수료 0.015% + 거래세(매도) + 슬리피지 0.1%. 거래정지·폐지 처리는 연구 CS와 같다.
- **위성 60% = LV1 단독**(연구 LV1: LE2 앙상블 모멘텀 로테이션 + 변동성 목표화, 코스피 시총 상위 풀 안, 구성은 이전 연구와 같은 코드).
- **합성**: 초기 배분 2011-01-03 종가(비용 없음). 매일 종가에 목표 비율(코어 40% / 위성 60%)과 현재 비중의 차이를 고정 금액으로 계산해 다음 거래일 종가에 이동하고, 이동 금액의 0.25%를 한 번, 들어가는 슬리브가 부담한다(정보용으로 0.50%와 0도 보고).
- **구현 보완(정의 변경 아님, 사전 점검에서 드러남)**: 위성 구성요소 비중은 직전 250일 변동성 역수 비중이고 이력이 부족한 구성요소만 있는 동안은 균등 비중(워밍업)이다. 이번 구간은 LV1 자신의 시작과 평가 시작이 같아 처음 250거래일 동안 이력 있는 구성요소가 하나도 없어 비중 합이 0이 되는 구현 틈이 있었다(사전 점검 run 41627216283이 비중 합 점검에서 중단, DS6 성과는 계산 전). **이력 있는 구성요소가 없으면 모든 구성요소 균등 비중**으로 고쳤다. 구성요소가 LV1 하나인 DS6에서는 어느 날이든 위성 안 LV1 비중 100%이므로 결과 정의는 바뀌지 않는다(2017 이후 DS6와 같은 동작).

## 6. 게이트 (기존 정의 그대로, 완화 없음)

A~H는 `scripts/researchGates.ts` 정의를 쓴다(DS6과 같음). **A = 069500 대비 CAGR +2%p 이상 ∧ MDD 같거나 작음, B = 세 구간 중 2개 이상, G = 진입 건수의 합(평가 시작 이후) ≥ 100, 완화 없음.** 해석 고정:

- **C**: 코어와 LV1을 모두 하루 지연(체결 d+2)해 돌린 순수익으로 같은 합성 규칙을 적용. CAGR 하락 ≤ 1%p ∧ MDD 악화 ≤ 2%p.
- **D (이웃, 평가 구간 전체 CAGR ≥ 069500이면 통과; 모든 이웃 통과)**: 코어 비중 30%·50%, 코어 1종목·3종목(4개).
- **E**: **판정은 위성 대체**다. LV1의 평가 구간 닫힌 거래 중 구성요소 계좌 대비 손익 상위 3개를 069500 수익률로 바꾼 위성과 실제 코어를 합성한 전체 CAGR ≥ 069500. 코어 상위 3개 거래 대체(구간 끝에 열린 보유 포함)와 둘 다 대체는 보고만 하고 판정하지 않는다.
- **F**: LV1의 원래 무작위 대조(같은 신호일·주문 수, 같은 청산 규칙, 시드 20261022, 1,000회)를 이번 구간의 실제 진입 일정으로 다시 만들어 실제 코어(고정)와 40:60으로 합성한 분포 대비 후보 실제 CAGR의 백분위가 95 이상. 코어는 무작위화하지 않는다.
- **G**: 위성 LV1 진입 건수 + 코어 진입 건수의 합 ≥ 100.
- **H**: 기준선 069500만으로 판정(CAGR +1%p 이상, 또는 MDD 3%p 이상 개선 ∧ CAGR ≥ 기준선 −1%p; 연구 PEAD와 같은 상수). 다른 후보와는 비교하지 않는다.
