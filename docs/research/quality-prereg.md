# 재무 품질(ROE) 사전등록 (Q1 320 · QV1 321 · QV1C 322) — **초안, 시험 보류(중단 조건 발동)**

연구 브랜치 `claude/ma-v3-portfolio-cap-run` 전용. main 병합·변경·운영 적용·PR 없음. 공시는 **정기 재무로 지표를 만드는 용도로만**, 접수일 다음 거래일부터 반영하고 이벤트 반응형은 쓰지 않는다. 연구 DB 쓰기 0, 외부 호출 0, 키 값 출력 없음, 데이터 파일 artifact 없음. **상태: 사용자 지정 중단 조건(TTM 계산 가능 종목이 월말 종목 수의 60% 미만) 발동으로 시험하지 않았다. 데이터 보강(순이익 수집) 또는 시작일 완화가 결정되면 아래 정의대로 확정 커밋한 뒤 시험한다. 정의는 이 초안 커밋 이후 변경하지 않는다.** 근거와 데이터는 `quality-data-check.md`.

## 0. 선택 편향 고지 (문서 첫머리)
**이 가설은 VB1(311)·VB1C(313)·DS14(315)·VL1(316)의 결과(2018-01-29~2020-03-23 낙폭이 가치 요인 붕괴에서 온 것으로 보임)를 본 뒤 만든 것이며 선택 편향이 있다.** 통과해도 **포워드 확인 대상일 뿐 확정이 아니다.** 시험 구간은 이미 반복해서 본 오염된 구간이다. 누적 시험은 319 → 322, 우연 통과 기대 322 × 0.05 = 16.10건(근사).

## 1. 공통 정의 (VB1과 동일)
유니버스·제외 조건(우선주·ETF·SPAC·리츠, BS1 적격 `B5_BS_P0`), 신호일(월말 마지막 거래일 종가)·체결(다음 거래일 종가)·수수료 0.015%/편도·매도세(시기별)·슬리피지(K200P 구성원 0.1%, 그 밖 0.2%)·현금 이자 0·수정주가·벤치마크 069500 원주가, 소멸 처리(마지막 종가 청산하되 직전 20거래일 중 거래정지 5일 이상이거나 마지막 종가 1,000원 미만이면 전액 손실), 데이터 표준(K200P 17건 보정, 의심 종목-일 0% 처리 793건, 처리 없는 결과는 정보용), 시작일 2011-06 월말(데이터 보강 후; 완화 시 2016-03 월말, 구간 2개, B는 두 구간 모두 069500 우위), 연속 + 3구간. **자본총계(비지배 포함)를 쓰는 한계도 같다**(지배주주지분이 없음).

## 2. ROE 정의 (결과를 보기 전에 고정, `lib/qualityRoe.ts`, quality-data-check.md §3)
ROE = TTM 당기순이익 ÷ 자본총계(직전 보고서 기말). TTM = 사업보고서 값 + 올해 누적 − 전년 같은 기간 누적(1분기는 당기 − 전기). **계산 불가 종목-월은 최근 사업보고서 값으로 대체하지 않고 제외**, 연결 우선·없으면 별도, 접수일 < 신호일, 경과 400일(`maxAge`) 초과 제외. **자본총계 ≤ 0 또는 TTM ≤ 0이면 제외**(적자·자본잠식 배제). PBR은 VB와 같다(시총 ÷ 자본총계, 접수일 < 신호일, 400일).

## 3. 시험
- **시험 320 (Q1)**: 유니버스 중 ROE가 있는(위 제외 통과) 종목에서 **ROE 상위 30종목 동일 비중(1/30)**. 기존 보유는 **ROE 순위 상위 90위(30 × 3) 안이면 유지**, 빈자리만 채움, 월말 신호.
- **시험 321 (QV1)**: **점수 = (PBR 하위 백분위 + ROE 상위 백분위) ÷ 2**(같은 날 BS1 적격 ∧ PBR 있음 ∧ ROE 있는 종목 안의 백분위, 높은 점수가 좋음; PBR 하위 백분위 = 100 − PBR 백분위), 상위 30종목, 보유 유지 규칙은 Q1과 동일(점수 순위 90위 안).
- **시험 322 (QV1C)**: DS6 코어 40% + 위성 60% = QV1(RM1C·VB1C와 같은 일별 40:60 합성, 이동 비용 0.25%).
- **D 이웃값**: 종목 수 20·40 / 보고서 최대 경과일 300·500 / (QV1·QV1C) PBR:ROE 가중 2:1·1:2.
- **관문 A~H는 기존 정의·구현 그대로(F는 백분위 95 이상, 참고선 1 − 0.05 ÷ 3 = 98.33), 기계 판정.** 이 3개만 시험하고 추가 변형·재시험 금지(누적 322에서 종료).

## 4. 보고 항목

## 5. 한계(미리 공개)
