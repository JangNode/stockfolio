## 1. 사용자 지정 정의 (원문)

### 데이터 규칙
- 소스: dart_quarterly_fundamentals(status='ok'), 4분기 순이익은 stock_annual_fundamentals.net_income_parent(E) − 같은 FY 3분기 ni_parent_cum, 전년 4분기도 같은 방식(같은 fs_div일 때만, 사용 가능일 = 연간 보고서 rcept_date). 4분기 영업이익은 만들지 않는다.
- 제외: off_cycle=true 행, rcept_date < 분기 말인 행, fs_div가 당기·전기 비교에 맞지 않는 행.
- 사용 가능일: rcept_date 당일 종가 이후(그날 리밸런스부터 사용 가능).
- 신선도: 기준일 t에 rcept_date ≤ t 이고 t − rcept_date ≤ 150일인 가장 최근 분기만 사용. 없으면 "데이터 없음".

### 풀과 신호
- 풀(POOL): 그날 PIT 유니버스(시총 5천억 이상 + 20일 평균 거래대금 5억 이상) 중 시총 상위 100, 시총 비례.
- S_OP = (op_income_q − op_income_prev_q) ÷ 기준일 시가총액. S_NI = (ni_parent_q − ni_parent_prev_q) ÷ 기준일 시가총액. 둘 중 하나라도 null이면 해당 신호는 "데이터 없음".
- 틸트: 풀 안에서 신호가 있는 종목을 신호 기준으로 5분위. 상위 20% 시총 비중 × 2, 하위 20% × 0.5, 나머지와 데이터 없음 × 1. 합 100%로 정규화. 종목 상한 없음.

### 변형 4개
- Q1: S_OP 틸트, 매월 말 리밸런스
- Q2: S_NI 틸트, 매월 말 리밸런스
- Q3: S_OP 틸트, 실적 시즌 리밸런스(5·8·11월 말, 그 사이엔 비중 유지·드리프트)
- Q4: S_OP 선정형(비교용): 풀 안 S_OP 상위 20%만 시총 비례 보유(종목당 상한 20%), 매월 말
- 비용: fee 0.015%/편, 세금 날짜별, 슬리피지 0.1%/편. 체결은 리밸런스일 종가, 지연 변형은 다음 거래일 종가. 상장폐지는 마지막 봉 강제 청산.

### 기간
- 학습 2016-06-01~2020-12-31, 확인 2021-01-01~데이터 끝, 전체 2016-06-01~데이터 끝. 비교 기준 POOL·D4·KOSPI는 같은 기간·같은 비용으로 재계산.

### 선택 규칙: 학습만 사용
- 자격(전부): 학습 CAGR > POOL, 학습 CAGR > D4, 학습 MDD ≤ POOL MDD + 3.0%p.
- 자격 있는 변형 중 학습 CAGR÷MDD 최대 1개 선택(동률이면 연 회전율 낮은 쪽). 0개면 확인 계산 없이 "선택 없음" 보고 후 종료.

### 확인 판정: 선택된 1개만
- C1 CAGR > POOL, C2 CAGR > D4, C3 MDD ≤ POOL MDD + 3.0%p, C4 CAGR÷MDD > POOL, C5 +1거래일 지연 시 CAGR 하락 ≤ 1.0%p. 전부 O일 때만 통과 표시. 선택되지 않은 변형은 확인 구간을 계산하지도 보고하지도 않는다.

### 정보용(학습 구간만, 기준 아님)

## 2. 구현 정의 보충 (실행 전에 고정, 사용자 정의를 바꾸지 않는 해석)

1. **데이터 소스·행 선택**: `dart_quarterly_fundamentals`의 status='ok' 행(전 행)과 `stock_annual_fundamentals`(stock_code, fiscal_year, rcept_date, net_income_parent, fs_div)를 REST로 읽는다. 분기 말 = 1분기 `FY-03-31`, 반기 `FY-06-30`, 3분기 `FY-09-30`. 후보 행(분기 레코드)은 위 제외 규칙을 통과한 1~3분기 행 + 파생 4분기 레코드다. 제외 규칙은 행 단위로 먼저 적용하고, 제외된 행은 "가장 최근 분기" 후보에서 빠진다(다음으로 최근 분기를 쓰지는 않고, 남은 후보 중 최근을 쓴다는 뜻이다). 분기 레코드가 쓰이려면 신호별 필요 값이 모두 non-null이어야 하고, 아니면 그 신호는 "데이터 없음"이며 더 오래된 분기로 대체하지 않는다.
2. **"가장 최근 분기" 판정**: 기준일 t에서 rcept_date ≤ t인 후보 중 rcept_date가 가장 큰 레코드(같으면 (회계연도, 분기)가 큰 것). t − rcept_date > 150일이면 "데이터 없음". 4분기 파생 레코드가 가장 최근이면 S_OP는 영업이익이 없으므로 "데이터 없음"이다(더 오래된 3분기로 대체하지 않음). S_NI는 4분기 순이익을 쓴다.
3. **fs_div 규칙**: 1~3분기 행의 당기·전기 값은 같은 응답(같은 fs_div)에서 나오므로 행 단위 불일치는 없다. 불일치 검사는 4분기 파생에만 적용한다: 파생에 쓰이는 `stock_annual_fundamentals`(E)의 fs_div, 같은 FY 3분기 행의 fs_div, `stock_annual_fundamentals`(E−1)의 fs_div가 모두 같아야 한다. 하나라도 다르면 그 4분기 레코드는 만들지 않고 "fs_div 불일치"로 집계한다.
4. **4분기 순이익 파생**: 당기 4분기 ni_parent_q = E.net_income_parent − (같은 FY 3분기 행).ni_parent_cum, 전년 4분기 ni_parent_prev_q = (E−1).net_income_parent − (같은 FY 3분기 행).ni_parent_prev_cum(3분기 행이 보고한 전년 같은 시점 누적). 필요한 값(E, E−1의 net_income_parent, 3분기 행의 cum·prev_cum)이 하나라도 null이거나 해당 3분기 행이 제외·없음이면 파생하지 않는다. 사용 가능일 = E의 `rcept_date`(연간 보고서 접수일, 3분기 행의 rcept_date보다 이른 경우 파생하지 않고 "사용 가능일 역전"으로 집계).
5. **신호 단위**: 기준일 시가총액 = 기준일 t 당일 행의 `market_cap_eok` × 1e8(원). 분기 값은 원 단위. S = (당기 − 전기) ÷ 시가총액(원).
6. **5분위·틸트·선정**: 풀(PIT 적격 상위 100) 안에서 신호가 있는 종목 수를 n이라 하자. 신호 내림차순(동점은 종목코드 오름차순)으로 정렬, k = floor(n / 5). 상위 k개 = "상위 20%", 하위 k개 = "하위 20%". n < 5(k = 0)이면 틸트 없음(= POOL과 같은 비중), Q4는 전량 현금. 틸트 곱: 상위 ×2, 하위 ×0.5, 나머지·데이터 없음 ×1. 비중 = 시총 × 곱 ÷ 합. Q4: 상위 k개를 시총 비례, 종목당 상한 20%(초과분은 나머지에 재분배, 반복), 보유 종목 수 m이 5 미만이면 총 투자 비중 = m × 20%, 나머지 현금. 이 k는 틸트·선정에만 쓰고, 정보용 5분위(아래 12항)는 별도로 정의한다.
7. **엔진·리밸런스**: 지난 연구(`scripts/research-trend-capweight.ts`)와 같은 엔진 규칙: 일별 종가 재평가, 마지막 행이 해당일 이전이며 데이터 끝−14일 이전이면 마지막 종가로 청산(강제 청산), 전체 재조정은 목표 거래금액 기준 총비용 C를 V에서 차감하고 비중을 (V−C)/V배(`simulateD4` 근사), 현금 이자 0, 매수비용률 `computeEffectiveBuyPrice(1)−1`, 매도비용률 `1−computeEffectiveSellPrice(1, 날짜, "KR")`. 월말 = 월 마지막 거래일(마지막 달이 끝나지 않았으면 제외). 첫 리밸런스는 2016-05 월말(마지막 거래일)이고, 수익률은 2016-06-01부터 평가 구간에 들어간다. 초기 진입 비용은 2016-05 월말 일 수익률에 반영되어 평가 구간에서 빠진다(후보·POOL·D4 동일 규칙). Q3의 리밸런스일은 5·8·11월 월말(2016-05 월말 포함)뿐이며 사이에는 거래하지 않는다(강제 청산 제외). 데이터가 없는 신호 때문에 제외되는 일은 없다(풀 안 종목은 모두 보유 대상).
8. **비교 기준**: POOL = 같은 풀 월말 시총 비례 전체 재조정, D4 = PIT 적격 전체 시총 비례 월말 전체 재조정, 둘 다 2016-05 월말부터 새로 시작해(2010년부터 이어진 값을 자르지 않고) 같은 엔진으로 계산한다. KOSPI = 가격지수 일 수익률을 같은 구간으로 자른 값. 후보·POOL·D4의 유니버스 판정은 직전 행 시총 ≥ 5000억 + 당일 행 `avgTv`(직전 20거래일 평균 거래대금) ≥ 5억, 가중·순위의 시총은 리밸런스일 당일 행 `market_cap_eok`.
9. **지표 정의**: CAGR = `computeCagrPct(총수익률, 구간 시작일, 구간 끝일(데이터 끝 또는 실행일 중 이른 날))`, MDD = `computeCumulativeAndMdd`(구간 안에서 100으로 시작), 연변동성 = 일 수익률(%) 표본 표준편차 × √252, 연 회전율 % = 구간 내 체결일별 (매수금액+매도금액)/2/V의 합 ÷ 구간 연수(구간 일수/365.25) × 100, 누적 비용 % = 구간 내 일별 (비용/직전 평가액)의 합 × 100.
10. **단계별 계산**: 4변형의 학습 구간(2016-05 월말~2020-12-31까지의 경로)과 POOL·D4·KOSPI의 학습 수치를 먼저 계산한다. 자격 판정·선택은 이 값만 쓴다. 선택이 있을 때만 선택 변형의 2021년 이후 경로(기본·지연)와 POOL·D4의 확인·전체 경로를 계산하고, 선택되지 않은 변형은 2020-12-31 이후 경로를 계산하지 않는다. 지연 변형(+1거래일): 리밸런스일 d에 계산한 목표 비중을 다음 거래일 종가 가격으로 체결(그날 행이 없는 종목은 제외). C5의 하락 = (확인 구간 기본 CAGR) − (확인 구간 지연 CAGR) ≤ 1.0%p.
11. **기여 상위 5종목**: 선택 변형 전체 구간(2016-06-01~) 일별 종목 기여(그날 종목 평가액 변화 ÷ 전일 포트폴리오 평가액)의 합이 큰 5종목. "제외 시 CAGR" = 일별 수익률에서 그 5종목의 일별 기여(%)를 뺀 계열로 계산한 전체 구간 CAGR(비용은 그대로).
12. **정보용 지표 정의**(학습 구간만, 매월 말 d, 다음 월말까지 d+1월 수익률이 필요하므로 d ≥ 2016-05 월말이고 다음 월말 ≤ 2020-12-31인 달): 풀 = 그날 PIT 적격 상위 100. 다음 달 수익률 = 다음 월말 종가 ÷ d 종가 − 1(두 날 모두 행이 있는 종목만). 월별 스피어만 상관(순위는 평균순위 처리) = 신호가 있는 풀 종목의 신호 순위와 다음 달 수익률 순위의 상관(신호 있는 종목이 5개 미만인 달은 제외). 상관의 월 평균과 t값 = 평균 ÷ (표준편차/√달 수), 신호 있는 종목 비율 = 신호 있는 종목 수 ÷ 풀 크기의 월평균, 5분위: 신호 내림차순으로 i번째(0-기준)를 q = floor(i×5/n)+1 (1 = 최상위)로 나누고 분위별 다음 달 평균 수익률 = 달마다 분위 내 단순평균을 구한 뒤 달에 걸쳐 평균. S_OP와 S_NI 각각 계산한다.
13. **데이터 규칙 적용 결과(f)**: 모든 status='ok' 분기 행(FY2016~2026)을 대상으로 제외 사유를 순서대로 첫 번째만 센다: ① off_cycle=true, ② rcept_date < 분기 말, ③ rcept_date 없음. 4분기 파생 시도 수와 실패 사유(필요 값 null, fs_div 불일치, 3분기 행 없음/제외, 사용 가능일 역전)별 건수. 월평균 신호 보유 종목 수 = 학습 구간 매월 말 풀(상위 100) 중 S_OP, S_NI 신호가 있는 종목 수의 월평균(전체 월말 기준, 변형별 리밸런스일과 무관).
14. **데이터 가용 범위의 한계(미리 공개)**: FY2015 분기 데이터가 없어 2016-05 월말에는 FY2016 1분기 공시만 신호 근거가 된다. 2016년 4분기 파생(전년 4분기 포함)은 FY2015 연간 값을 쓴다.
