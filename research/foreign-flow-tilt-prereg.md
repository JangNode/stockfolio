# 대형주 외국인 수급 3변형 사전등록 (누적 시도 122 → 125, 홀드아웃 실행 시 +1)

승인 범위: 사전등록 커밋 → 백테스트 1회. 재실행 금지. 결과를 본 뒤 정의·기준·변형·선택 규칙 변경 금지. 다음 라운드 자동 시작 금지.
브랜치 claude/ma-v3-portfolio-cap-run (병합 금지). 외부 요청 0건(Storage 다운로드 제외), DB 쓰기 금지, psql 금지. 주가 Parquet은 기존 디스크 캐시 엄격 게이트(17개 연도 파일)를 따름.

## 사용자 문안 (원문)
[데이터]
- 수급: research/investor_flow_stock_clean/(정리본). 주가·시총·폐지: 기존 PIT Parquet(수정주가), 기존 백테스트와 같은 폐지 강제 청산 규칙.
- 비용(주식): 편도 수수료 0.015% + 슬리피지 0.1% + 매도 시 연도별 증권거래세(기존 규칙). 리밸런싱은 비중 변화분만 거래.

[유니버스·신호]
- 매월 마지막 거래일 기준 PIT 시총 상위 100종목(기존 POOL 정의와 동일, 유동성 기준 포함).
- 강도 I_f = 최근 60거래일 외국인 순매수 금액 합 ÷ 그날 시총. I_fo = (외국인 + 기관) 순매수 금액 합 ÷ 시총.
- 60거래일 중 주가가 있는 날이 40일 미만인 종목은 강도 없음 → 중립(틸트 1.0, K2에서는 제외).
- 체결: 월말 신호를 다음 거래일 종가에 체결. 지연 변형은 그다음 거래일 종가.

[변형]
 K1 외국인 틸트: 100종목을 I_f로 3등분, 상위 1/3은 시총 비중 × 1.5, 중간 × 1.0, 하위 × 0.5, 합 1로 정규화.
 K2 외국인 선별: I_f 상위 30종목만 시총가중.
 K3 외국인+기관 틸트: K1과 같되 I_fo 사용.

[기간] 학습 2010-04-01~2016-12-31(첫 신호 2010-03 말), 확인 2017-01-01~2021-12-31, 홀드아웃 2022-01-01~데이터 끝.
 비교: POOL(상위 100 시총가중, 같은 월말 리밸·같은 비용), B&H(069500 보유), 참고로 KOSPI.

[기준: 각 관문 공통]
 G1 CAGR ≥ POOL CAGR + 1.0%p
 G2 CAGR > B&H CAGR
 G3 MDD ≤ POOL MDD + 5.0%p
 G4 지연 시 CAGR 하락 ≤ 1.0%p

[절차] 학습 G1~G4 전부 O인 것 중 (CAGR − POOL CAGR) 최대 1개 선택(없으면 종료) → 확인 → 홀드아웃. X면 그 단계에서 종료. 선택 안 된 변형의 확인·홀드아웃 계산 금지.

[추가 검증, 홀드아웃까지 전부 O일 때만]
 R1 주변 값: 60일을 40일·90일로 바꾼 2개 조합의 전 기간(2010-04~끝) CAGR ≥ POOL 전 기간 CAGR + 1.0%p.
 R2 상위 사건 제거: 전 기간 중 POOL 대비 초과 수익이 가장 큰 1개월을 POOL 수익으로 바꿔도 전 기간 CAGR ≥ POOL + 1.0%p.
 R3 무작위 비교: 매월 같은 3등분 크기(K2면 같은 30개)로 종목을 무작위 배정해 1,000회(시드 20261020), 전략의 전 기간 CAGR이 상위 5% 안.
 최종 통과 = 세 관문 + R1~R3 전부 O.

[정보용, 학습 구간만]
 월말 I_f, I_fo 순위와 다음 달 종목 수익률 순위의 상관(월별 순위상관) 평균, 표준편차, t값, 양수인 달 비율. 3등분별 다음 달 평균 수익(상·중·하).

[보고] 숫자와 표만, 판정·추천 문장 금지.
 (a) 사전등록 해시와 순서
 (b) 학습 표: K1~K3, POOL, B&H, KOSPI의 CAGR / MDD / 샤프 / 연변동성 / 월평균 회전율 / 누적 비용 / 평균 보유 종목 수 / 지연 CAGR, G1~G4 O/X
 (c) 정보용 표
 (d) 선택 결과
 (e) 계산한 단계의 표·G1~G4·연도별 수익률(전략, POOL, B&H)
 (f) (해당 시) R1~R3 숫자와 O/X
 (g) 읽은 행·다운로드 크기·[parquet-cache] 줄, 쓴 행(0), 소요 시간

## 구현 세부 (결과를 보기 전에 고정하는 해석 — 사용자 문안에 없는 부분)
1. **엔진·유니버스**: research/quarterly-tilt-prereg.md 구현 세부 7·8과 같은 엔진(scripts/research-quarterly-tilt.ts): 수정주가(`loadAllStockSeriesFromParquet` + 적용된 분할·병합 조정), 일별 종가 재평가, PIT 적격 = 직전 행 시총 ≥ 5,000억 + 당일 행 직전 20거래일 평균 거래대금 ≥ 5억, 풀 = 적격 종목 중 신호일 당일 행 시총 상위 100(동점 코드 오름차순), 폐지 강제 청산(마지막 행이 데이터 끝−14일 이전이고 해당일 이전이면 마지막 종가로 청산, 매도 비용 적용), 현금 이자 0, 매수 비용률 `computeEffectiveBuyPrice(1)−1`, 매도 비용률 `1−computeEffectiveSellPrice(1, 체결일, "KR")`(수수료·슬리피지·연도별 거래세는 lib/transactionCostConfig.ts). 데이터 로드는 2010년부터(`STOCK_DATA_EARLIEST_YEAR`).
2. **달력·신호일·체결일**: 달력 CAL = 2010-01-01 이후 전 종목 거래일의 합집합. 월말 = 다음 CAL 거래일의 연월이 달라지는 날(마지막 달이 끝나지 않았으면 제외). 신호일 d = 2010-03 월말부터 모든 월말. 체결일 e = d 다음 CAL 거래일(지연 변형은 그다음 CAL 거래일). 목표 비중은 d 기준으로 계산해 e 종가에 체결한다(체결일에 행이 없는 종목은 목표에서 빼고 남는 비중은 현금, 재정규화 없음). 비중 변화분만 거래(목표에 없는 보유는 전량 매도, 비용 = 매수금액×매수율 + 매도금액×매도율을 체결일 가치에서 차감).
3. **평가 구간**: 단일 연속 경로(첫 체결일 = 2010-03 월말의 다음 거래일 종가에 초기 진입)에서 창을 잘라 쓴다. 초기 진입 비용이 반영되는 첫 체결일의 일 수익률은 어느 창에도 넣지 않는다(창은 그다음 거래일부터, CAGR 기간의 시작일은 창 정의의 시작일). 학습 2010-04-01~2016-12-31, 확인 2017-01-01~2021-12-31, 홀드아웃 2022-01-01~달력 마지막 거래일, 전 기간 2010-04-01~달력 마지막 거래일. CAGR의 종료일은 창 종료일과 달력 마지막 거래일 중 이른 날. POOL·후보는 같은 경로 규칙(같은 체결일·같은 비용)이며, 선택되지 않은 변형의 확인·홀드아웃 구간은 계산하지도 보고하지도 않는다(단일 경로 계산 자체는 학습 끝일 이후까지 진행하지 않고, 확인·홀드아웃 구간은 선택된 변형만 새로 계산).
4. **강도**: 신호일 d의 CAL 인덱스를 c라 하면 창 = CAL[c−N+1..c](N = 60, R1에서 40·90). c−N+1 < 0이면 모든 종목 강도 없음. 주가가 있는 날 = 창 안에서 그 종목 행이 있고 종가 > 0인 날. 주가 있는 날 수 < ceil(N×2/3)(N=60이면 40, 40이면 27, 90이면 60)이면 강도 없음. 수급 정리본에 그 종목이 아예 없으면 강도 없음. 그 외: I_f = 창 안 외국인 순매수 금액(frgn_ntby_amt, 정리본 행이 없거나 값이 비면 그날은 0) 합 ÷ d 당일 행 시총(market_cap_eok 값 그대로, 모든 종목에 같은 단위 상수라 순위·3등분에 영향 없음), I_fo는 (외국인 + 기관 orgn_ntby_amt) 합 ÷ 같은 시총. 강도 없음 종목은 K1·K3에서 곱 1.0, K2에서 제외, 3등분 순위 계산에서도 제외.
5. **3등분·틸트·선별**: 강도 있는 종목 n개를 강도 내림차순(동점은 종목코드 오름차순)으로 정렬해 i번째(0-기준)의 그룹 = floor(i×3/n) (0 = 상위, 1 = 중간, 2 = 하위; n = 100이면 34·33·33). K1·K3 곱 = 상위 1.5 / 중간 1.0 / 하위 0.5, 강도 없음 1.0. 비중 = 시총 × 곱 ÷ 합. n = 0이면 POOL과 같은 비중. K2 = 강도 있는 종목 중 상위 min(30, n)개를 시총가중(종목 상한 없음), n = 0이면 전액 현금. POOL = 풀 100종목 시총가중.
6. **B&H·KOSPI**: B&H = etf_daily_prices.adj_close 069500을 첫 체결일 종가에 매수해 보유(비용 없음, 창에서 진입일 제외). 069500의 하루짜리 튐 정제는 research/etf-allocation-prereg.md(e0219298) 규칙(KOSPI 면제 포함)과 같다. KOSPI = DB 지수 종가 일 수익률.
7. **지표**: CAGR = `computeCagrPct(총수익률, 창 시작일, 창 종료일)`, MDD = `computeCumulativeAndMdd`, 연변동성 = 일 수익률 % 표본표준편차×√252, 샤프 = 일 수익률 % 평균×252 ÷ (표본표준편차×√252)(무위험 0), 월평균 회전율 % = 창 안 체결일별 (매수금액+매도금액)/2/체결 직전 가치의 합 ÷ (창 연수×12) ×100, 누적 비용 % = 창 안 일별 (비용/직전 가치) 합 ×100, 평균 보유 종목 수 = 창 안 매 거래일 종가 후 보유 종목 수의 평균. 지연 CAGR = 같은 변형의 지연 경로의 같은 창 CAGR, G4의 하락 = 기본 CAGR − 지연 CAGR. 관문 G1~G4는 같은 창의 POOL·B&H·MDD와 비교한다.
8. **선택**: 학습에서 G1~G4 전부 O인 변형 중 (CAGR − POOL CAGR) 최대 1개, 동률이면 월평균 회전율이 낮은 쪽. 0개면 확인 계산 없이 종료.
9. **정보용**(학습 구간만): 월말 d가 첫 신호일 이상이고 다음 월말 d′ ≤ 2016-12-31인 모든 달. 풀 종목 중 강도가 있고 d·d′ 모두 행이 있는 종목 쌍(강도, d 종가→d′ 종가 수익률)이 5개 이상인 달에서 평균순위(동점 평균) 스피어만 상관. 상관의 월 평균, 월 표준편차(n−1), t = 평균 ÷ (표준편차/√월 수), 양수인 달 비율을 I_f·I_fo 각각 보고. 3등분별 다음 달 평균 수익 = 달마다 그룹 내 단순평균(그룹 정의 5항, 행 있는 종목만)을 구해 달에 걸쳐 평균(%).
10. **추가 검증**(홀드아웃까지 G1~G4 전부 O일 때만 계산, 선택 변형만): 전 기간 = 3항의 전 기간. R1: N = 40, 90으로 바꾼 두 조합(4항 규칙, 나머지 동일)의 기본 경로 전 기간 CAGR이 둘 다 ≥ POOL 전 기간 CAGR + 1.0%p면 O. R2: 달력 월(YYYY-MM)별 수익률 = 그 달 일 수익률(전 기간 창 안)의 복리, 월 초과 수익 = 전략 월 수익률 − POOL 월 수익률(%p). 초과가 가장 큰 1개월의 일 수익률 전체를 같은 날 POOL 일 수익률로 바꾼 계열의 전 기간 CAGR ≥ POOL 전 기간 CAGR + 1.0%p면 O. R3: 신호일마다 실제 전략과 같은 강도 있는 종목 집합에서 실제와 같은 그룹 크기(5항의 floor(i×3/n) 크기, K2는 min(30,n)개)로 무작위 배정(Fisher–Yates, rng = mulberry32, 시드 20261020, 1,000회, 신호일 순서대로 같은 난수열을 이어 씀)해 같은 엔진으로 전 기간 경로를 계산, 무작위 CAGR이 실제 전략 CAGR 이상인 횟수 ÷ 1,000 ≤ 5%면 O. 최종 통과 = 홀드아웃까지 G1~G4 전부 O + R1~R3 전부 O.
11. **보고 추가 항목(참고 수치)**: 첫 신호일에 강도가 있는 풀 종목 수, 월평균 풀 종목 중 강도 있는 종목 수(정보용 달 기준)와 수급 정리본에 없는 풀 종목 수(월평균).
12. 상수는 lib/foreignFlowTiltConfig.ts(및 lib/investorFlowConfig.ts, lib/strategyBacktestSummaryConfig.ts, lib/etfAllocationConfig.ts, lib/seasonalityConfig.ts)에 둔다.
