## 0. 공통 정의

### 0.1 유니버스 "K200P"
묶음 1~3과 같다. 월말 시장 구분(PIT)에서 판단일 직전 월말 스냅샷의 **코스피** 종목 중 제외 규칙(우선주·ETF·스팩·리츠, 커밋 `4c1557a`)을 적용하고, 판단일 시총 내림차순으로 정렬한 **상위 200종목**이다(거래대금 하한 없음). 같은 시총이면 종목코드 순. 후보는 판단일 c에 그 종목의 행이 있고 거래량 > 0인 종목만이다.

### 0.2 실행 엔진
- 묶음 1~3과 같은 슬롯 시뮬레이터 `lib/slotSim.ts`(수정 없음). 판단일 c 종가의 정보만 쓰고 **체결은 다음 거래일 종가**(c+1)다. 슬롯 수 = 2k(k = 업종당 종목 수, 기본 3 → **6슬롯 × 계좌의 1/6씩 동일 비중**), 슬롯이 남으면 현금이다. 이미 보유한 종목은 다시 사지 않고, 슬롯이 부족하면(다른 사건의 포지션이 남아 있을 때) 시총 순위 앞선 종목부터 채운다(대기열 없음).
- 비용: 수수료 0.015%/편도 + 매도 증권거래세(시기별) + 슬리피지 0.1%/편도(`lib/transactionCostConfig.ts`, `L_SLIPPAGE`). 체결일 거래량 0이면 진입 후보는 건너뛰고 청산은 다음 거래일로 순연, 상장폐지는 마지막 가격으로 청산한다. 수익률은 수정주가 기준.
- 평가 시작: 초기 2011-01-03 종가 기준으로 시작하고 수익 집계는 **2011-01-04 ~ 2026-10-26** 연속. 판단에 필요한 과거 이력(2010~)은 평가 시작 전에도 쓴다. 이력이 모자라 매크로 변화를 만들 수 없는 날은 신호 없음(현금)이다.
- 청산: **체결일부터 hold 거래일째 종가**(기본 20)에 체결(판단일 c ≥ 체결일 + hold − lag, 거래정지면 순연). 다른 청산 규칙은 없다(손절·익절 없음).

### 0.3 매크로 정렬·신호 정의 (모든 가설 공통, 판단일 c 종가 시점 이전 정보만)
- **저장 자료**: Storage `research/macro_daily/macro_daily.parquet`(긴 형식: series_id, obs_date, value(결측 가능), source; 2010-01-01~, 매니페스트 SHA-256 대조). 이번 묶음에서 추가 호출·수집은 없다. 시리즈: M1 `USDKRW_ECOS`(ECOS 731Y001 매매기준율, FRED 환율이 아님), M2 `WTI`(FRED DCOILWTICO), M3 `KTB10Y`(ECOS 817Y002 국고채 10년). 브렌트·FRED 환율·나스닥·국고채 3년은 이번 시험에 쓰지 않는다.
- **한국 거래일 맞추기(전진 채움)**: 한국 거래일 k의 값 x[k] = `obs_date ≤ CAL[k]`인 최신 비결측 관측값(없으면 결측). 판단일 c의 신호에는 **직전 한국 거래일(c−1)까지의 x**만 쓴다(`x[c−1]`은 obs_date ≤ CAL[c−1]인 값). 당일(c) 날짜의 관측값은 쓰지 않는다. 시차가 있는 FRED 현물가나 ECOS의 고시 시각 불확실성을 이 규칙이 모두 덮는다(보수적).
- **20거래일 변화**: 변화율(M1·M2) = x[c−1] ÷ x[c−21] − 1, 차이(M3, %p) = x[c−1] − x[c−21]. 두 값 중 하나라도 결측이거나(M1·M2는 ≤ 0이어도) 조건은 거짓이다(WTI는 2020-04-20 음수 가격이 있어 비율이 무의미해진다. 이 규칙은 결과를 보기 전에 고정).
- **조건 cond(c)**: M1 변화율 ≥ +thr%(기본 3), M2 상승 변화율 ≥ +thr% / 하락 변화율 ≤ −thr%(기본 10), M3 차이 ≥ +thr %p(기본 0.20). 모두 비엄격 부등호.
- **진입 사건(edge)**: cond(c)가 참이고 cond(c−1)이 거짓일 때만 판단일 c에 신호가 난다(첫 성립일). 조건이 계속 참인 동안에는 새 신호가 없고, **보유가 끝난 뒤 다시 진입하려면 조건이 거짓이 되었다가 다시 참이 되어야 한다**("조건을 다시 충족할 때만 재진입"의 해석, 결과를 보기 전에 고정). 전일 cond(c−1)이 결측으로 거짓이면 edge로 센다.
- **업종 선택**: 업종 코드 = `stock_industry_classification.induty_code`(DART 기업개황의 KSIC 업종 코드, **종목별 현재 값 하나**), 앞 2자리가 대상 접두사와 같은 종목. 코드가 없는 종목은 어떤 업종에도 속하지 않는다. 판단일 c의 K200P(시총 순, 행 있고 거래량 > 0) 중 업종별 시총 상위 k종목(같은 시총이면 종목코드 순)을 후보로 하고, 후보가 여러 업종이면 시총 순위가 앞선 순으로 우선순위를 준다. 업종 안 종목이 k개보다 적으면 있는 만큼만 산다.
- **업종 매핑**: M1 26(전자부품·컴퓨터·영상·음향·통신장비 제조), 30(자동차·트레일러 제조) / M2 상승 19(코크스·연탄·석유정제품), 20(화학물질·화학제품) 하락 51(항공 운송업) / M3 64(금융업), 65(보험·연금업). 한계: 현재 코드를 과거에도 적용하므로 과거 업종 이동·분할·합병 종목은 부정확하고, 지주회사(예: 64 분류 지주)·복합기업은 실제 사업과 다를 수 있다.

### 0.4 평가·게이트 (묶음 1~3과 같은 정의, 구현 `scripts/researchGates.ts`)
- 기준선: 069500 원주가(가격 수익만, 보조 파일), 시작일 2011-01-04 (CAGR 7.42 / MDD 42.03). 구간 3개: **2011-01-04~2016-12-29 / 2017-04-04~2021-12-31 / 2022-01~2026-10-26**.
- A 연속 전체에서 069500 대비 CAGR **+2%p 이상** ∧ MDD가 069500과 같거나 작음. B 세 구간 중 **2개 이상**에서 069500보다 CAGR이 높고 MDD가 더 크지 않음. C 하루 지연(진입·청산 체결을 모두 +1거래일, lag 2)에서 연속 전체 CAGR 하락 ≤ 1%p ∧ MDD 악화 ≤ 2%p. D 이웃값 모두 연속 전체 CAGR ≥ 069500 CAGR(하나라도 미만이면 탈락). E 손익 상위 3개 거래를 069500 수익률로 대체해도 연속 전체 CAGR ≥ 069500. F 무작위 진입 백분위 ≥ 95. G 진입 건수 ≥ 100(`researchGates`의 기준). ## 사용자 문안에서 해석을 정한 곳 (결과를 보기 전에 고정)
1. **"20거래일 변화"**: x[c−1] ÷ x[c−21] − 1 (M3은 차이). 직전 한국 거래일 기준 값과 그보다 20거래일 앞선 값의 비교다(변화 구간 끝이 c−1이므로 당일 값은 쓰지 않는다).
2. **"조건을 다시 충족할 때만 재진입"**: edge(거짓 → 참 전환)로만 신호가 난다. 보유 중 새 edge가 나도 슬롯이 없으면 진입하지 않고(대기열 없음), 같은 종목은 사지 않는다.
3. **"동일 비중"**: 슬롯 1개 = 계좌의 1/(2k). 업종 종목 수가 모자라거나 한 업종만 해당하면 남는 슬롯은 현금이다(다른 종목으로 채우지 않는다).
4. **M2 두 규칙**: 상승·하락 edge가 같은 날 겹칠 수 없다(변화율 부호). 상승 사건의 포지션(최대 6)과 하락 사건(최대 3)이 겹치면 슬롯 6개 한도 안에서만 보유한다(동시 보유 허용 = 한도 안에서 겹침 허용).
5. **K200P 후보와 시총**: 판단일 c 시총(원 종가 기준 `mcapRow`)으로 순위를 매긴다. 같은 시총이면 종목코드 순. 업종 안 순위는 K200P 안에서의 시총 순위다(K200P 밖 종목은 후보가 아니다).
6. **매크로 결측**: FRED 결측(휴일 `.`)은 값 없음(null)으로 저장되어 있고 전진 채움이 직전 비결측 값을 이어 쓴다. 전진 채움이 7달력일 넘게 같은 값을 이어 쓴 날 수는 사전 점검에서 보고만 한다(규칙 변경 없음).
7. **WTI 음수 가격(2020-04)**: x[c−1] ≤ 0 또는 x[c−21] ≤ 0이면 cond 거짓(변화율이 무의미).
8. **업종 코드 없는 종목**: 어떤 업종에도 속하지 않는다(제외 규칙의 일부가 아님).

## 1. M1 (291): 원/달러 급등 → 반도체·자동차 대형주
- **신호(판단일 c 종가)**: USDKRW_ECOS 20거래일 변화율 ≥ +3% 가 새로 성립(edge).
- **후보**: K200P 중 KSIC 26 시총 상위 3 + KSIC 30 시총 상위 3(최대 6).
- **진입**: 다음 거래일 종가, 슬롯 6 × 1/6. **청산**: 체결일부터 20거래일째 종가.
- **D 이웃(6개)**: 문턱 +2%, +4% / 보유 10, 40거래일 / 업종당 2, 5종목.
- **구조적 주의**: 원화 약세는 위험회피 국면(2011, 2015~16, 2020, 2022, 2024~25)과 겹쳐 시장 전체가 같이 빠지는 시기에 진입하게 된다. 26 업종은 삼성전자·SK하이닉스, 30 업종은 현대차·기아가 K200P 상위를 차지해 사실상 4~6개 종목 시험이다.

## 2. M2 (292): 유가 급변 → 정유·화학(상승) / 항공(하락)
- **신호**: WTI 20거래일 변화율 ≥ +10% 새로 성립(상승 사건) 또는 ≤ −10% 새로 성립(하락 사건).
- **후보**: 상승 사건 = K200P 중 KSIC 19·20 각 시총 상위 3(최대 6), 하락 사건 = K200P 중 KSIC 51 시총 상위 3(최대 3, K200P 안 항공 종목이 3개보다 적으면 있는 만큼).
- **진입·청산**: M1과 같음(슬롯 6 × 1/6, 20거래일).
- **D 이웃(6개)**: 문턱 ±7%, ±13%(상승·하락 같은 값) / 보유 10, 40거래일 / 업종당 2, 5종목.
- **구조적 주의**: 항공(51)은 K200P 안 종목이 매우 적다(대한항공 중심). 2020-04 음수 가격 구간은 cond 거짓으로 처리한다. 유가 급락은 위험회피·수요 충격과 함께 올 수 있어 항공의 "저유가 수혜"와 충돌할 수 있다.

## 3. M3 (293): 국고채 10년 금리 급등 → 은행·보험
- **신호**: KTB10Y 20거래일 차이 ≥ +0.20%p 새로 성립(edge).
- **후보**: K200P 중 KSIC 64·65 각 시총 상위 3(최대 6). 64에는 지주회사(금융지주)와 증권사·카드사 등이 섞인다(현재 코드 기준).
- **진입·청산**: M1과 같음.
- **D 이웃(6개)**: 문턱 +0.15, +0.25%p / 보유 10, 40거래일 / 업종당 2, 5종목.
- **구조적 주의**: 금리 20일 +0.20%p는 2011~2020년에는 드물고 2021~2022년에 몰릴 수 있어 사건 수가 적을 수 있다. 진입 건수가 G(≥ 100)에 못 미치면 G 탈락으로 판정하고 변형을 만들지 않는다.

## 4. 사전 점검 계획 (성과 계산·출력 없음)
1. **신호 독립 대조**: 매크로 조건과 업종 선택을 원자료(Parquet 행, 직전 거래일까지의 관측만 허용해 판단일마다 다시 계산하는 브루트포스)로 만든 것과 모듈 값을 모든 판단일·기본·이웃 설정에서 비교한다(불일치 = 구현 결함 → 중단). 이 대조는 미래 정보 점검(판단일 c의 신호가 obs_date > CAL[c−1] 관측에 의존하지 않음)을 겸한다.
2. **체결·청산 타이밍**: 진입 = 신호일 + lag, 청산 = 체결일 + hold(거래정지 순연 제외), 조건 성립 일치(lag 1·2).
3. **업종 매핑 범위**: K200P 안 업종 코드 없는 종목 수, 대상 업종별 종목 수(연말 기준), 진입 사건 수(기본·이웃)와 하루 후보 수 분포.
4. 구조 통계(사건 수, 사건 간격, 전진 채움 7일 초과 날 수). 성과는 계산·출력하지 않는다.

## 정정 기록 (문서 오기, 정의·기준 변경 아님; M1 시험 후 발견, 2026-11-15)
0.4절의 H 기준 문구 "CAGR +2%p 또는 (MDD 개선 5%p ∧ CAGR ≥ −1%p)"는 옮겨 적은 수치가 틀렸다. 게이트 H는 묶음 1~3과 **같은 상수**(`lib/peadConfig.ts`: `PEAD_H_CAGR_GAIN_PP = 1`, `PEAD_H_MDD_GAIN_PP = 3`, `PEAD_H_MDD_GAIN_STRONG_PP = 5`(참고 표시), `PEAD_H_CAGR_FLOOR_PP = 1`)를 쓰며 코드는 처음부터 이 상수를 썼다 — 즉 **H = 069500 대비 CAGR +1%p 이상, 또는 (MDD 개선 3%p 이상 ∧ CAGR ≥ −1%p)**. 시험 코드·게이트·결과는 바뀌지 않았다(오기는 문서에만 있었다). 이 정정은 M1 결과(H 탈락, CAGR −4.60%p로 어느 문구로도 같은 판정)를 본 뒤에 했지만 판정에 영향이 없고, 사전 점검·M2·M3 코드는 그대로이다.
