# 중형주 저변동성·영업이익 전략 3변형 사전등록 (누적 시도 129 → 132, 0단계에서 빠지는 변형은 제외, 홀드아웃 실행 시 +1)

승인 범위: 0단계 재측정 → 사전등록 커밋 → 백테스트 1회. 재실행 금지. 결과를 본 뒤 정의·기준·변형·선택 규칙 변경 금지. 다음 라운드 자동 시작 금지.
브랜치 claude/ma-v3-portfolio-cap-run (정렬 수정 a996586 이후, 병합 금지). 외부 요청 0건, DB 쓰기 0, psql 금지. 주가 Parquet은 기존 디스크 캐시 엄격 게이트(17개 연도 파일)를 따름.
시도 번호: N1 = 130, N2 = 131, N3 = 132 (0단계 게이트를 통과하지 못하면 N2·N3는 시도에서 제외), 홀드아웃 실행 시 +1.

## 기록: 수집 대상 편향 (a996586 점검)
SMALL 재무 신호와 M3는 수집 대상 미래 정보 편향으로 무효(a996586). MID 구성원은 신호일에 이미 PIT 유니버스 구성원이라 이 편향 없음.
(근거: dart_quarterly_fundamentals·dart_xbrl_fundamentals 수집 대상은 "2010-01 이후 월말에 한 번이라도 직전 행 시총 5,000억 이상 + 20일 평균 거래대금 5억 이상이었던 종목" — scripts/backfill-dart-quarterly-fundamentals.ts의 `entered` 집합. 신호일 d의 MID 구성원은 d에 이미 그 조건을 만족하므로 수집 대상에 속한다. 이 조회 코드는 정렬 수정(a996586)을 적용한 상태로 실행한다.)

## 구현 세부 (결과를 보기 전에 고정하는 해석 — 사용자 문안에 없는 부분)
1. **한 번의 실행으로 처리**: 0단계 재측정과 백테스트를 같은 스크립트·같은 실행(워크플로 1회 dispatch)에서 순서대로 수행한다. 게이트 판정은 스크립트가 아래 규칙대로 자동 적용하며, 재실행하지 않는다. 보고서에서 0단계 표를 먼저 보고한다.
2. **엔진·달력·지표·비교 기준·단계**: research/smallcap-lowvol-prereg.md(3a41f17d) 구현 세부 1(엔진: 수정주가, 폐지 강제 청산, 체결일에 행 없는 종목은 목표에서 빼고 현금, 비중 변화분만 거래·비용 일괄 차감), 3(VOL: 창 60일, 주가 있는 날 ≥ ceil(N×2/3), 연속한 두 거래일 수익률의 표본표준편차), 4(SOP: dart_quarterly_fundamentals status='ok', off_cycle=false, 1~3분기, rcept_date ≥ 분기말, rcept_date ≤ d이고 d − rcept_date ≤ 150일인 가장 최근 분기 행, SOP = (op_income_q − op_income_prev_q) ÷ |op_income_prev_q|, 둘 다 non-null이고 prev ≠ 0일 때만), 5(신호일 3·6·9·12월 마지막 거래일, 2010-03-31 이상, 체결일 = 다음 CAL 거래일, 지연 = 그다음 거래일, 첫 체결일 일 수익률 제외), 7(지표: CAGR `computeCagrPct`, MDD `computeCumulativeAndMdd`, 연변동성, 샤프, 분기 평균 회전율, 누적 비용, 평균 보유 종목, 20일 평균 거래대금 중앙값, 폐지 청산 건수, 지연 CAGR), 8(B&H = 069500 adj_close·정제 규칙, KOSPI·KOSDAQ = DB 지수), 9(단계: 학습에서 N변형과 MEW를 학습 끝까지 계산, 선택은 학습 값만 사용, 선택 변형만 데이터 끝까지 계산)와 같다. 다른 점은 아래뿐이다: 유니버스(MID), 비용(슬리피지 0.1%), 변형(N1~N3)과 비교 기준 이름(SEW → MEW), 선택 동률 처리(아래 6항).
3. **유니버스 MID(d)**: research/signal-scan-smallmid-prereg.md(fcc2f16f) 구현 세부 2와 같다 — ELIG(d) = d에 행이 있고 i ≥ 1, 직전 행 시총 ≥ 5,000억, d 당일 행 직전 20거래일 평균 거래대금 ≥ 5억(`computeTrailingAvgTradingValue`, 수정주가 기준). MID = ELIG를 d 당일 행 시총 내림차순(동점 코드 오름차순)으로 정렬한 101번째부터 끝까지. MEW = MID(d) 전부(VOL·SOP 유무 무관) 동일가중.
4. **비용**: 매수 = `computeEffectiveBuyPrice(1) − 1`, 매도 = `1 − computeEffectiveSellPrice(1, 체결일, "KR")` (슬리피지 0.1% + 수수료 0.015% + 연도별 거래세, lib/transactionCostConfig.ts). 스캔 2회차 MID 비용과 동일.
5. **0단계**: 스캔 2회차 MID 행의 정의를 그대로 쓴다 — 월간 표본일(2010-04-01 이후 월 마지막 거래일), 예측 기간 H = 21·63 거래일(신호일 다음 거래일 종가 진입, H 거래일 뒤 종가 청산, 청산일이 2016-12-31 이내인 표본일만), 표본일별 평균순위 스피어만, 신호·수익률이 모두 있는 종목이 20개 이상인 표본일만 사용, Newey-West t(시차 = max(1, round(H ÷ 21))), 방향 = 순위상관 평균의 부호, 3등분 floor(i×3/n)·동점 코드 오름차순, 순차이 = 방향 × (상위−하위) − 교체 비용(교체 비용 = (상위 교체 비율 + 하위 교체 비율) × (매수율 + 매도율), 표본일 d와 d′ = CAL[c+H]의 구성 비교), 신호값은 스캔의 VOL(−1 × 60일 일수익률 표준편차, 연속 거래일 쌍 수익률 40개 미만 제외)과 SOP(위 SOP 정의, 클수록 좋음). 계산은 2016-12-31 이후 데이터를 쓰지 않는다. 대상 행은 MID × {SOP 월21, SOP 월63, VOL 월63} 3개뿐이다.
   - **게이트**: SOP 월21 행과 SOP 월63 행이 둘 다 (|t| ≥ 3.0 그리고 방향 반영 순차이 > 0)이면 N1·N2·N3를 실행, 아니면 N1만 실행. 후보 표시와 같은 조건이며 방향(순위상관 평균의 부호)은 별도로 보고할 뿐 게이트 조건에 추가하지 않는다. VOL 월63 행은 보고만 하고 게이트에 쓰지 않는다. N1은 게이트와 무관하게 실행한다.
6. **추가 확인(진입 여부·보유율)**: 학습 구간 분기 신호일(2010-03-31~2016-12 마지막 거래일 28개 이내)마다 MID 구성원 수, "이미 진입" 수, "이후 진입" 수, 분기 데이터 보유 수와 %(신선도 150일 이내인 분기 행이 있음), SOP 계산 가능 수와 %를 표로 보이고 평균 행을 둔다. "이미 진입" = 종목의 최초 PIT 진입 월말(2010-01 이후 월 마지막 거래일 중 i ≥ 1, 직전 행 시총 ≥ 5,000억, 당일 20일 평균 거래대금 ≥ 5억인 첫 날; scripts/backfill-dart-quarterly-fundamentals.ts의 `entered` 규칙과 같은 정의)이 신호일 d 이하. 신호일은 모두 월 마지막 거래일이므로 이 정의로는 정의상 전부 "이미 진입"이 되며, 그 계산 결과를 그대로 보고한다.
7. **변형별 선정**(신호일 d, MID(d)에서):
   - N1: VOL이 있는 종목 n개를 VOL 오름차순(동점 코드 오름차순)으로 정렬해 floor(i×3/n) = 0인 종목(앞쪽 ceil(n/3)개).
   - N2: SOP가 있는 종목 m개를 SOP 내림차순(동점 코드 오름차순)으로 정렬해 floor(j×3/m) = 0인 종목(앞쪽 ceil(m/3)개). VOL 유무와 무관. m = 0이면 그 분기는 선정 0개(전액 현금). N1 대체·최소 종목 수 규정은 없다.
   - N3: (VOL이 있는 MID 종목 n개를 VOL 오름차순 정렬한 앞쪽 ceil(n/2)개) ∩ (SOP가 있는 MID 종목 m개를 SOP 내림차순 정렬한 앞쪽 ceil(m/2)개). 두 집합은 각각 MID 전체에서 독립적으로 정하고 교집합을 취한다(사용자 문안의 "∩" 해석; 3a41f17d의 M3처럼 VOL 하위 1/2 안에서 SOP 순위를 다시 매기는 방식이 아니다). 교집합이 30종목 미만이면 그 분기는 N1 선정으로 대체하고, 대체 횟수(그 변형이 계산한 신호일 중 대체된 신호일 수 / 전체 신호일 수)를 창별로 보고한다.
   - 선정 종목은 동일가중(1/개수).
8. **선택·진행**: 학습 창에서 실행 변형들과 MEW를 학습 끝까지 같은 경로 규칙으로 계산한다. G1~G4 전부 O인 변형 중 (CAGR − MEW CAGR) 최대 1개를 선택한다. 동률이면 분기 평균 회전율이 낮은 쪽, 그래도 같으면 N1 < N2 < N3 순. 선택이 없으면 확인을 계산하지 않고 종료한다. 선택이 있으면 선택 변형·MEW·지연 변형을 데이터 끝까지 계산해 확인·홀드아웃 창으로 자른다. 선택되지 않은 변형은 2016-12-31 이후 경로를 계산하지 않는다.
9. **추가 검증**(홀드아웃까지 G1~G4 전부 O일 때만, 선택 변형만, 전 기간 = 2010-04-01~데이터 끝): R1 = VOL 창 40일, 90일, 분기 대신 매월 리밸런싱(월말 모두 신호일, VOL 창 60일)의 기본 경로 전 기간 CAGR이 셋 다 ≥ MEW(분기 리밸 MEW) 전 기간 CAGR + 2.0%p이면 O(선택이 N2이면 VOL 창 변경은 선정에 영향이 없어 세 값 중 두 값이 기본과 같다). R2 = 달력 분기(YYYY-Q)별 수익률(그 분기 일 수익률 복리)의 전략 − MEW(%p)가 가장 큰 1개 분기의 일 수익률 전부를 같은 날 MEW 일 수익률로 바꾼 계열의 전 기간 CAGR ≥ MEW 전 기간 CAGR + 2.0%p이면 O. R3 = 각 신호일마다 실제 전략의 선정 종목 수(N3의 N1 대체 분기는 대체된 선정 수)와 같은 수를 비복원 무작위로 뽑아(Fisher–Yates 부분 셔플, mulberry32, 시드 20261020, 1,000회, 신호일 순서대로 같은 난수열) 동일가중으로 같은 엔진·비용의 전 기간 경로를 계산한다. (a) 풀 = MID(d) 전체, (b) 선택 변형이 N2·N3일 때만 풀 = MID(d) 중 SOP가 있는 종목(뽑는 수는 min(선정 수, 풀 크기)). 전략 전 기간 CAGR 이상인 무작위 경로 수 ÷ 1,000 ≤ 5%이면 O, (a)(b) 둘 다 O여야 R3 = O. 최종 통과 = 홀드아웃까지 G1~G4 전부 O + R1~R3 전부 O.
10. 상수는 lib/midcapLowvolSopConfig.ts(및 lib/signalScanConfig.ts, lib/smallcapLowvolConfig.ts)에 둔다.
