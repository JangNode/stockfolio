## 0단계 사전 확인 (기존 시험과의 관계)

- **KOSDAQ 포함 유니버스로 터틀(M3·K3 계열)을 돌린 기존 시험은 저장소(docs/research, research, scripts)에 없다.** M·N 연구까지의 터틀 계열(F~N)은 모두 K200P(월말 KOSPI 목록 ∩ 유동성·제외 규칙 ∩ 시총 상위 200)를 썼다. 따라서 Q1~Q3은 재계수 대상이 아니며 새 시험으로 센다(195~197).
- KOSDAQ를 포함한 기존 연구는 돌파·터틀 계열이 아니다(참고만, 재실행하지 않음): research/smallcap-lowvol-prereg.md(소형주 저변동성·영업이익 M1~M3, 분기 리밸), research/midcap-lowvol-sop-prereg.md(중형주 N1~N3, 분기 리밸), research/sector-mom-tilt-v2_1-prereg.md(전 시장 시총 상위 100 업종 모멘텀 틸트, 월간). 이름이 같은 "M3"(소형주 저변동성·영업이익)는 이번 M3(터틀 시스템2 + NH > 0)와 다른 전략이다.
- **데이터 가용성(코드로 확인한 사실)**: (1) 월말 시장 구분 목록(research/market_membership/month_end.parquet, 2010-01~)은 KOSPI와 KOSDAQ를 모두 담는다(scripts/collect-market-membership.ts). 신호일 d의 시장 = d 이하 최신 월말 목록의 값(M 연구까지와 같은 규칙). (2) 가격 Parquet은 KRX 일별매매정보(stk_bydd_trd KOSPI + ksq_bydd_trd KOSDAQ)를 합쳐 저장해 시총(marketCapEok, 억원)·거래량·거래대금이 두 시장 모두 일별로 있다(scripts/backfill-stock-daily-prices.ts). 20일 평균 거래대금은 종목 자신의 가격 행으로 PIT 계산한다. (3) 업종 분류는 DB 표 stock_industry_classification의 KSIC 코드(앞 2자리 = 업종)이며 **시점별 이력이 없는 현재 분류**다(K200P 시험들과 같은 한계). 코스닥 종목의 보유율은 실측해야 안다 → 아래 "실행 불가 판정 규칙".

### 실행 불가 판정 규칙 (측정 전에 고정)
- 각 판단일 d의 **업종 보유율** = (유니버스 구성 종목 중 KSIC 코드가 있는 종목의 시총 합) ÷ (유니버스 구성 종목 시총 합). 연도 값 = 그 해 판단일 평균.
- **어떤 해(2010-07 이후 판단일이 있는 해)든 연도 값이 70% 미만이면 그 유니버스를 쓰는 후보는 "실행 불가"**로 표시한다(성적 계산·게이트 판정 제외, 번호는 소진). 기준 70%는 J 연구의 실적 필터 커버리지 기준(J_COVERAGE_MIN_PCT)과 같다. Q1과 Q3은 같은 유니버스라 함께 판정한다. 연도별 값은 모두 보고한다.
- 시총·거래대금 PIT 가용: 유니버스 정의에 쓰이므로 값이 없는 종목은 유니버스에 들어오지 않는다. 시장별·연도별 가격 행 수와 시총>0·평균 거래대금>0 비율을 보고만 한다.
- 업종 분류가 없는 종목은 K200P 시험들과 같이 업종 순위에서 제외되고 신규 진입 후보가 될 수 없다("미분류" 그룹은 순위에 넣지 않는 기존 규칙).
- 시장 구분이 월말 목록에 없는 종목은 유니버스에 넣지 않는다(해당 종목 수와 시총 비율을 보고).

## 공통 구현 정의 (결과를 보기 전에 고정하는 해석)

1. **엔진**: scripts/research-n-book-canon.ts(e7ea090)의 M3 엔진(simN)과 같은 슬롯·쿨다운·체결·상폐 청산·ATR·채널 코드를 쓰며 유니버스 함수만 바꾼다. 입력(가격 Parquet 수정주가, 제외 규칙 4c1557a, 업종, 시장 목록)은 M 연구(8bd1ba2)와 같다. 첫 판단일 2010-06-30(M 연구와 같음), 시작 현금 100%, 수익률 집계는 M 연구와 같은 구간(학습 2010-07~2016-12 / 확인 2017~2021 / 보류 2022~, 전 기간 = 학습 시작~최신). 069500 원주가와 각 후보를 같은 구간으로 비교한다.
2. **유니버스 U(d)** (판단일 d마다 새로 계산, PIT): 가격 행이 d에 있고, 20일 평균 거래대금 ≥ 5억 원(PIT_MIN_AVG_TRADING_VALUE_WON), 제외 규칙(우선주=종목코드 끝자리 ≠ 0, ETF/ETN 겹침, 스팩 이름, 리츠 이름·업종·명시 코드)에 해당하지 않고, d 이하 최신 월말 목록에서 시장이 KOSPI 또는 KOSDAQ인 종목 = 후보 풀 P(d). 시총 내림차순(동률은 코드 오름차순).
   - **Q1·Q3**: U(d) = P(d) 중 시총 ≥ 5,000억 원(marketCapEok ≥ 5,000).
   - **Q2**: U(d) = P(d)를 시총 순으로 줄 세워 201~500위(1부터 센 순위). 순위는 전 시장 P(d) 안에서 매긴다.
3. **업종 순위·NH·신호**: M3와 같되 구성 종목을 U(d)로 바꾼다. 업종 순위 = U(d) 안 업종(KSIC 2자리)별 시총가중 6−1개월 수익률(업종당 종목 수 ≥ SMT_MIN_SECTOR_STOCKS, 미분류 제외), 상위 3업종(F_TOP_SECTORS). NH(c) = U(d) 구성 종목 중 (종가 > 직전 55개 행 종가 최고값인 종목 수) − (종가 < 직전 55개 행 종가 최저값인 종목 수), 행 인덱스 ≥ 55인 종목만 센다. 신호 = 종가 > 직전 55개 행 종가 최고값(엄격) ∩ 상위 3업종 ∩ NH(c) > 0. 슬롯보다 신호가 많으면 시총 큰 순. 20거래일 쿨다운, 보유 종목 제외는 기존과 같다. 판단일에 U(d)에 속하는 종목만 신규 진입하고, 보유 중인 종목은 U(d)를 벗어나도 청산 규칙(채널·ATR·상폐)으로만 정리한다.
4. **Q3 미너비니 조건**: N 연구 P8의 정의 그대로(종가 > SMA150 ∧ > SMA200 ∧ SMA150 > SMA200 ∧ SMA200[i] > SMA200[i−20] ∧ SMA50 > SMA150 ∧ 종가 > SMA50 ∧ 종가 ≥ 52주 저가 × 1.3 ∧ 종가 ≥ 52주 고가 × 0.75; 52주 = 종목 최근 252개 행 종가, 행 수가 모자라 값이 정의되지 않으면 충족 안 함 = 진입 금지). "200일선 미정의 구간은 진입 금지"는 Q3에 이렇게 적용된다. Q1·Q2의 M3 틀에는 200일선이 쓰이지 않으므로 해당 조항은 적용되지 않고, 2010-07 이전에는 판단일 자체가 없다.
5. **비용·슬리피지**: 수수료 0.015%, 거래세 일정, 상폐 청산은 기존(lib/transactionCost) 그대로. 슬리피지는 기존 0.1%(SLIPPAGE_PCT_PER_SIDE)이며 Q1·Q3은 그대로, **Q2는 매수·매도 각 0.2%**(0.1%p 추가). 구현: 매수 승수 = 기존 매수 승수 × (1+s)/(1+0.001), 매도 후 수취율 = 기존 수취율 × (1−s)/(1−0.001). Q_SLIPPAGE 상수로 둔다.
6. **시총가중 바스켓(참고, 판정 제외)**: 판단일 순서대로, 전 거래일 U(d_prev) 구성 종목을 전 거래일 시총 비율로 가중해 오늘 수정 종가 수익률을 가중 평균한 일별 수익률(오늘 가격 행이 없는 종목은 가중에서 빼고 재정규화, 비용 없음)을 이어 붙인 지수. 평가 구간은 전략과 같다. 유니버스별(Q1=Q3 하나, Q2 하나)로 CAGR·MDD를 보고한다.
7. **게이트 구현**: A·B·E·F·G는 M·N 연구와 같은 코드. C: 진입·청산 체결을 하루 더 늦춤(신호 계산은 같음). D: 한 번에 하나만 바꾸는 이웃 8개 = (L,M) (40,15)·(70,25), ATR 배수 1.5·2.5, 동시 보유 7·13(13종목은 현금 한도로 총 노출 100% 초과 불가), 상위 업종 수 2·4. 각각 전 기간 CAGR ≥ 069500 원주가 CAGR이면 O. E: (거래 손익 ÷ 진입 시점 계좌 평가액) 상위 3개 거래를 보유 기간 069500 원주가 수익률로 대체한 CAGR. F: 신호 건수 nSig(첫 판단일~데이터 끝−1일, 슬롯·쿨다운 적용 전), 풀 = 신호 사건(55일 돌파)을 빼고 나머지 조건(U(d) 구성, 상위 3업종, NH > 0, Q3은 미너비니의 돌파 외 조건, ATR 정의됨·행 인덱스 ≥ 55)을 충족한 (종목, 판단일) 쌍, 비복원 무작위 nSig개(같은 날은 시총 큰 순), 1,000회, mulberry32(KSS_R3_SEED = 20261022)를 후보마다 새로 시작, 후보 CAGR의 백분위(무작위 CAGR 중 더 작은 비율) ≥ 95면 O, 참고 1 − 0.05/3 = 98.33 이상 여부 표시. G: 진입 건수 ≥ 100. H(Q2만, 보고): Q2 전 기간 CAGR > 069500 원주가 CAGR ∧ MDD < 069500 원주가 MDD이면 "재현 성공" 표시, K200P의 M3 값(11.24/35.41, 같은 2010-07 시작 구간)과 나란히 보고.
8. **통과 판정**: Q1~Q3 모두 A~G가 전부 O여야 통과. H는 판정에 넣지 않는다.
9. **추가 보고 정의**: 진입·청산 건수·승률·손익비·평균 보유일은 K·M·N 연구와 같은 정의. 동시 후보 종목 수 = 판단일별 신호 수(슬롯·쿨다운 적용 전, NH 통과일) 평균(전체 판단일 / 신호 있는 날). 코스닥 종목 비중 = 진입 건수 중 진입일 시장이 KOSDAQ인 비율, 수익 기여 = KOSDAQ 진입 거래의 (거래 손익 ÷ 진입 시점 계좌 평가액) 합 ÷ 전체 거래 합. 업종 쏠림 = 진입 건수의 업종(KSIC 2자리)별 비중 상위 3개와 최대 비중. 체결 가능성 = 시드 1,000만 원 정수 주 모의의 각 진입에서 (진입 금액 ÷ 진입일 20일 평균 거래대금)의 중앙값·95분위·최대와 1%·5% 초과 건수(Q_ORDER_RATIO_FLAGS). 단일 종목 최대 비중, 삼성전자+SK하이닉스 합산 비중, 현금 100% 기간, 연 회전율·연 비용, 특정 구간(2020-03, 2022, 2026-10-01~10-15)은 N 연구와 같은 정의.
10. **시드 모의·최소 필요 금액**: 정수 주(조정 이벤트 반영), 진입 금액 = 계좌 평가액 × 10% 내림, 1주도 못 사면 다음 후보. 시드 KSS32_SEEDS_WON(100/300/500/700/1,000만 원). 최소 필요 금액 = 진입일 원 종가 ÷ 0.10(2024-01 이후 진입)의 중앙값·최대.

## 구현 방침 (실행 전 고정)
1. 스크립트 scripts/research-q-universe.ts 하나, 워크플로 diagnose-benchmark-reference-implementation.yml의 `which=q` 선택지로 **1회** 실행한다. 상수는 lib/kodexSectorSatConfig.ts의 Q_* 로 둔다. 외부 요청 0, DB·Storage 쓰기 0.
2. 실행 가능 여부(업종 보유율)는 같은 실행 안에서 위 규칙으로 판정하고, 실행 불가이면 해당 후보는 성적을 계산하지 않는다. 판정 때문에 다시 돌리지 않는다.
3. 논리 결함(계산 오류·크래시)만 수정하며 사유를 기록한다. 결과를 본 뒤 정의·기준은 바꾸지 않는다.

## 주의 (보고서에 반드시 포함)
- 보류 구간(2022~)은 이미 여러 번 본 데이터라 순수 검증이 아니다.
- 누적 시험 197번 중 우연히 걸릴 가능성이 있다: 귀무에서도 5% 수준 기준 하나를 우연히 넘는 후보가 평균 197 × 0.05 = 9.85개 나올 것으로 기대되고, 적어도 하나가 걸릴 확률은 1 − 0.95^197 ≈ 100%다(시험들이 독립이 아니므로 근사).
- 통과해도 운영 적용·PR 생성은 하지 않고 보고만 한다.
- 업종 분류는 현재 값을 과거에 적용한 것이라 PIT가 아니다(K200P 시험들과 같은 한계).
