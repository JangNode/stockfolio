# DS13 사전등록 (DS13M 309 / DS13L 310: 코어 + 잔차 모멘텀·저위험 혼합 위성)

연구 브랜치 `claude/ma-v3-portfolio-cap-run` 전용. main 병합·변경·운영 적용·PR 없음. 공시(DART)·외부 호출 없음, 연구 DB 쓰기 0. 사용자 지정 2026-11-17. 이 문서는 **DS13 성과를 계산하기 전에** 커밋한다. 등록 후 정의 변경 금지, **추가 변형·재시험 금지(누적 310에서 종료)**. 구현의 논리 결함만 사유를 기록하고 고친다.

## 0. 선택 편향 고지 (문서 첫머리)
**이 가설은 RM1C(295), MV1C(303), DS6, DS8의 결과와 K200P 17건 보정 재채점 결과를 모두 본 뒤 조립한 변형이며 선택 편향이 매우 크다.** 위성을 "RM1(잔차 모멘텀)"과 "MV1(최소분산) 또는 LV1(DS6 위성)"로 반반 섞는 아이디어는 RM1C가 구간 2에서 B를 못 넘고 MV1C가 A·F 근처에서 탈락한 것을 보고 나온 것이다. 통과하더라도 **포워드 관찰 대상일 뿐 확정이 아니다.** 2011~2026은 이미 반복해서 본 오염된 구간이다. 누적 시험은 308 → 310(DS13M 309, DS13L 310), 실력이 없어도 5% 기준 하나를 우연히 넘는 후보 기대는 310 × 0.05 = 15.50건(근사)이다.

## 0.1 데이터 표준 결정 (사용자 지정 2026-11-17)
**이번부터 K200P 가격 오류 17건 보정(`k200p-correction-summary.md`, `PRICE_CORRECTION=k200p17`)을 적용한 데이터를 표준으로 쓴다.** DS13 시험과 비교용 DS6·DS8·RM1C·MV1C는 모두 보정 적용 데이터로 같은 실행에서 계산한다. 기존 시험의 공식 판정은 바꾸지 않고 기본 미적용 옵션도 그대로 둔다. 사전 점검에서 **보정 미적용 DS6 재현(연속 11.70 / 39.15, 구간 1 4.10 / 24.51)과 보정 적용 DS6 값을 둘 다 확인**한다(보정 재채점에서 DS6는 17건과 보유 겹침이 없어 같은 값이 나왔다).

## 0.2 사전 확인: 같은 형태의 선행 시험이 있는가 → 없음(실질적으로 같은 정의 아님)
| 선행 | 구조 | DS13과 차이 |
|---|---|---|
| DS2(267)·DS5(270) | 코어 40% + 위성 60% = W3(워크포워드 랭커: 가격 특성 + 외국인 수급) + LV1(변동성 역수 250일 배분), 일별 목표 비중 리밸런싱 | 위성 두 구성요소가 W3·LV1이고 변동성 역수 일별 배분이다. DS13은 RM1(069500 회귀 잔차 모멘텀 20종목) + MV1/LV1을 **고정 30/30 비중으로 월 1회** 맞춘다 |
| DS4(269) | 코어 40% + PE4(공시)+W3+LV1 | 공시 사용, 구성요소 다름 |
| DS6(271)·DS8(274) | 코어 40% + 위성 60% = LV1 단독 | 위성이 한 구성요소 |
| RM1C(295)·MV1C(303) | 코어 40% + 위성 60% = RM1 단독 / MV1 단독, 일별 40:60 리밸런싱 | 위성이 한 구성요소 |
따라서 "코어 + 모멘텀류/저위험류 위성 반반" 조합은 시험한 적이 없다. 새 번호로 시험한다.

## 1. 정의
### 1.1 구조: 3개 하위 계좌(sleeve)
- **코어 40%**: **DS6 코어 정의 그대로**(월말 K200P(PIT) 안 당일 시총 상위 2종목 시총 비율, 순위 밖 5거래일 연속일 때만 교체, 신호 종가·다음 거래일 종가 체결; `coreOf(2, …)`).
- **모멘텀 위성 30%**: **RM1 정의 그대로**(K200P(PIT) 월말 신호, 069500 회귀 잔차 모멘텀 점수 `rmScore`, 상위 20종목 동일 비중, 보유는 순위 40위 안이면 유지, 월 1회 재조정). 하위 계좌 안 종목당 5%, **계좌 기준 종목당 1.5%**.
- **저위험 위성 30%**:
  - **DS13M (시험 309)**: **MV1 정의 그대로**(K200P 시총 상위 100, 공분산 252일 0.5 축소 최소분산, 종목 0~5%, 월말 신호, 항상 100%), 하위 계좌 안 비중 × 0.3(계좌 기준 종목당 최대 1.5%).
  - **DS13L (시험 310)**: **DS6 위성(LV1) 정의 그대로**(변동성 목표 배율 일별 조정 등 LV1 자체 규칙은 이 30% 안에서만 DS6 정의대로 적용; DS6의 60% 위성을 30%로 축소 = 비중 × 0.5).
- **같은 종목이 두 위성에 뽑히거나 코어 종목(시총 상위 2)이 위성에도 뽑히면 위성에서도 그대로 보유**한다. 하위 계좌들의 노출이 계좌 수준에서 합산된다(구현은 하위 계좌별 독립 계산이라 종목 거래를 계좌 사이에 상쇄하지 않는다 — 각 하위 계좌가 자기 거래 비용을 낸다. 보수적).
### 1.2 하위 계좌 간 재조정
- 초기 배분 40 / 30 / 30 (첫 신호일 종가, 비용 없음). **매월 마지막 거래일(월말 신호일) 종가의 하위 계좌 평가액으로 40 / 30 / 30 목표를 계산**하고, **다음 거래일 종가에 그 고정 금액을 옮긴다**(이동 금액의 0.25% 비용, 기존 `CS_MOVE_COST`, 받는 하위 계좌들이 이동 금액 비율로 부담 — `combine2`와 같은 방식). **DS6의 일별 40:60 재조정은 쓰지 않는다**(월 1회). 월 사이에는 하위 계좌가 자기 수익률대로 변해 비중이 흐른다.
- 코어 내부 재조정은 DS6 코어 정의(교체 이벤트 때만), RM1·MV1 내부는 월말 신호, LV1 내부는 DS6 위성 정의(일별 규칙)다.
### 1.3 비용·기간·벤치마크
- 비용·슬리피지·수정주가·벤치마크는 기존 규칙(069500 원주가, 가격 수익만; 수수료 0.015%/편도 + 매도 증권거래세(시기별) + 슬리피지 0.1%/편도, 현금 이자 0, 보정 적용 데이터).
- **기간**: 수익 집계 **첫 신호일 다음 거래일**(RM1·MV1의 첫 신호일 2011-01-31 → 2011-02-01)부터 2026-10-26 연속 + 기존 3구간(구간 1 = 시작일~2016-12-29, 구간 2 = 2017-04-04~2021-12-31, 구간 3 = 2022-01-03~2026-10-26). 069500·DS6도 같은 구간으로 비교한다.

## 2. 관문 A~H (기존 정의·구현 그대로, 기계 판정, `scripts/researchGates.ts`; **F는 백분위 95 이상**)
A 연속 전체에서 069500 대비 CAGR +2%p 이상 ∧ MDD가 069500과 같거나 작음. B 세 구간 중 2개 이상에서 069500보다 CAGR이 높고 MDD가 더 크지 않음. C 하루 지연(lag 2: 코어·RM1·MV1/LV1 체결을 모두 +1거래일; 하위 계좌 간 이동 자체는 지연하지 않음, DS8·DS9와 같은 방식)에서 연속 전체 CAGR 하락 ≤ 1%p ∧ MDD 악화 ≤ 2%p. D 이웃값 모두 연속 전체 CAGR ≥ 069500 CAGR. E 손익 상위 3개 보유 구간을 069500 수익률로 대체해도 연속 전체 CAGR ≥ 069500. F 무작위 대조 백분위 ≥ 95(1,000회, 시드 20261022). G 진입 건수 ≥ 100. H 069500 대비 CAGR +1%p 이상, 또는 (MDD 개선 3%p 이상 ∧ CAGR ≥ −1%p). 통과 = 전부 통과, 게이트는 완화하지 않는다.
- **D 이웃값(한 번에 하나씩, 6개)**: 위성 배분(모멘텀/저위험) 20/40 → 비중 40 / 20 / 40, 40/20 → 40 / 40 / 20; 코어 비중 30% → 30 / 35 / 35, 50% → 50 / 25 / 25(위성은 비례 조정); RM1 종목 수 15, 25(`B5_RM_NB`의 종목 수 이웃, 유지 순위 2N).
- **E의 해석(고정)**: 두 위성(모멘텀 + 저위험)의 닫힌 보유 구간을 합쳐 **계좌 기준 손익**(= 하위 계좌 기준 손익 × 하위 계좌 비중 0.3) 상위 3개를 069500 수익률로 대체하고(기존 `replace` 규칙), **코어는 실제 그대로**. 출력의 상위 거래 목록은 코어 거래를 포함한 참고용이다(DS8·DS9와 같은 관례).
- **F의 해석(고정)**: 위성별 무작위 대조를 실제 코어(고정)와 40 / 30 / 30으로 합성한다. 모멘텀 위성: RM1 신호일·주문 수·보유 기간 분포와 같게 K200P 점수 있는 종목에서 무작위(`randomS`). 저위험 위성: DS13M은 MV1의 같은 방식(동일 비중 무작위), DS13L은 LV1의 기존 무작위 대조 1,000회(DS6 게이트 F와 같은 시드·횟수)의 같은 번호 표본. 한 번의 시행에서 두 위성이 서로 독립인 난수를 쓴다(같은 난수열을 모멘텀 → 저위험 순으로 소비).
- **G 해석**: 진입 건수 = 코어 + 모멘텀 위성 + 저위험 위성 진입 합.

## 3. 보고 항목 (구현 후 이 목록과 출력을 대조하고 빠진 것은 별도 실행으로 채운다)
1. 연속·3구간 CAGR/MDD/최악 12개월/샤프, 관문별 판정(탈락이면 기준과의 차이), 연도별 승패(069500 대비, DS6 대비), 연 회전율·비용
2. **같은 보정 데이터** 기준의 DS6, DS8, RM1C, MV1C와 나란히 비교한 표(연속·3구간, 같은 구간)
3. 손익 분해: 코어, 모멘텀 위성, 저위험 위성 각각의 기여(하위 계좌 비중 × 일별 수익률의 단순 합 %p, 재조정 비용 별도)
4. 삼성전자·SK하이닉스 평균 비중(코어 + 위성 합산; 월말 신호일 목표 비중 기준 근사, LV1 위성은 투자 비중을 보유 종목 수로 나눈 근사)과 두 종목을 뺀 나머지의 CAGR(정보용: 두 종목의 수정 수익률을 0으로 둔 별도 실행 `NEUTRALIZE_CODES`, 시험 아님)
5. 구간 2(2017-04~2021-12) 상세: 연도별 수익(2017은 04-04부터)과 이 구간의 낙폭(고점일·저점일), DS13M·DS13L·RM1C·DS6·069500 나란히
6. 하루 지연 체결(C)에서의 CAGR·MDD 변화
7. 모든 관문 통과 시 "통과(선택 편향 큼, 포워드 확인 필요)" 표시 + DS6 포워드 관찰 도구에 이 전략을 추가하는 데 필요한 작업만 제안(구현 안 함)
8. 누적 시험 횟수와 우연 통과 기대 건수(310 × 0.05 = 15.50)
