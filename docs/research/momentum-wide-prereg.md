## 1. 목적

연구 LE에서 앙상블 모멘텀 로테이션은 보유 수 5개(LE2, 풀 30)가 전체 CAGR 10.87 / MDD 55.36이었고, 보유 10개(LE1 풀 30: 6.04 / 57.86, LE3 풀 50: 6.09 / 68.78)는 오히려 CAGR이 낮고 MDD가 컸다. 069500의 MDD(41.34)보다 낙폭이 큰 점이 모든 후보의 공통 약점이었다. 이번 시험은 **보유 종목 수와 풀을 더 크게(15/20/30개, 풀 50/100) 늘리면 분산 효과로 낙폭이 얼마나 줄어드는지** 본다. 점수·편입·청산 구조는 바꾸지 않고 풀·보유 수·한도만 키운다. 보유 종목 수와 CAGR·MDD의 관계를 LE2(5개)·LE3(10개)와 함께 한 장 표로 정리해 보고한다.

## 3. 구현 정의 (실행 전 고정; "해석"은 지시 문구에 없어 문서화 시 정한 것)

기준값은 lib/momentumWideConfig.ts, 점수 계산은 lib/momentumEnsemble.ts(연구 LE와 같은 모듈), 엔진은 공용 슬롯 시뮬레이터(lib/slotSim.ts, 변경 없음), 스크립트는 scripts/research-lw-wide.ts다. 구조는 scripts/research-le-ensemble.ts와 같고 풀·보유 수·한도만 후보별 값이다.

1. **입력·비용·평가 구간·시총 순위·재진입 금지**: 연구 LE와 같다(고정 스냅샷, 월말 시장 목록, 제외 규칙, 매수 = 종가 × (1 + 0.1%) × (1 + 0.015%), 매도 = 종가 × (1 − 0.1%) × (1 − 0.015% − 당일 거래세), 현금 이자 0%, 평가 시작 판단일 2011-01-03·수익률 집계 2011-01-04~, 신호는 매 거래일 종가 판단·체결 다음 거래일 종가(lag 1), 재진입 금지 20거래일). 시총 순위는 d 행 시총 내림차순·동점 코드 오름차순·코스피 보통주이며 이번엔 130위까지 계산한다(깊이만 다름).
2. **앙상블 점수·풀(해석 불필요, LE와 같음)**: 풀 = 판단일 시총 순위 ≤ pool(50 또는 100)인 코스피 보통주 중 세 구간 수익률이 모두 계산되는 종목(n개). 구간별 백분위 = (더 낮은 종목 수 + 0.5 × 같은 값 수[자기 포함]) ÷ n, 점수 = 세 백분위의 단순 평균, 순위 = 점수 내림차순(동점이면 시총 순위가 앞선 쪽). 풀 100개 안에서는 순위 폭이 넓어 상·하위 백분위 차이가 LE의 풀 30보다 촘촘하다.
3. **편입**: 풀 안 앙상블 순위 ≤ slots(15/20/30)인 종목 중 12-1개월 수익률 > 0(엄격)인 것을 순위 순으로 빈 슬롯에 채운다. 후보가 모자라면 빈 슬롯은 현금. 종목당 투입 = 계좌의 1/slots(LE와 같은 슬롯 방식, 변동성 목표화 없음).
4. **청산(매일, 순위로만)**: 시총 순위 > keepCap(70/130/130)이면 "시총 순위 밖", 풀 안 앙상블 순위 > keepRank(25/35/50)이면 "앙상블 순위 밖"(보유 종목이 풀 밖이면 풀에 끼워 넣어 같은 식으로 점수를 내고 순위 = 1 + 풀에서 점수가 더 높은(엄격) 종목 수). 판단일에 행이 없거나 세 구간 중 하나라도 계산할 수 없는 보유 종목은 판단하지 않고 보유. 12-1개월 ≤ 0 규칙은 편입에만 적용한다. 손절·추세·국면 필터 없음.
5. **게이트 D 이웃**: 후보당 4개(보유 수 2개 + 순위 매도 한도 2개), 하나씩만 바꾼다. 보유 수를 바꾸면 편입 순위 한도와 종목당 비중(1/slots)이 함께 바뀌고 순위 매도 한도·시총 한도는 기본값 그대로다. 순위 매도 한도를 바꿀 때는 보유 수·시총 한도가 그대로다.
6. **게이트 F 무작위 풀**: 신호일마다 실제 매수 주문 수만큼 **풀 안 12-1개월 수익률이 양(+)이고 보유·재진입 금지가 아닌 종목**을 무작위로 뽑아 같은 청산 규칙(앙상블 순위 + 시총 한도)·같은 크기 규칙으로 다시 돌린다.
7. **게이트 H 해석**: 기준선 = 같은 실행에서 다시 계산한 **LE3와 LE2 각각**. 한 기준선에 대해 조건1 = 후보 전체 CAGR ≥ 기준선 CAGR + 1%p, 조건2 = 후보 MDD ≤ 기준선 MDD − 3%p 이고 후보 CAGR ≥ 기준선 CAGR − 1%p, 둘 중 하나면 그 기준선에 대해 O. **두 기준선 모두 O**일 때 H = O. 지시문의 "MDD 3~5%p 개선"은 하한 3%p를 통과 기준으로 쓰고 5%p 이상 개선인지도 함께 표시한다(통과 조건 아님).
8. **기준선 재계산**: LE2(풀 30·5개·순위 10·시총 40)와 LE3(풀 50·10개·순위 15·시총 60)를 같은 실행·스냅샷으로 다시 계산해 LE 시험 값(10.87 / 55.36, 6.09 / 68.78)과 일치하는지 출력한다(시도 수에 넣지 않음).
9. **보고용 계산**: 보유 종목 수별 한 장 표(5 = LE2, 10 = LE3, 15 = LW1, 20 = LW2, 30 = LW3)는 구간별·2026년 제외 CAGR / MDD, 연 회전율, 15년 합계 비용(연평균), 진입 건수, 보유일 중앙값을 같은 정의로 한 줄씩 낸다(풀 크기가 달라 "보유 수만의 효과"가 아님을 표에 풀 크기를 병기한다). 평균 투자·현금 비중, 삼성전자·SK하이닉스 일별 평균 계좌 비중, 상위 3개 거래 대체, 하루 지연(lag 2), 학습 구간 연도별 후보 − 069500은 연구 LE와 같은 방식이다.
10. **비용 표기**: "비용 합계 %"는 해당 구간 안 일별 비용 비율의 합계(전체 구간 = 15년 합계)이고 연평균 = 합계 ÷ 15.8년을 병기한다.

## 5. 게이트 (연구 LE와 같은 정의; 완화 없음)

- **A**: 전 기간 CAGR ≥ B&H CAGR + 2%p 이고 MDD ≤ B&H MDD.
- **B**: 학습·확인·보류 세 구간 중 2개 이상에서 각각 CAGR > B&H CAGR 이고 MDD ≤ B&H MDD.
- **C**: lag = 2 전 기간에서 기본 CAGR − 지연 CAGR ≤ 1%p 이고 지연 MDD − 기본 MDD ≤ 2%p.
- **D**: 3절 5항의 이웃 4개 모두 전 기간 CAGR ≥ B&H CAGR.
- **E**: 기본 실행의 닫힌 거래 중 거래 기여(= (매도 대금 − 투입액) ÷ 진입 실행일 V)가 큰 상위 3개를 같은 진입·청산 실행일 동안 069500 원주가 일수익률로 바꿔(비용 같음) 전 기간 CAGR을 다시 계산했을 때 B&H CAGR 이상.
- **F**: 1,000회, 시드 20261022 mulberry32, 3절 6항의 무작위 풀. 백분위 ≥ 95여야 O. 참고로 1 − 0.05/3 ≈ 98.3 백분위 이상인지도 표시(통과 조건 아님).
- **G**: 전 기간 진입 100건 이상(완화 금지).
- **H**: 3절 7항.
- **통과** = A~H가 모두 O.

B&H = 069500 원주가(가격 수익만), 같은 구간·같은 스냅샷.
