# 업종 모멘텀 틸트 v2.1 — 바탕을 코스피 상위 200으로 (누적 시도 142) 사전등록

v2(6c49375)의 바탕 POOL(전 시장 시총 상위 100)이 B&H 가격(069500 원주가)보다 전 기간 1.4%p/년 낮음. KOSDAQ 대형주 포함 등 KOSPI 200과 구성 차이로 추정. 바탕을 KOSPI 상장 시총 상위 200으로 바꿔 비교 대상과 맞춤. 틸트 규칙은 v2와 동일. 모든 구간 성적은 개발 데이터 내 성적.

## 사용자 지정 규칙 (그대로 옮김)

[0단계 확인] 시장 구분(KOSPI/KOSDAQ) 정보가 어디 있는지(Parquet·DB 표·파일:줄)와 시점별 이력 여부. 상장폐지 종목의 시장 구분도 있는지. 시장 구분을 신호일 시점 기준으로 알 수 없는 종목이 시총 기준 5% 넘는 연도가 있으면 실행하지 말고 숫자만 보고(현재 값 하나만 있으면 그 사실과 이전 상장 종목 수를 보고하고 진행).
[바탕 K200P] 매월 마지막 거래일 KOSPI 상장 종목 중 시총 상위 200, 우선주·리츠 제외(4c1557a 규칙), 유동성 기준 20일 평균 거래대금 5억. 시총가중, 월 리밸, 같은 비용.
[v2.1] K200P 시총 비중에 v2와 같은 업종 모멘텀 틸트(6-1개월, 상위 3 ×1.5, 하위 3 ×0.5, 종목 2개 미만 업종·미분류 중립, 업종 모멘텀도 K200P 안에서 계산).
[비교] K200P, POOL, B&H 가격(069500 원주가), B&H 총수익(참고), KOSPI. 그리고 K200P와 B&H 가격의 연도별 수익 차이(추적 오차).
[기간] 학습 2010-07-01~2016-12-31, 확인 2017~2021, 2022~, 전 기간.
[참고 기준 표시, 판정 문장 금지] G1 CAGR ≥ K200P + 1.0%p / G2 CAGR > B&H 가격 / G3 MDD ≤ K200P MDD + 5.0%p / G4 지연 하락 ≤ 1.0%p.
[튼튼함 검사, 전 기간] R1: v2와 같은 6개 변형. R2: K200P 대비 초과 최대 1개월 제거. R3: 업종 순위 무작위 1,000회(시드 20261021), CAGR·샤프 백분위.
[보고] 숫자와 표만.
 - 0단계 결과
 - 구간별 v2.1·K200P·POOL·B&H 가격·B&H 총수익·KOSPI 표(CAGR, MDD, 샤프, 연변동성, 월 회전율, 누적 비용, 지연 CAGR, G1~G4)
 - 연도별 수익률(v2.1, K200P, B&H 가격)과 K200P − B&H 가격 차이
 - R1~R3 표
 - 최근 신호일 비중 상위 10종목(v2.1, K200P)
 - 읽은 행·[parquet-cache] 줄, 쓴 행(0), 소요 시간

## 실행 전 코드 조사 (0단계 중 코드로 확인되는 부분)

- **가격 Parquet**: 시장 컬럼 없음. 백필이 KRX `stk_bydd_trd`(KOSPI)·`ksq_bydd_trd`(KOSDAQ) 응답을 합쳐 시장을 버리고 저장한다(scripts/backfill-stock-daily-prices.ts:169-201, 저장 컬럼 lib/stockDailyPricesStorage.ts:67-76).
- **stock_beta.market**(supabase/migrations/20260904010000_create_beta_price_history_and_stock_beta.sql:19-21): 종목당 한 행, 현재 값 하나(시점별 이력 없음). scripts/calc-stock-beta.ts:56-61·77-84 — 대상은 시총 1조 이력 후보 종목, 시장 값은 실행 시점의 KIS 종목마스터(lib/stockMaster.ts:7-8, 외부 다운로드)에서 가져오며 종목마스터에 없는 종목(상장폐지 등)은 건너뛴다 → **상장폐지 종목의 시장 구분은 없다**.
- **lib/stockMaster.ts**: KIS 종목마스터 파일(현재 상장 종목만)을 외부에서 받는다 — 이번 실행은 외부 요청 0이라 쓰지 않는다.
- **beta_price_history·investor_flow_market**: 시장 단위 지수·수급(종목별 시장 구분 아님). investor_flow_stock 정리본에도 시장 컬럼 없음.
- **이전 상장(KOSDAQ → KOSPI) 종목 수**: 시점별 이력이 없어 데이터로 셀 수 없다.

## 구현 세부 (실행 전 고정)

1. **시장 값**: stock_beta.market(현재 값)만 쓴다. stock_beta에 없는 종목 = 시장 미상.
2. **0단계 수치**: stock_beta 행 수·시장별 수·computed_at 범위. 각 월간 신호일 d에서 후보 집합 C(d) = d에 가격 행이 있고 20일 평균 거래대금 ≥ 5억이며 4c1557a 제외 규칙에 걸리지 않는 종목 중, d 행 시총이 "시장 값이 KOSPI인 종목 중 200번째 시총" 이상인 종목. 미상 비율 = C(d) 중 시장 미상 종목의 시총 ÷ C(d) 시총. 연도 값 = 그 해 신호일 값 평균(최대값도 표시). **게이트**: 연도 평균 미상 비율이 어느 해든 5% 초과면 이후를 계산하지 않고 숫자만 보고한다. 통과하면 "현재 값 하나만 있음, 이전 상장 종목 수는 셀 수 없음"을 보고하고 진행한다. 업종 분류 보유율(K200P 시총 기준)도 함께 표시한다(게이트 아님).
3. **K200P(d)**: 시장 값 = KOSPI, d에 가격 행이 있고 20일 평균 거래대금 ≥ 5억(`computeTrailingAvgTradingValue`, 수정주가 기준), 4c1557a 제외 규칙에 걸리지 않는 종목을 d 행 시총 내림차순(동점 코드 오름차순)으로 정렬한 상위 200. 시총 하한(5천억) 없음. 시총가중, 월 리밸런싱, 같은 엔진·비용.
4. **v2.1**: v2(6c49375) 구현 세부 2·4·5·6과 같고 유니버스만 K200P(d). 업종 모멘텀도 K200P(d) 구성원으로 계산한다.
5. **POOL**: v2와 같은 월간 POOL(ELIG 상위 100, 제외 규칙 적용, 시총가중).
6. **비교·기간·지표·R1~R3**: v2(6c49375) 구현 세부 1·7·9와 같고, 비교 기준만 POOL → K200P(G1·G3, R2). B&H 가격 = 069500 raw_close, 총수익 = adj_close(참고), 가격 Parquet 마지막 거래일에서 자름. 연도별 추적 차이 = K200P 연수익률 − B&H 가격 연수익률.
7. 외부 요청 0, DB 쓰기 0, 1회 실행, 재실행 없음.
