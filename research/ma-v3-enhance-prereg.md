# [임시 연구 — 병합 금지] ma_cross v3 추가 강화 후보 4개 사전 등록

작성: 2026-10-13(KST). 결과를 한 번도 보기 전에 커밋한다. 이 문서는 이후 수정하지 않는다.
모든 결과는 2010~현재 같은 데이터를 반복 사용한 in-sample이다. 하네스: `scripts/research-ma-lab.ts`(R0·R1b 재현 검증 완료) + 신규 `scripts/research-v3-enhance.ts`.

## 1. 기준선 = 운영 v3 (= 이전 연구의 R1b)
진입 = 50/200 골든크로스 봉 종가 + 종가/직전 252거래일(진입일 포함) 고가 − 1 > −0.1829, 청산 = 데드크로스 봉 종가, 종목당 1포지션, 재진입은 새 골든크로스에서만.
PIT 유니버스(진입일 as-of 시총 ≥ 5천억 + 직전 20거래일 평균 거래대금 ≥ 5억), 비용 반영(수수료 0.015%/편, 슬리피지 0.1%/편, 거래세 일정표), 점수 게이트 없음.
사용자 지정 기준선 수치: 전체 CAGR 6.36% / MDD 53.31% / 승률 32.2% / 손익비 4.03 / 기대값 62.02% / 2,335건. 학습(2010~2018) 0.36% / 26.01%, 확인(2019~) 13.75% / 41.13%.
실행 시 하네스가 이 수치를 재현하는지 먼저 출력한다. 판정에는 **하네스 재현값**을 쓴다(소수 둘째 자리 기준 일치가 기대값이며, 불일치하면 보고서에 그대로 표기).

## 2. 후보 4개 (값 고정, 데이터 보고 조정 금지) — 모두 기준선 v3 위에 추가되는 조건
| 후보 | 정의 (진입일 = 신호일 = 골든크로스 봉, 그 종가까지의 정보만 사용) |
|---|---|
| S1 | ATR(14) 고정 손절: 진입일 종가 − 3×ATR(14,진입일) 이하로 종가가 처음 떨어진 날(진입 다음 거래일부터 판정) 그날 종가로 청산. 손절선은 진입 시 고정(추적 안 함). 데드크로스 청산과 먼저 오는 쪽 적용. 청산 후 다음 골든크로스까지 재진입 없음 |
| S2 | 200일 이동평균 20일 기울기 `SMA200[e] / SMA200[e−20] − 1 > 0` 일 때만 진입 |
| S3 | 신호일 거래량 ≥ 직전 20거래일(신호일 제외) 평균 거래량 × 1.5 일 때만 진입 |
| S4 | 신호일 KOSPI 지수 종가 > KOSPI 200일 단순이동평균(신호일 포함)일 때만 신규 진입. 이미 보유한 종목의 청산은 데드크로스 그대로 |

### 세부 확정 (결과 보기 전 해석 고정)
- ATR: Wilder 평활(초기값 = 첫 14개 TR의 단순평균), TR = max(고−저, |고−전일종가|, |저−전일종가|). 고가·저가가 0 이하이면 종가로 대체(기존 `experiment-ma-cross.ts`의 처리와 동일). 진입일에 ATR이 계산 불가이면 진입하지 않음(200일선 조건상 사실상 발생하지 않음).
- S3: 직전 20일 평균 거래량이 0이거나 20일 미만이면 진입하지 않음. 이전 "골든크로스일 거래량≥20일평균"(배수 1.0)과 창·정의가 같고 배수만 1.5로 엄격하다.
- S4: KOSPI 지수는 `getIndexPriceSeries("KOSPI")`를 **2008-01-01부터** 로드해 2010-01 신호부터 200일선이 계산되게 한다. 신호일에 해당 지수 행이 없으면 직전 가용일(as-of) 값을 쓴다. 200일선 계산 불가(<200행)이면 진입하지 않음. 지수 시리즈 시작일은 로그로 출력한다.
- 5천억 미만 복제 유니버스: 진입일 as-of 시총 500억 이상 5천억 미만 + 평균 거래대금 5억 이상. **이 유니버스의 기준선 = v3 규칙(52주 고점 필터 포함, 후보 조건 없음)을 같은 유니버스에 적용한 것**(이전 연구 R1~R2와 동일 해석; 사용자 문구 "조건 없음"은 "후보 조건 없음"으로 해석).
- 지표 정의(이전 연구와 동일): 승률 = 비용 반영 수익률 > 0 비율, 손익비 = 평균 이익 ÷ |평균 손실|, 기대값 = 승률 × (손익비 + 1) − 1, 평균 보유일 = 거래별 달력일 평균, 평균 동시 보유 종목 수 = 보유 종목이 1개 이상인 날들의 일별 보유 종목 수 평균. 구간 CAGR/MDD는 하나의 연속 실행을 구간으로 자른 일별 수익률 시계열로 계산(CAGR 분모는 구간 시작일~종료일), 승률·손익비·거래 수는 진입일이 구간에 속한 거래.

## 4. 평가 프로토콜
1. 선택은 학습구간(2010~2018)만으로. **학습 관문** = 채택 조건 1 AND 6. 관문을 통과한 후보에 한해서만 확인 구간(2019~)과 전체 구간 수치를 후보당 1번 출력한다. 탈락 후보는 학습·5천억 미만 복제 학습 수치만 출력하고 확인·전체는 출력하지 않는다(코드는 모두 계산하지만 출력 안 함).
2. 채택 조건(모두 충족):
   1) 학습: CAGR이 기준선(학습)보다 높고(>) MDD가 기준선보다 나쁘지 않다(≤)
   2) 확인: CAGR ≥ 기준선(확인), MDD ≤ 기준선(확인)
   3) 전체 거래 수 ≥ 1,168건(기준선 2,335의 50%)
   4) 전체 손익비 ≥ 3.43(기준선 4.03의 85%)
   5) 전체 기대값 ≥ 기준선(전체) 기대값
   6) 5천억 미만 복제 유니버스의 학습 CAGR ≥ 그 유니버스 기준선, MDD ≤ 그 유니버스 기준선
3. 여러 개 충족 시 학습 기대값이 가장 높은 1개만 새 기준선. 결합(동시 적용)은 하지 않는다.
4. 채택 후보가 없으면 결론은 "v3 유지".
5. 보고 전용 지표(판정에 미사용): 전체 MDD, 평균 동시 보유 종목 수, 연도별 수익률(equal-weight 일별 수익률 복리, 현금일 0). 연도별은 학습 연도(≤2018)는 전 후보, 2019 이후 연도는 학습 관문 통과 후보만 출력.

## 5. 한계 (그대로 표기)
- 누적 43회 시도(in-sample). 전부 같은 2010~현재 데이터에서 선택·검증 → 선택 편향, 다중 비교 편향이 있다.
- v3 자체가 39회 중 선택된 기준선(R1b)이다. R1b의 학습·확인 수치를 이미 본 상태에서 후보를 정했다.
- 2019~ 확인 구간은 이전 시도(거래량 확인, ADX, 트레일링 등)와 R1b 선택 과정에서 이미 반복 관측됐다 → 홀드아웃이 아니다.
- 학습 구간 기준선 거래 수가 약 1,069건으로 작아, 학습 CAGR 0.36%는 작은 차이에도 부호가 뒤집히는 수준이다(조건 1이 "기준선보다 높다"만 요구하므로 우연 통과 가능성이 큼).
