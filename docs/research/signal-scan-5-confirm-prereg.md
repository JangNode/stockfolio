# 신호 스캔 5-A 후보 확인 점검 사전등록 추기 (시험 아님)

사용자 지정 2026-11-14. 이 문서는 **확인 구간 수집·열람 전에 커밋**한다. 이후 대상 행·구간·재현 기준을 바꾸지 않는다(논리 결함만 사유를 기록하고 고친다). 연구 브랜치 `claude/ma-v3-portfolio-cap-run`, main 병합·PR·운영 적용 없음, 공시(DART) 호출 0, 연구 DB 쓰기 0, 데이터 아티팩트 없음. 이 점검은 **시험이 아니라 후보 확인**이라 **시험 번호는 290 그대로, 스캔 행 누적도 385 그대로**다(확인 행은 별도로 기록).

관계 문서: `docs/research/signal-scan-5-prereg.md`(신호·유니버스·측정 정의는 그 문서 그대로. 이 추기는 구간과 재현 기준만 정한다).

다른 21행과 5-B 행은 확인하지 않는다. 학습 구간의 후보 기준(|t| ≥ 3.0, 비용 차감 순차이 > 0)은 학습 구간 결과로 이미 확정이며 바꾸지 않는다.

## 2. 구간

- **확인 구간: 2017-01-01 ~ 2021-12-31**(신호일 기준; 5-A 사전등록 1절에 수집 전 고정된 구간). 대상 종목 수집 목록은 학습 구간과 같은 344종목(외국계 창구 코드 99999, `inquire-member-daily`)이다.
- 20일 창 연속성을 위해 확인 구간 첫 표본일의 신호는 학습 구간 마지막 달들의 정리본 값을 이어 쓴다(확인 구간 신호 계산에 학습 값만 쓰는 것이며 학습 구간 결과는 다시 계산하지 않는다).
- 표본일 선택(월간 21거래일 간격·주간 5거래일 간격), 예측 기간 끝이 구간 안에 들어오는 표본일만 사용하는 규칙, 유니버스(POOL 시총 상위 100위, MID 101~150위, PIT 적격), 비용 모델(`transactionCost`), 겹침 보정(NW Bartlett, L = max(1, round(H ÷ 간격))), IC 정의(스피어만)는 학습 스캔과 같은 코드·상수를 쓴다.

## 3. 재현 기준 (사용자 지정, 3개 모두 충족해야 "재현")

1. **같은 부호**: 확인 구간 IC 평균이 음.
2. **Newey-West |t| ≥ 2.0** (학습 후보 기준 3.0보다 느슨한 확인 기준).
3. **신호 방향(음)으로 계산한 비용 차감 순차이 > 0**: 부호가 음이므로 롱 쪽을 하위 그룹, 숏 쪽을 상위 그룹으로 보고 (하위 − 상위 수익 차이) − 왕복 비용 > 0.

기준 값은 `lib/scan5Config.ts`의 `S5_CONFIRM_MIN_ABS_T = 2.0`, 대상 행은 `S5_CONFIRM_ROWS`로 상수화했다.

## 4. 절차

1. 이 문서를 커밋·푸시한다(수집 전).
2. 확인 구간 수집(`collect-scan5.ts` fmc 모드, 코드 99999, 344종목, 2017-01-01~2021-12-31, 종목당 호출 1회, 이어받기 가능, 쓰기 예산 25 MiB). 수집 후 정리본을 Actions 캐시에 저장하고 선행 조건(전부 0 종목·결측일·항등·종가 대조·κ·99999 의미 대조)을 확인 구간에서도 점검한다. 선행 조건을 못 지키면 스캔하지 않고 숫자만 보고한다.
3. 확인 스캔 1회(`research-signal-scan-5-confirm.ts`, `SCAN5_ONLY=confirm`). 3행의 IC·NW t·순차이·재현 여부를 표로 보고한다.
4. **재현된 행이 하나 이상이면** 보류 구간(2022-01-01 ~ 2026-10-26)을 **한 번만** 같은 방식으로 수집(fmh)·스캔(`SCAN5_ONLY=holdout:<재현 행 번호>`)하고 **부호와 순차이만 참고용으로** 보고한다(판정 기준·후보 승격 기준 없음). **재현된 행이 없으면 보류 구간은 열지 않고** 결과만 보고한다.
5. 결과를 `signal-scan-5-progress.md`와 이 문서 5절에 기록하고 커밋·푸시한다.

## 5. 한계 (미리 공개)

- 3행만 보므로 다중 비교 부담은 작지만, 학습 구간에서 고른 3행이라 확인 구간에서 |t| ≥ 2.0이 나와도 독립 확인은 보류 구간(참고용)까지 반복해야 의미가 있다.
- 2011~2026은 이미 여러 연구에서 반복해 본 데이터라 순수 홀드아웃이 아니다(기존 연구 오염 공지와 같음).
- 수집 목록 344종목은 학습 구간 기준 시총 상위 목록이라 확인 구간에 새로 상위 150위에 든 종목이 빠질 수 있다(스캔은 "수집 목록에 없는 구성원 쌍" 수를 출력한다). 목록은 바꾸지 않는다.
- 2020-03 코로나 급락·공매도 금지(2020-03~2021-05) 구간이 확인 구간에 들어 있다.
- 순차이는 롱·숏 가정(하위 − 상위)의 이론 값이며 공매도 제약·차입 비용을 반영하지 않는다.
- 재현은 후보가 아니라 "학습 구간 결과가 확인 구간에서 같은 방향으로 유지되었는가"만 뜻한다. 전략 시험은 별도 사전등록 뒤에만 한다.
