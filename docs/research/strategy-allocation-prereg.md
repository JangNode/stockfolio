# 연구 ALLOC — 전략 배분 포트폴리오 (P1 = 시도 254, P2 = 255, P3 = 256) 사전등록

작성 2026-10-28(사용자 지정). **이 문서는 시험 실행 전 사전등록이며 후보 실행 전에 커밋한다(커밋 해시는 보고에 기록).** 국내 주식과 현금만 쓴다(ETF 매매 금지, 069500은 기준선으로만 쓴다). 모든 구간 성적은 개발 데이터 내 성적이다. 통과해도 운영 적용·PR은 하지 않고 보고만 한다. 탈락하면 원인을 파고들지 않고 결과만 보고한다. 브랜치 `claude/ma-v3-portfolio-cap-run`, main 병합 없음. 누적 시도 253 → 256(후보 3개 모두 실행하면 소진, 사전 점검은 번호를 소진하지 않음).

## 1. 목적

지금까지 개별 전략은 모두 게이트를 통과하지 못했다. 그러나 강한 국면이 서로 다르다: PE4(잠정 실적 후 20거래일 보유, 2017-04~ 14.21 / 23.99)는 낙폭이 작고, W3(WFR 점수 저회전, 5.77 / 47.04)·LV1(대형주 모멘텀 앙상블 + 변동성 목표화, 6.95 / 46.46)·L3(시총 상위 5종목 집중, 11.05 / 51.63)는 서로 다른 시기에 큰 낙폭을 겪었다. 이 연구는 이미 만든 전략들의 일별 순수익을 목표 비율로 매일 되돌리는 계좌 배분으로 합쳤을 때 **낙폭이 분산되는지**를 단 한 번 확인한다. 새 신호·새 모델은 없다.

## 2. 선택 편향 명시 (정직 소진)

**구성요소는 개별 결과를 본 뒤에 골랐다.** PE4(14.21 / 23.99), W3(5.77 / 47.04), LV1(6.95 / 46.46), L3(11.05 / 51.63)는 모두 개별 시험에서 이미 탈락한 전략이고, 그 결과(구간별 낙폭 시기 포함)를 본 뒤 "강한 국면이 다르다"고 판단해 조합 대상으로 골랐다. 비율(균등)은 시험 전에 고정했고 결과를 본 뒤 바꾸지 않는다. 그럼에도 구성요소 선정 자체가 사후적이므로 합성 결과는 낙관적으로 편향될 수 있다. 시도 번호 254~256은 형식상 소진한다.

## 9. 배분 규칙 (사용자 정의 + 해석, 실행 전 고정)

- 매일 종가에 각 구성요소 계좌(슬리브) 평가액을 목표 비율과 비교한다. 어긋나 있으면 **다음 거래일 종가**에, 전일 종가에 정한 **고정 금액**을 과대 슬리브에서 과소 슬리브로 옮긴다(일별 리밸런싱, 허용 밴드 없음). 그 사이 하루의 가격 변동은 반영한다.
- **비용**: 이동 금액(= 과소 슬리브로 들어가는 금액의 합, 과대 슬리브에서 나가는 금액과 같음)에 **0.25%를 한 번** 적용하고, 들어가는 슬리브가 부담한다. 근거: 사용자 지정 "편도 평균 비용+슬리피지 0.25%"를 이동 금액에 한 번 곱한다. 이는 매도·매수 양쪽에 각각 0.25%를 곱하는 해석(0.50%)보다 낙관적일 수 있어, **정보용(판정 불사용)**으로 0.50% 적용 결과를 함께 보고한다. 구성요소 내부 거래 비용·슬리피지는 각 순수익에 이미 반영돼 있어 다시 곱하지 않는다.
- 합산 계좌의 일수익률 = 슬리브 평가액 합의 전일 대비 변화율. 합산 계좌의 투자 비중·보유 수·회전율·비용은 슬리브 값을 전일 슬리브 비중으로 가중해 만든다.
- 같은 종목을 여러 구성요소가 동시에 들어도 그대로 둔다(계좌 단위로 합쳐 보고만 한다).

## 10. 게이트 (기존 정의 그대로, 완화 없음)

A(069500 대비 CAGR +2%p ∧ MDD 이하), B(세 구간 중 2개 이상에서 069500을 CAGR로 앞서고 MDD 이하), C, D, E, F, G, H는 `scripts/researchGates.ts` 정의를 그대로 쓴다. **G = 구성요소 진입 건수의 합(평가 시작 이후) ≥ 100, 완화 없음.** 이번에 해석을 고정하는 항목:

- **C (하루 지연)**: 각 구성요소를 원래 규칙으로 하루 지연(lag 2)해 돌린 순수익을 같은 규칙으로 합산한다. CAGR 하락 ≤ 1%p ∧ MDD 악화 ≤ 2%p.
- **D (이웃)**: 비율 변형과 구성요소 하나 제외 변형을 모두 평가 구간 CAGR ≥ 069500이어야 통과. P1 = (PE4 40/W3 30/LV1 30), (30/40/30), (30/30/40) + PE4 제외·W3 제외·LV1 제외(나머지 1/2씩). P2 = 한 구성요소 35%(나머지 21.67%씩) 4개, 한 구성요소 15%(나머지 28.33%씩) 4개 + 한 구성요소 제외(나머지 1/3씩) 4개. P3 = PE4 60/40, 40/60 + 한쪽 단독(= 구성요소 하나만 100%). 단독 변형도 CAGR ≥ 069500이어야 한다(완화 없음). 목록은 `lib/strategyAllocationConfig.ts`에 있다.
- **E (상위 3개 거래 대체)**: **구성요소마다** 평가 구간에 닫힌 거래 중 그 구성요소 계좌 대비 손익 상위 3개를 069500 일수익률로 대체한 순수익을 만든 뒤 합산한다(합산 계좌 기준 상위 3개가 아니다). 평가 구간 전체 CAGR ≥ 069500. 평가 함수의 "E:" 줄에 적히는 거래 이름은 합산 기준 표시일 뿐이며, 실제 대체한 구성요소별 거래 목록을 따로 출력한다.
- **F (무작위 대조)**: 구성요소마다 **원래 시험의 무작위 대조**(같은 신호일·같은 주문 수, 같은 청산 규칙, 시드 20261022, 1,000회)를 **같은 번호끼리** 합산 규칙(같은 비율·같은 리밸런싱)으로 합쳐 1,000개 분포를 만들고, 후보 실제 CAGR의 백분위가 기존 임계(F_F_MIN_PCTILE)를 넘어야 한다. 참고로 1 − 0.05/3 = 98.33 이상도 표시한다.
- **H**: 기준선 069500으로 판정(조건1 CAGR ≥ 기준선 + 1%p, 조건2 MDD ≤ 기준선 − 3%p ∧ CAGR ≥ 기준선 − 1%p; 연구 PEAD와 같은 상수). PE4 단독 대비는 참고 표시이며 판정에 쓰지 않는다. B, E 등 임계는 `lib/kodexSectorSatConfig.ts` 상수.
