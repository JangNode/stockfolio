# DS15 사전등록 (DS15L 339 · DS15M 340)

연구 브랜치 `claude/ma-v3-portfolio-cap-run` 전용. main 병합·변경·운영 적용·PR·pg_cron 등록 없음. **가격 데이터만 사용**(재무·공시 미사용). 연구 DB 쓰기 0, DART 신규 호출 0, 외부 호출 0, 키 값 출력 없음, 데이터 파일 artifact 없음. 사전 점검 전에 이 문서를 먼저 커밋하며, **이후 정의·값·변형·재시험을 바꾸거나 추가하지 않는다**(구현의 논리 결함만 사유를 기록하고 고친다). 구현은 `scripts/research-batch5.ts`(ALLOC_MODE `ds15pre`·`ds15test`·`ds15info`·`ds15info2`), 기준값은 `lib/ds15Config.ts`.

## 0. 선택 편향 고지 (문서 첫머리) — 독립 증거가 아니다
**이 가설은 DS13(DS13L·DS13M)과 RM1SC의 통과 결과를 본 뒤 두 구조를 합쳐 만든 변형이며 선택 편향이 매우 크다.** 같은 데이터·같은 구간(2011~2026, 이미 반복해서 본 오염된 구간)에서 이미 통과한 두 구조(DS13의 3계좌 월 재조정, RM1SC의 RM1 손절)를 결합한 것이라 **통과해도 독립된 증거가 아니고, 포워드 확인 대상일 뿐 확정이 아니다.** 이웃값(게이트 D)을 포함해 누적 시험 338 → **340**, 우연 통과 기대 340 × 0.05 = **17.00건**(근사). DS15L·DS15M의 결과 숫자는 이 문서 커밋 전에 보지 않았다.

## 1. 정의 (사용자 지정)
- **DS15L (339)**: **코어 40%(DS6 코어) + RM1S 30% + LV1 30%(저변동)**, **월 리밸런스**(월말 종가에 목표 금액을 계산해 다음 거래일 종가에 이동, 이동 비용 `CS_MOVE_COST` 0.25%, DS13과 같은 `combineN`). **RM1S** = RM1 신호(K200P 잔차 모멘텀 상위 20, 순위 40 안이면 유지, 월말 신호) + **진입 후 최고 종가 대비 −20% 손절**(다음 거래일 종가 전량 매도, 현금 보유, 다음 월말까지 재진입 없음; 앞선 RM1S(329)와 같은 구현). **위성 내부 규칙은 기존과 완전히 같다**(RM1S = 329, LV1 = DS13L의 LV1).
- **DS15M (340)**: DS15L과 같되 **LV1 자리를 MV1(최소분산)로 교체**(DS13M의 MV1과 같음).
- **이웃값(게이트 D, 한 번에 하나만 변경)**: **손절 −15%·−25%**, **코어 35%·45%(위성은 비율 유지 → 35/32.5/32.5, 45/27.5/27.5)**. DS15M은 DS15L과 같다. 모두 연속 전체 CAGR ≥ 069500 원주가여야 D 통과(기존 정의).
- **시작·구간**: 시작 2011-02-01(RM1·DS13과 같은 첫 신호일 2011-01-31), 연속 + 3구간(2011-02~2016-12-29 / 2017-04~2021-12 / 2022-01~2026-10-26).
- **데이터 표준**: K200P 17건 보정(`correct=k200p17`) + 의심 종목-일 0% 처리 794건(`zero=1`), 처리 없음 결과는 정보용. 비용·슬리피지·세금·소멸 처리는 각 하위 계좌의 기존 규칙 그대로(수수료 0.015%/편도, 매도세 시기별, 현금 이자 0, 수정주가, 벤치마크 069500 원주가).

## 2. 사용자 지정에 없던 부분, 구현상 정한 값 (결과 전 고정)
- **하위 계좌 정의는 새로 만들지 않는다**: 코어 = `coreOf(2)`(DS6 코어, DS13과 같은 코드·캐시), 모멘텀 위성 = 앞선 RM1S(`mkRMS`, `lib/stopConfig.ts`의 `RM1S_P0`·`RM1S_NB`, 손절 구현 `makeStopper`), 저위험 위성 = DS13의 LV1(`lv1Of`) / MV1(`B5_MV_P0`). 합성은 DS13의 `combineN`(하위 계좌 비중 40/30/30, 월 1회 목표 금액 이동)이다. 따라서 DS15L은 DS13L에서 모멘텀 위성만 RM1 → RM1S로 바꾼 것, DS15M은 DS13M에서 같은 교체를 한 것이다.
- **불변식(사전 점검)**: 손절을 끈(−100%) RM1S는 기본·하루 지연 경로 모두 RM1과 일별 수익률까지 같고, **손절을 끈 DS15L·DS15M은 DS13L·DS13M과 일별 수익률까지 같다**(하위 계좌와 합성 경로가 DS13과 같음을 확인).
- **게이트 F(무작위 대조)**: 기존 방식, 백분위 95 이상, 참고선 1 − 0.05 ÷ 2 = 97.50. 모멘텀 위성은 RM1S 진입 건수·보유 일수 분포로 RM1 후보 풀에서 임의 종목을 1/20씩 담는 **손절 없는** 무작위 대조(RM1SC 시험과 같은 방식), 저위험 위성은 DS13과 같은 무작위 대조(LV1 = 기존 표본, MV1 = MV1 무작위), 코어는 실제 그대로 40/30/30으로 합성(시드 20261022, 1,000회).
- **게이트 E**: 두 위성의 닫힌 거래 중 계좌 기준 손익 상위 3개를 069500 수익률로 바꾸고 코어는 실제 그대로 돌린 연속 전체 CAGR ≥ 069500(DS13과 같은 정의). G는 코어 + 두 위성 진입 합 ≥ 100건, H는 069500만 판정(CAGR +1%p, 또는 MDD 개선 3%p ∧ CAGR ≥ −1%p).
- **비교 기준**: 069500 원주가, DS6(일별 40:60)·DS13L·DS13M·RM1SC(월 리밸)를 같은 시작일(2011-02-01)로 새로 계산해 나란히 비교.

## 3. 평가·판정
관문 A~H는 기존 정의·구현 그대로(기계 판정, F는 백분위 95 이상). 연속 + 3구간 CAGR/MDD, 069500 원주가 기준, 탈락이면 부족한 폭 표기. 이 두 가지만 시험하고 추가 변형·재시험 금지(누적 340에서 종료).

## 4. 정보용 보고 항목 (판정 불사용)
연도별 069500·DS6·DS13L 대비 승패(**2025·2026년 069500 대비 수익 별도 표기**), 승률·손익비·거래당 기대값, 연 회전율·비용 합계, 상위 10개 거래 손익 비중, 삼성전자·SK하이닉스 평균 비중과 **두 종목 수익을 0으로 둔 CAGR**(`NEUTRALIZE_CODES`), **월 신호일 5·10거래일 앞당김 민감도(RM1SC·DS13L·DS13M과 비교)**, 손절 발동 횟수와 손절 후 21거래일 수익, VB1 MDD 구간(2018-01-29~2020-03-23) 구간 수익·낙폭, DS13L·RM1SC(그 밖에 DS13M·DS6·069500)와의 일간 상관, 의심 종목-일 처리 없음 비교, 하루 지연(C), 하위 계좌별 손익 분해, 누적 시험 횟수와 우연 통과 기대 건수. 모든 관문 통과 시 "통과(선택 편향 큼, 포워드 확인 필요)"와 포워드 도구 추가 여부만 제안(구현 금지; **DS13L·RM1SC보다 신호일 민감도와 삼성전자 의존이 실제로 나은지 근거와 함께**). 통과 후보가 없으면 같은 가설의 재시험은 하지 않는다.

## 5. 사전 점검(`ds15pre`, DS15L·DS15M 성과 미계산, 하루 지연 경로 포함, 시험 전에 모두 통과해야 함)
DS6 재현(연속 11.70 / 39.15, 불일치면 중단) · **DS13L·DS13M·RM1SC 재현**(보정만 적용 표준: DS13L 12.40 / 37.91, DS13M 11.57 / 40.29, RM1SC 13.38 / 34.87 — ds13 시험·RM1S 기록과 같은 기준; 보정 + 0% 처리 표준: DS13L 12.47 / 37.91, RM1SC 13.48 / 34.87, DS13M은 기록 없어 값만 보고) · **불변식**: 손절을 끈 RM1S = RM1(기본·하루 지연, 일별 수익률·진입·거래·체결일 수까지), **손절을 끈 DS15L·DS15M = DS13L·DS13M(기본·하루 지연, 일별 수익률까지)** · DS15의 모멘텀 위성이 RM1SC의 RM1S 위성과 일별 수익률까지 같음, 저위험 위성·코어가 DS13과 같음 · 보정·의심 종목-일 0% 처리 적용 · 소멸 관례 확인 · 하위 계좌 날짜 축·첫 체결일 · 첫날 비중 40/30/30 · 손절 발동 건수 = 앞선 RM1S와 같음. 하나라도 어긋나면 시험하지 않고 보고한다.

## 6. 한계(미리 공개)
세 구조를 같은 데이터에서 이미 본 뒤 합쳤으므로 **통과해도 독립 증거가 아니다**, 코어(사실상 삼성전자) 의존이 DS6·DS13과 같다(손익의 60~66%), 월 리밸 신호일 민감도(DS13L·RM1SC의 한계 그대로), RM1S 손절은 방향을 맞히지 못하고 낙폭만 줄인다는 앞선 결과의 한계, 모멘텀 위성 비중 30%로 줄어 손절 효과가 희석됨, 선택 편향, 오염된 구간.
