# 저PBR 대형주 사전등록 (VL1 316 · VL1C 317: K200P(PIT) 안 저PBR)

연구 브랜치 `claude/ma-v3-portfolio-cap-run` 전용. main 병합·변경·운영 적용·PR 없음. 연구 DB 쓰기 0, 외부 호출 0(저장된 자료만), 키 값 출력 없음, 데이터 파일 artifact 없음(저장소 공개). 사용자 지정 2026-11-22. 이 문서는 **첫 시험 전에** 커밋한다. 등록 후 정의 변경 금지, **이 2개만 시험하고 추가 변형·재시험 금지(누적 317에서 종료)**. 구현의 논리 결함만 사유를 기록하고 고친다.

## 0. 선택 편향 고지 (문서 첫머리)
**이 가설은 VB1(311), VB1C(313), VB1F(314), DS14(315) 결과를 모두 본 뒤 만든 것이며 선택 편향이 크다.** VB1이 소형주 비중이 커서 2018-01-29~2020-03-23에 MDD 64%를 낸 것을 보고(VB1은 같은 구간 069500 −39.85%, KOSDAQ −52.13%), 유니버스를 대형주(K200P)로 좁히면 낙폭이 줄지 보는 가설이다. 통과해도 **포워드 확인 대상일 뿐 확정이 아니다.** 시험 구간은 이미 반복해서 본 오염된 구간이다. 누적 시험은 315 → 317, 실력이 없어도 5% 기준 하나를 우연히 넘는 후보 기대는 317 × 0.05 = 15.85건(근사).

## 0.1 사전 확인 (중복 시험 여부, 2026-11-22)
`docs/research/` 전체에서 "PBR", "저PBR", "K200P + PBR"을 찾았다. 가장 가까운 것: **R0~R4**(r-allcap-fundamentals-prereg: 전 종목·K200P 다른 신호에 PBR 중앙값 이하 *필터*를 얹음)와 **guru-composite**(1/PBR을 V 요인 하나로 다른 요인과 합성). **K200P(PIT) 안에서 PBR 하위 30종목을 단독으로 동일 비중 보유하는 정의는 기록에 없다.** VB1~VB1F·DS14는 전체 유니버스(BS1 적격)였다. 따라서 진행한다. 정책: 공시는 **정기 재무로 PBR을 만드는 용도로만**, 접수일 < 신호일(다음 거래일부터 반영). 이벤트 반응형 없음.

## 0.2 시장 필터를 쓰지 않는 이유 (VB1F에서 확인된 사실)
VB1F(314)에서 월말 069500 종가 < 200일 단순이동평균이면 주식 50%로 줄인 결과 연속 CAGR이 10.07 → 7.55(−2.52%p)로 떨어졌고 MDD는 64.17 → 49.52(−14.66%p)에 그쳤다. 필터 가동 기간(전체의 42.19%) 일수익률 단순 합이 필터 없는 VB1 94.18%p 대비 47.18%p로 **필터 손익 기여 −47.00%p**였다. 가치 전략에는 불리해 이번에는 시장 필터를 쓰지 않는다(value2-summary.md).

## 1. 공통 데이터·정의 (VB 시험과 같은 것은 그대로)
value-prereg.md §0.2·§1, value2-prereg.md §1과 같다: 자본총계 분모 PBR(접수일 < 신호일 중 가장 최근 보고서, 경과 400일 초과·자본 ≤ 0 제외), BS1 적격 유니버스·제외 조건, 신호일(월말 마지막 거래일 종가)·체결(다음 거래일 종가)·수수료 0.015%/편도·매도세·슬리피지(K200P 구성원 0.1%, 그 밖 0.2%)·현금 이자 0·수정주가·벤치마크 069500 원주가, 소멸 처리(마지막 종가 청산하되 직전 20거래일 중 거래정지 5일 이상이거나 마지막 종가 1,000원 미만이면 전액 손실). **데이터 표준**: K200P 17건 보정(`PRICE_CORRECTION=k200p17`), 의심 종목-일 0% 처리(`ZERO_SUSPECT=1`, 793건). 처리 없는 결과는 정보용(시험 번호 없음, 판정 불사용). **기간**: 첫 신호일 2011-05-31, 수익률 집계 2011-06-01~2026-10-26, 연속 전체 + 3구간(2011-06-01~2016-12-29 / 2017-04-04~2021-12-31 / 2022-01-01~2026-10-26), 069500도 같은 구간 기준선.

## 2. 시험 316 — VL1 (K200P 안 저PBR 30종목)
- **VB1 정의 그대로**: PBR 하위 30종목 동일 비중(종목당 1/30), 기존 보유는 PBR 순위 하위 90위(30 × 3) 안이면 유지, 빈자리만 채움, 월말 신호.
- **유니버스 제한**: 신호일 시점의 **K200P(PIT)**(그날 행이 있는 코스피 구성원 중 제외 규칙 적용 후 시총 상위 200, 앞선 연구의 `rank200`과 같음) **∩ BS1 적격 ∩ PBR 있음**.
- **후보가 30개 미만이면** 그만큼만 종목당 1/30(3.33%)씩 담고 나머지는 현금(이자 0).
- **D 이웃값(한 번에 하나씩, 5개)**: 종목 수 20 · 40 / PBR 보고서 최대 경과일 300 · 500 / **유니버스 K200P 대신 시총 상위 300**(= BS1 적격 종목 중 신호일 시총 상위 300, 코스피·코스닥 합, PBR 있는 종목에서 PBR 하위 30).

## 3. 시험 317 — VL1C (DS6 코어 40% + 위성 60% = VL1)
- RM1C·MV1C·BS1C·VB1C와 같은 합성: DS6 코어 40%(`coreOf(2…)`, 시총 상위 2) + 위성 60% = VL1, 일별 40:60 재조정, 이동 비용 0.25%(`CS_MOVE_COST`). **코어 종목(예: 삼성전자)이 VL1에서도 뽑히면 각 하위 계좌가 독립으로 보유해 계좌 기준 비중이 합산된다**(각자 비용 부담).
- **D 이웃값**: 위성 VL1의 이웃값(위 5개).

## 4. 관문 A~H (기존 정의·구현 그대로, 기계 판정, `scripts/researchGates.ts`; F는 백분위 95 이상)
A 연속 전체 069500 대비 CAGR +2%p 이상 ∧ MDD가 069500과 같거나 작음. B 3개 구간 중 2개 이상에서 069500을 이긴다(구간 CAGR이 크고 MDD가 같거나 작음). C 하루 지연에서 CAGR 하락 ≤ 1%p ∧ MDD 악화 ≤ 2%p. D 이웃값 모두 연속 전체 CAGR ≥ 069500. E 손익 상위 3개 보유 구간을 069500 수익률로 대체해도 연속 전체 CAGR ≥ 069500(VL1C는 위성의 닫힌 거래 기준, 코어는 실제 그대로). F 무작위 진입일(같은 신호 건수·보유 기간 분포, 같은 유니버스에서 PBR 있는 종목 무작위, 1,000회, 시드 20261022) 백분위 ≥ 95. G 진입 건수 ≥ 100. H 069500 대비 CAGR +1%p 이상, 또는 (MDD 개선 3%p 이상 ∧ CAGR ≥ −1%p). 통과 = 전부 통과, 게이트는 완화하지 않는다. **F 참고선 1 − 0.05 ÷ 2 = 97.50**(판정 기준 자체는 95).

## 5. 보고 항목 (구현 후 출력과 대조한다)
- **R1** 연속·3구간 CAGR/MDD/최악 12개월/샤프, **R2** 관문별 판정(탈락이면 기준과의 차이), **R3** 연도별 승패(069500 대비 · DS6 대비 · DS13L 대비), **R4** 연 회전율·비용, **R5** 같은 데이터·구간 나란히 비교 표(DS6, DS13L, DS13M, VB1, VB1C, RM1C, DS14, VL1, VL1C, 069500).
- **정보용**: **J1** VB1의 MDD 구간(2018-01-29~2020-03-23)에서 VB1 보유 종목을 **신호월 시가총액 3분위**(그 달 월말 BS1 적격 ∧ PBR 있는 유니버스의 시총 3등분, 보유 구간 내내 고정, 직전 월말 분류가 없으면 최대 3개월 전까지 소급)로 나눠 구간 종목 가격 손익 기여(%p 단순 합)를 분해하고 하위(소형) 3분위가 낙폭의 몇 %를 만들었는지(= 하위 합 ÷ 전체 합) 보고, **J2** VL1·VB1·RM1·DS13L 사이 일간 수익률 상관계수(공통 구간), **J3** VL1·VB1 보유 종목 평균 PBR, **J4** VL1·VL1C의 삼성전자·SK하이닉스 보유 여부(월말 목표 보유 횟수)와 평균 목표 비중(계좌 기준 %), **J5** 하루 지연(C)에서의 CAGR·MDD 변화, **J6** 후보 30개 미만 월 수와 후보 수 최소·평균, **J7** 의심 종목-일 처리 유무 비교(정보용), **J8** 누적 시험 횟수와 우연 통과 기대 건수.
- 모든 관문을 통과하면 "통과(선택 편향 큼, 포워드 확인 필요)"로 표시하고 포워드 도구에 추가하는 데 필요한 작업만 제안한다(구현 금지).
