## 구현 세부 (실행 전 고정)

1. **입력·비용**: scripts/research-e-new-goal.ts(75c8b69)와 같은 입력과 비용을 쓴다. Parquet 2010~, 적용된 조정 이벤트, 월말 시장 목록, dart 이름, 업종, 069500 raw·adj, 하루짜리 튐 정제를 포함한다.
   - 주식 매수 = 종가 × (1 + 0.1%) × (1 + 0.015%), 매도 = 종가 × (1 − 0.1%) × (1 − 0.015% − 그날 거래세)다. 폐지 청산 규칙도 같다(마지막 행이 데이터 끝 − 14일보다 이전이면 그 종목이 처음 행이 없는 날 직전 평가액으로 매도).
   - 외부 요청 0, DB 쓰기 0, 1회 실행이다. 구간은 학습 2010-07-01~2016-12-31, 확인 2017-01-01~2021-12-31, 보류 2022-01-01~데이터 끝이고 전 기간은 2010-07-01~데이터 끝이다.
   - 시뮬레이션은 2010-06-30(CAL)부터 현금으로 시작한다. SMA 200일 자료가 필요해 첫 진입은 2010년 하반기 이후다.
2. **유니버스 K200P(d)**: d 행이 있고, d의 20일 평균 거래대금(당일 제외 직전 20행) ≥ 5억이며 제외 규칙(4c1557a)에 걸리지 않는 종목 중, d 이하 가장 최근 월말 시장 목록에서 KOSPI인 종목을 d 시총 내림차순(동점 코드 오름차순) 상위 200개로 한다(D1 주간 연구의 kAtW와 같다).
3. **이동평균·신호**: 종목 자신의 수정 종가 행 순서에서 단순이동평균을 쓴다. SMA_N(i) = 행 i−N+1..i 종가 평균이고 N행 이상이 있어야 한다.
   - 골든크로스일 = 행 i에서 SMA_short > SMA_long이고 행 i−1에서 SMA_short ≤ SMA_long(둘 다 계산 가능)인 날이다.
   - 데드 상태 = 행 i에서 SMA_short < SMA_long이다.
   - 기본 (short, long) = (50, 200), R1에서 (40, 150)·(60, 250)이다.
4. **일별 업종 모멘텀**: D1 주간 연구의 rankedW와 같다. 신호일 d마다 K200P(d)에서 업종별 시총가중 수익률(시작 = d의 6개월 전 같은 일자, 달에 없는 날이면 말일로 맞춘 날짜 이하 마지막 행 종가, 끝 = d의 1개월 전 같은 방식, 가중 = 시작 시점 시총)을 구한다. 유효 종목 2개 이상 업종만 쓰고 미분류는 뺀다. 모멘텀 내림차순(동점 업종 코드 오름차순) 앞 K개가 상위 업종이다. 기본 K = 3, R1에서 2·4다.
5. **일별 루프** (CAL 인덱스 c, 종가 판단 → 실행일 c + lag, 기본 lag = 1, 지연 변형 lag = 2):
   - (a) 평가: 보유 종목은 그날 행이 있으면 평가가격을 갱신한다.
   - (b) 실행: 오늘 실행일인 청산을 먼저 처리하고(그날 행이 없는 종목은 다음 거래일로 미룬다), 이어 진입을 처리한다.
   - (c) 판단(종가): 보유 종목마다 그날 행이 있으면 최고 종가를 갱신하고 청산 조건을 확인한다. 이어 진입 후보를 구해 슬롯만큼 진입 주문을 낸다.
6. **진입**: 판단일 d의 후보 = K200P(d) 종목 중 d가 골든크로스일이고(G1·G2·G4는 상위 K업종 소속 추가), 현재 보유·주문 중이 아니며, 직전 청산 실행일 e에 대해 d − e ≥ 20(CAL 인덱스)인 종목이다. 후보는 d 시총 내림차순(동점 코드 오름차순)으로 세운다. 빈 슬롯 수 = 최대 보유(기본 5) − (보유 종목 수, 청산 주문 중인 것 포함) − (이미 낸 진입 주문 수)다. 슬롯 수만큼 앞에서 자른 목록을 실행일에 처리한다(슬롯보다 많은 신호는 이월하지 않는다).
   - 실행일의 처리: 그날 행이 없으면 취소한다. 계좌 평가액 V = 현금 + 보유 평가액(청산 처리 후, 같은 실행일의 진입 전)이다. 투입액 = min(0.20 × V, 현금)이고 0 이하이면 건너뛴다. 연속 비중 판에서는 소수 주를 허용하고 정수 주 판은 아래 시드 모의를 따른다.
   - 매수 후 보유 가치 = 투입액 ÷ (1 + 매수 비용률)이다. 진입가 = 실행일 수정 종가이고, 이후 최고 종가 계산은 실행일부터 시작한다.
7. **청산**: 판단일 d의 보유 종목 수정 종가 P에 대해 수준 L = max(진입가 × (1 − stop), 최고 종가 × (1 − trail))이다. P ≤ L이면 청산 신호이고, 아니면 데드 상태이면 청산 신호다.
   - 사유 표기: L 조건이 맞으면 진입가×(1−stop) ≥ 최고 종가×(1−trail)일 때 "손절", 아니면 "트레일링"이다. 둘 다 맞을 때도 손절/트레일링을 먼저 표기하고, L 조건이 아니면서 데드 상태이면 "데드크로스"다.
   - G1은 stop·trail 없음(데드크로스만), G2·G3은 stop 0.10, trail 0.25, G4는 stop 0.10, trail 0.30이다.
   - 청산 주문은 d + lag 종가에 매도한다. 청산 실행일을 쿨다운 기준 e로 쓴다.
8. **보유 평가·보고 지표**:
   - 일별 수익률 = 그날 종가 계좌 평가액 ÷ 전일 평가액 − 1이다. 매수·매도 비용은 실행일 수익률에 반영된다.
   - 기간 끝에 열려 있는 거래는 청산하지 않고 평가액에만 반영한다(거래 통계에서는 제외한다).

   - D(R1): 이웃값마다 전 기간 CAGR ≥ B&H 가격 전 기간 CAGR이어야 하고 모두 O여야 한다. 하나씩만 바꾼다.
     - 이동평균 (40, 150), (60, 250)

   - E(R2): 기본 실행(lag = 1)의 닫힌 거래 중 거래 기여 = (매도 대금 − 투입액) ÷ 진입 실행일 V가 큰 상위 3개 거래를 고른다. 각 거래를 같은 진입·청산 실행일 동안 069500 원주가(B&H 가격) 일수익률로 평가하도록 바꾸고(비용은 같음) 전체를 다시 계산한 전 기간 CAGR이 B&H 가격 전 기간 CAGR 이상이어야 O다.
