# DS13L·DS13M 포워드 관찰 도구 (연구 브랜치 전용, 운영 적용 금지)

정의 동결: `ds13-forward-freeze.md`(커밋 3e8a2c1, 변경 금지). 이 문서는 도구 구현·검증 기록이다. 시험이 아니다(누적 310 유지).

## 1. 구성
- `lib/ds13Engine.ts`: `scripts/research-batch5.ts` main 안에 있던 계산 코드(코어·RM1·MV1·LV1 하위 계좌, 재조정 시뮬레이터 호출, 3계좌 합성 `combineN`, `d13Of`)를 로직 변경 없이 옮김. 바뀐 점은 (a) 인터페이스를 모듈 수준으로 올림 (b) 쓰이지 않던 `DS8D`·`DS9D`·`bRetAxis`·`coreHolds`·`evLine` 삭제 (c) 보고용 선택 인자 2개 추가(`runLV1`의 `onDay`, `d13Of`의 `shift`; 기본값이면 기존과 동일).
- `scripts/ds13ForwardRecord.ts`: 포워드 기록. `scripts/research-ds6-forward.ts`가 호출한다(기존 DS6 로그 로직은 그대로).
- `lib/ds13ForwardConfig.ts`: 기록값·파일 경로·열 이름 상수.
- 워크플로 `which=ds6fwd`(검증 → 관찰 2단계)에 `PRICE_CORRECTION=k200p17`을 항상 적용(K200P 17건 보정 기본 적용). 도구는 이 보정이 없으면 실행을 거부한다.
