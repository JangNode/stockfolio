# 연구 C — 투자 대가 모델의 숫자 규칙 종합 점수 (C1 = 시도 208, C2 = 시도 209, C3 = 시도 210) 사전등록

작성 2026-10-26(사용자 지정). **이 문서는 시험 실행 전 사전등록이다. 시험 실행은 사용자 승인 후에만 한다.** 개별 국내 주식과 현금만 쓴다(ETF 매매 금지, 069500은 기준선 전용). 숫자 규칙만 쓰고 LLM 판단은 쓰지 않는다. 모든 구간 성적은 개발 데이터 내 성적이다. 연구 브랜치 claude/ma-v3-portfolio-cap-run에서만 작업하고 main 병합은 하지 않는다.

> **사전 점검 결과 요약(3절 아래 "0단계"): 현재 규칙대로면 C1·C2·C3 모두 "실행 불가"이고 번호 208~210은 소진하지 않았다.** Q 점수는 "당기순이익 최근 8분기", Gr 점수는 "매출액·영업이익 1년 전 TTM"의 SMALL 재무 커버리지가 평가 구간의 어느 해에서 70% 미만이다. 기준(70%)은 완화하지 않았다.

## 1. 목적

"유명 투자자들이 쓰는 숫자 기준(싸다·좋은 회사다·성장한다)을 일별로 한 점수로 합쳐 상위 10종목을 들고 가면, 소형주(SMALL)에서 069500보다 수익이 높은가?"를 본다. 점수 가중치는 균등으로 고정하고(튜닝 금지), 가치(V)·품질(Q)·성장(Gr)을 어떻게 섞느냐만 C1~C3로 비교한다.

## 4. 점수 정의 (실행 전 고정; "해석"은 지시 문구에 없어 문서화 시 정한 것 — 승인 시 함께 확인받는다)

기준값은 lib/guruCompositeConfig.ts, 계산은 lib/guruFinMetrics.ts·lib/guruScoring.ts(순수 함수), SMALL 기준·200일·70%·평가 구간·슬리피지는 연구 R의 상수(R_*)를 그대로 쓴다.

1. **유니버스 SMALL(d)**: 연구 R과 같다 — d 행이 있고 제외 규칙(4c1557a: 우선주·ETF·스팩·리츠)에 걸리지 않으며, d 이하 가장 최근 월말 시장 목록에서 코스피·코스닥이고, PIT 시총 1,000억 이상 5,000억 미만, 20일 평균 거래대금 ≥ 2억, 원 종가 ≥ 1,000원.
2. **재무 값(PIT)**: fin.parquet 값 중 접수일이 d보다 앞선 가장 최근 비정정 정기보고서(최초 접수일부터 200일 이내)의 값. 정정 접수일 D부터 정정 후 값을 쓰고 D 전까지는 원본(보관돼 있지 않으면 "자료 없음"), 연결 우선·완비되지 않으면 별도, 한 묶음 안에서 연결/별도를 섞지 않는다(연구 R과 같은 규칙, rFinMetrics.eventsByCorpPit와 동일). 어떤 계산도 이벤트 기준일 이후에 접수된 보고서를 쓰지 않는다.
3. **TTM**: 사업보고서는 연간 값. 분기·반기·3분기 보고서는 직전 사업연도 연간 + 올해 누적 − 전년 같은 시점 누적. **1년 전 TTM** = 직전 사업연도의 직전 연도 연간(직전 사업보고서의 전기 열) + 전년 누적 − 전전년 같은 시점 누적(전년 같은 종류 보고서의 전기 열). 하나라도 없으면 계산 불가.
4. **V**: 항목 = [자본총계 ÷ 시총(= 1/PBR), TTM 순이익 ÷ 시총]. TTM 순이익 > 0 이고 자본총계 > 0 이어야 한다.
5. **Q**: 항목 = [ROE = TTM 순이익 ÷ 평균 자본총계, 영업이익률 = TTM 영업이익 ÷ TTM 매출액, −(부채총계 ÷ 자본총계), 최근 8분기 중 분기 순이익 > 0 인 분기 수]. 계산 불가 규칙:
   - **해석**: 평균 자본총계 = (보고서 시점 자본총계 + 직전 사업연도말 자본총계) ÷ 2. fin.parquet은 보고서마다 당기 시점과 전기말 자본총계만 갖고 있다.
   - **해석**: 자본총계 ≤ 0, 평균 자본총계 ≤ 0, TTM 매출액 ≤ 0 이면 Q 계산 불가(ROE·부채비율이 뜻을 잃는다).
   - **해석**: 분기 순이익은 분기 보고서의 당분기 값, 4분기는 연간 − 3분기 누적, 없으면 다음 해 같은 보고서의 전기 열. 최근 8분기가 **전부** 계산돼야 값이 있다(일부만 있어 비율로 환산하는 것은 하지 않는다).
6. **Gr**: 항목 = [TTM 매출액 ÷ 1년 전 TTM 매출액 − 1, TTM 영업이익 ÷ 1년 전 TTM 영업이익 − 1]. **해석**: 1년 전 값이 0 이하이면 성장률이 정의되지 않아 계산 불가(적자 → 흑자 전환 종목은 Gr 후보가 아님).
7. **백분위·점수**: 후보 집합 = 그날 SMALL(d) 종목 중 그 후보(C1~C3)가 쓰는 점수가 모두 계산되는 종목. **해석**: 백분위는 후보(C1~C3)별 후보 집합 안에서 매긴다(같은 종목의 V 백분위도 C1과 C2에서 모집단이 달라 다를 수 있다). 항목 백분위 = (평균 순위 − 0.5) ÷ n, 클수록 좋은 방향(부채비율은 부호 반전), 동점은 평균 순위. 묶음 점수 = 항목 백분위의 평균, 종합 = 묶음 점수의 평균(균등). 종합 순위 = 종합 점수 내림차순 1, 2, 3, …(동점은 코드 오름차순).
8. **매매(일별 루프)**: 판단일 d(종가), 체결 d의 다음 거래일 종가. 보유 종목의 d 종합 순위가 30위 밖이거나 후보에서 빠졌으면(점수 계산 불가·SMALL 이탈·행 없음 포함) 청산 주문. 빈 슬롯 수 = 보유 수 − (보유 종목 수, 청산 주문 중 포함) − (이미 낸 매수 주문 수) 만큼, 후보 중 종합 순위가 높고 보유·주문 중·재진입 금지(마지막 청산 후 20거래일 이내)가 아닌 종목을 매수 주문. 종목당 투입 = min(계좌 평가액 ÷ 보유 수, 현금), **해석**: 균등 비중 = 1/보유 수(기본 10 → 10%, 이웃 7 → 1/7, 15 → 1/15). 매수 후 비중 재조정 없음. 후보가 모자라면 현금. 거래정지(거래량 0)·행 없음 처리와 상장폐지 강제 청산은 연구 R·A·B의 공용 슬롯 시뮬레이터(lib/slotSim.ts)와 같다.
9. **평가 구간**: 평가 시작 판단일 2017-04-03, 수익률 집계 2017-04-04~최신. 구간 2017-04-03~2021-12-31 / 2022-01-01~. 비용 = 0.015%/편도 + 매도세, 슬리피지 SMALL 0.2%. 현금 이자 0%.
10. **정보용 비교 행(판정 불사용)**: "후보 전체 균등 보유" — 같은 유니버스·같은 비용·같은 체결 규칙에서 후보 집합 종목을 순위와 무관하게 모두 같은 비중으로 들고 가는 대조(후보가 된 다음 거래일 매수, 후보에서 빠지면 다음 거래일 매도, 재진입 금지 20거래일). 평균 후보 수가 340~415개라 보유 한도를 상수(예: 400종목, 종목당 1/400)로 정해야 하는데 **해석이 갈리므로 승인 시 함께 확정한다**(승인 전에는 상수를 코드에 넣지 않는다).

## 6. 게이트 (임의 완화 금지, 기존 정의 그대로 — f-daily-trend-prereg.md 구현 세부 9, r-allcap-fundamentals-prereg.md 단계 2)

기준선 B&H = 069500 원주가(가격 수익만, 비용 없음). MDD 비교는 1e-9 허용.

- **A**: 전 기간 CAGR ≥ B&H CAGR + 2%p 이고 MDD ≤ B&H MDD.
- **B**: 구간 2017-04-03~2021-12-31, 2022-01-01~ **두 구간 모두**에서 CAGR > B&H CAGR 이고 MDD ≤ B&H MDD.
- **C**: lag = 2 전 기간에서 기본 CAGR − 지연 CAGR ≤ 1%p 이고 지연 MDD − 기본 MDD ≤ 2%p.

## 10. 경고 문구

- **홀드아웃 오염**: 보류 구간(2022~)은 이미 여러 번 본 데이터이고, 2017-04~2021 구간도 앞선 연구(R 등)에서 반복해 본 구간이라 순수 검증이 아니다.
- **소형주 편향**: SMALL(시총 1천억~5천억) 유니버스는 거래대금이 작아 종가 체결 가정이 낙관적일 수 있고(슬리피지 0.2%는 일부만 반영), 시총 상한 5,000억 도달 시 후보 제외로 매도되는 구조라 "작을 때 사서 커지면 파는" 방향의 편향이 있다. 업종은 현재 값을 과거에 적용한 것이라 PIT가 아니고, 정정 전 원본 값이 보관돼 있지 않아 정정이 많은 종목·연도는 자료가 비어 커버리지가 낮아진다. 지배주주 귀속 자본·순이익이 아니라 총 자본총계·당기순이익을 쓴다.
- **우연 통과 기대 건수**: 이 연구가 실행되면 누적 시험이 210번이 되어 실력이 없어도 5% 수준 기준 하나를 우연히 넘는 후보가 평균 210 × 0.05 = 10.5개 나올 것으로 기대되고, 적어도 하나가 걸릴 확률은 1 − 0.95^210 ≈ 100%다(시험들이 독립이 아니므로 근사). 실제 소진한 시험 수가 210보다 적으면 그 수로 계산해 보고한다(현재 누적 207).
