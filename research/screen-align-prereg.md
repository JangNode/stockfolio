# [임시 연구 — 병합 금지] 스크리닝-백테스트 정렬 연구 사전 등록

작성: 2026-10-12(KST). 결과를 보기 전에 커밋한다. 이 파일은 이후 수정하지 않는다(수정이 필요하면 별도 "정정" 파일로 추가하고 사유를 밝힌다).
대상: ma_cross v2(50/200), reversal_breakout_v2, peg_lynch. 모든 결과는 같은 데이터를 반복 사용한 in-sample이다.

## 1. 공통 조건 (사용자 지정)
2010-01-01~현재, PIT 유니버스, 비용 반영(수수료 0.015%/편, 거래세 일정표, 슬리피지 0.1%/편), 점수 게이트 없음.
기본 유니버스: 신호(진입)일 as-of 시총 ≥ 5천억 + 직전 20거래일 평균 거래대금 ≥ 5억(= 현재 백테스트 배치). (B)에서만 시총 하한을 바꾼다.
데이터·집계: 배치(`scripts/compute-strategy-backtest-summary.ts`)와 같은 Parquet(분할·병합 조정계수 적용)·같은 일별 동일가중 집계 함수.
진입 = 신호 봉 종가, 청산 = 청산 봉 종가. 손절·익절도 종가 기준(장중가 미사용). 기간 끝까지 미청산이면 마지막 봉 종가로 강제청산(거래에 포함).

## 2. 정의
- 구간: 학습 2010-01-01~2018-12-31, 확인 2019-01-01~현재, 전체 2010-01-01~현재. 하나의 연속 실행을 자른 것(경계에서 포지션 재시작 없음). 구간 CAGR·MDD는 해당 구간 일별 수익률로, 승률·손익비·기대값·거래 수·평균 보유일은 진입일이 구간에 속한 거래로 계산.
- 승률 = 비용 반영 수익률 > 0 비율. 손익비 = 평균 이익 ÷ |평균 손실|. 기대값 = 승률 × (손익비 + 1) − 1 (사용자 지정 식).
- 평균 보유일 = 거래별 (청산일 − 진입일) 달력일 평균. 평균 동시 보유 종목 수 = 구간 내 보유 종목이 1개 이상인 날들의 일별 보유 종목 수 평균.
- 신호/진입: 상태 배열(참/거짓/미정)에서 직전=거짓·당일=참인 봉(`lib/backtest.ts`의 전환 감지와 동일). 진입은 그 봉의 유니버스 조건(시총·거래대금)을 충족할 때만. 포지션은 종목당 1개. 진입 후 청산 전까지 새 신호는 무시. 청산 후에는 청산 봉 **이후**에 생기는 새 전환에서만 재진입("재진입 불허"가 기본).

## 3. (A) 청산 규칙 후보 (전략별 3개, 시총 하한은 5천억 고정)
- A0 baseline: 현재 백테스트 청산 — ma_cross = 데드크로스(50<200), v2/peg = 상태 이탈(참→거짓). 손절·익절 없음.
- A1 스크리닝 현재 규칙: 진입가 대비 종가 기준 손절 7% / 익절 20%**만**으로 청산(신호 이탈로는 청산하지 않음 — 스크리닝은 상태 이탈로 닫지 않기 때문). 둘 다 미도달이면 기간 끝 강제청산.
- A2 baseline + 손절 7%만 추가(익절 없음): 신호 이탈 또는 종가 ≤ 진입가×0.93 중 먼저 오는 쪽으로 청산.
- 참고용(후보·시도 수에 미포함): A1/A2에서 "재진입 허용"을 같이 돌려 차이를 한 줄로 보고. 허용 규칙 = 청산 봉 이후 처음으로 상태가 참이고 유니버스 조건을 충족하는 봉에서 즉시 재진입(스크리닝이 닫힌 뒤 다음 실행에서 새 행으로 등록하는 동작과 같음). ma_cross는 이벤트형이라 해당 없음(불허와 동일)으로 표기.
- baseline에서 재진입이 없음을 확인: A0 거래에 대해 같은 종목의 연속 거래가 "직전 청산 봉 이후 새 전환"에서만 시작됨을 검사해 위반 건수 보고(기대 0).

## 4. (B) 시총 하한 후보 (전략별 4수준)
신호(진입)일 as-of 시총 하한 500억 / 1,000억 / 3,000억 / 5,000억(= A0). 거래대금 5억 필터 유지, 청산은 A0 고정.
추가 보고: 수준별 신호(진입) 수, 시총 구간(500~1,000억 / 1,000~3,000억 / 3,000~5,000억 / 5천억 이상, 진입일 as-of 시총)별 거래당 평균 수익률·승률(500억 하한 실행 기준).
peg_lynch 한 줄 확인: A0 거래 중 "2011~현재 어느 날이든 시총 1조 이상이었던 종목" 비율과 그 안/밖 승률·평균 수익률(스크리닝 후보 풀 영향).

## 5. 판정 기준 (사용자 지정, 결과 전 확정)
### (A) baseline(A0)을 이기는 조건 — 모두 충족해야 채택
1. 학습 구간 CAGR이 baseline보다 높고, 학습 MDD가 baseline보다 나쁘지 않다(≤).
2. 확인 구간에서 CAGR이 baseline 이상이고 MDD가 baseline보다 나쁘지 않다(≤).
3. 거래 수가 baseline의 50% 이상.
4. 기대값이 baseline보다 낮지 않다(≥).
- 3·4의 비교 구간은 **전체 구간(2010~)**으로 확정한다(구간 미지정이라 사전에 고정). 학습·확인 값도 표에 보고한다.
- 하나라도 미충족이면 baseline 유지 → 스크리닝을 baseline 규칙에 맞춘다.
- A1과 A2가 모두 통과하면 학습 Calmar(CAGR÷MDD)가 높은 쪽 1개. 동률이면 규칙이 단순한 A2.
### (B) 하한을 낮추는 조건
5천억 대비 학습·확인 **둘 다** CAGR이 더 높고, MDD가 나쁘지 않고(≤), 거래 수가 늘 때만 해당 하한 채택. 여러 수준이 통과하면 학습 Calmar가 가장 높은 수준. 통과가 없으면 5천억 유지.

## 6. 평가 프로토콜 (확인 구간은 후보당 1번만)
- 학습 구간 조건(1번, (B)는 학습 CAGR 상승·MDD 비악화·거래 증가)을 먼저 평가한다. **학습 조건을 통과한 후보에 대해서만** 확인 구간·전체 구간 수치를 계산해 보고한다. 통과하지 못한 후보는 "확인 구간 미평가"로 표기한다(사용자의 학습/확인 분리 표 요청과의 충돌을 이렇게 정리: 확인 구간을 선택에 쓰지 않기 위함). baseline(A0, 5천억)은 기준선이라 학습·확인·전체 모두 보고한다.
- 확인 구간은 baseline 성과를 이미 본 적이 있어(ma_cross 연구 포함) 깨끗한 홀드아웃이 아니다.

## 7. peg_lynch 예외(구조적 문제의 사전 공개)
peg_lynch는 재무 데이터 한계로 첫 신호가 2021-03 이후라 학습 구간(2010~2018) 거래가 0건이다. 사용자 지정 판정 규칙을 그대로 적용하면 학습 조건 1번을 어떤 후보도 충족할 수 없어(0 vs 0) peg_lynch는 모든 비교에서 "baseline 유지/하한 유지"로 판정된다. 이 규칙은 바꾸지 않는다.
참고용(탐색적, 판정에 쓰지 않음, 시도 수 미산입): peg_lynch만 2021-03~2023-12 / 2024-01~현재로 나눈 표를 추가로 보고하되 "사전 등록되지 않은 탐색 구간"으로 명기한다.

## 8. 시도 횟수
이번 시도: (A) 3전략 × 후보 2개(A1, A2) = 6, (B) 3전략 × 낮춘 수준 3개(500/1,000/3,000억) = 9 → 15회. 재진입 허용 변형과 peg 탐색 구간 표는 미산입. 누적 = 기존 16회 + 15회 = 31회. (기존 16회는 모두 ma_cross 전용 시도이고 reversal_breakout_v2·peg_lynch에는 처음 하는 시도다. 전략별 누적도 병기한다: ma_cross 16+5 = 21, reversal_breakout_v2 5, peg_lynch 5.)
