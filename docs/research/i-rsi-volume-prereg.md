# 연구 I — 일별 매매: 골든크로스 추세 종목의 RSI 눌림 매수·과매수 매도·거래량 확인 (누적 시험 168~172) 사전등록

개별 주식과 현금만 쓴다(ETF 매수 금지, 국내 주식만, 069500은 비교·신호 계산에만). 모든 신호는 일별 종가 판단, 다음 거래일 종가 매매다(월말 판단 없음). 모든 구간 성적은 개발 데이터 내 성적이다. 보류 구간(2022~)은 이미 여러 번 본 데이터라 순수 검증이 아니다.

## 사용자 지정 규칙 (그대로 옮김)

공통: PIT 유니버스(K200P: KOSPI 시총 상위 200, 우선주·리츠 제외, 거래대금 5억↑), 비용·세금·슬리피지·상폐 청산 기존과 동일, 현금 이자 0%, 기간 구분 학습 2010~2016 / 확인 2017~2021 / 보류 2022~최신. 동시 최대 5종목, 진입 시 계좌 평가액의 20% 투입, 이후 비중 조정 없음, 빈 슬롯은 현금, 신호가 슬롯보다 많으면 시총 큰 순. 청산 후 같은 종목 20거래일 재진입 금지. 종가 기준만 사용.
정의: RSI = Wilder RSI(14), 일봉 수정종가. 추세 상태 = 50일선 > 200일선. "골든크로스 후 경과" = 50일선이 200일선을 상향 돌파한 날부터의 거래일 수. 거래량은 분할·병합 조정(조정계수 역수)한 값을 쓰고, 2015~2022년 거래대금이 종가×거래량으로 대체된 구간도 같은 방식으로 일관되게 계산하되 사용 가능한 구간을 보고. 거래량 확인 = 신호일 거래량 ≥ 직전 20일 평균 거래량 × 1.5.
진입 신호(눌림 회복): 추세 상태이고 골든크로스 후 경과 120거래일 이내이며, 직전 거래일 RSI ≤ 40이고 신호일 RSI > 40(과매도권에서 회복하는 날).
청산(공통): 다음 중 먼저 오는 것 — (a) RSI ≥ 70(과매수), (b) 종가 ≤ 진입가×0.90(손절), (c) 데드크로스(50<200), (d) 보유 120거래일 경과.

## 0단계 사전 확인 결과 (실행 전)

- research/·docs/research/ 전수 검색(rsi, 과매도, 과매수, 거래량 확인, volume 등)에서 **RSI를 매매 규칙으로 쓴 기존 시험은 없다.** scripts/research-ma-lab.ts에 `computeRSI`(Wilder)와 `rsi14`가 있으나 ma_cross v2 연구에서 진입일 종목 피처를 기술하는 용도이며 RSI 진입·청산 규칙 시험이 아니다(결과 문서에도 RSI 언급 없음).
- reversal_breakout(lib/reversalBreakout.ts)은 운영 스크리닝 규칙이다. 신호는 "역배열 이력 → 최근 20일 내 매집봉(거래량 3배·양봉) → 5일 내 MA20 돌파"로 RSI를 쓰지 않고, 거래량 배수도 3배 단일 스파이크다. 같은 시험이 아니다. minervini_trend_template은 종료된 운영 전략으로 RSI·거래량 확인 규칙 시험이 research/에 없다.
- 거래량 확인(20일 평균 대비 배수)을 진입 필터로 시험한 연구도 없다.
- 따라서 I1~I5 5개 모두 새로 실행하고 계수한다. 시험 번호는 I1 = 168, I2 = 169, I3 = 170, I4 = 171, I5 = 172(누적 167 + 5 = 172)다.

## 사용자 문안에서 해석을 정한 곳 (결과를 보기 전에 고정)

1. **Wilder RSI(N)**: 종목 자신의 수정 종가 행 기준. 첫 N개 변화의 단순 평균으로 시작(행 인덱스 N에서 첫 값), 이후 평균 이익 = (직전 평균×(N−1) + 이번 이익)/N, 평균 손실도 같다(scripts/research-ma-lab.ts `computeRSI`와 같은 계산). 평균 손실 0이면 RSI = 100. 행 인덱스 N 미만은 정의되지 않으며 정의되지 않으면 신호·청산에 쓰지 않는다. "직전 거래일 RSI"는 그 종목의 직전 행 RSI다.
2. **추세 상태·골든크로스 후 경과**: 종목 자신의 수정 종가 행 기준 단순이동평균. 상향 돌파일 = 전일에 장기선이 정의돼 있고 전일 단기 ≤ 장기이며 당일 단기 > 장기인 날(F 연구의 `cross` 정의 그대로: 장기선이 정의된 첫 날은 돌파일이 아니다). 경과 = 돌파일 0, 이후 행마다 +1이고, 단기 > 장기 상태가 한 번이라도 끊기면 경과는 정의되지 않는다(다시 돌파하면 0부터). 즉 장기선이 처음 정의될 때 이미 단기 > 장기였던 종목은 첫 돌파 전까지 "경과"가 없다(골든크로스 후가 아니므로 진입 불가). 진입 조건 "경과 ≤ N" = 신호일 경과가 정의돼 있고 N 이하.
3. **눌림 회복 신호**: 신호일(행 i)에 (단기선 > 장기선) ∧ (경과 ≤ 120) ∧ (RSI(i−1) ≤ 40 ∧ RSI(i) > 40). RSI 임계 40은 ≤ 직전, > 신호일(엄격). 한 번의 눌림당 한 번만 신호가 나오는 구조(40 상향 돌파).
4. **거래량 확인**: 신호일 조정 거래량 ≥ 직전 20개 행(신호일 제외) 조정 거래량의 단순 평균 × 배수(1.5). 직전 행이 20개 미만이거나 평균이 0 이하이면 확인 실패(신호 제외). 거래량은 Parquet의 volume을 적용된 조정 이벤트의 역수로 조정한 값(`applyAdjustmentsInPlace`)을 쓴다. 거래대금(trading_value)은 쓰지 않는다: 2015~2022 행의 trading_value가 0이어서 종가×거래량으로 대체되는 구간이 있지만 이 연구의 거래량 확인은 거래대금이 아니라 **거래량 자체**만 쓰므로 일관성은 유지된다. 유니버스 유동성(20일 평균 거래대금 5억)은 기존대로 `tradingValueWon`(대체 규칙 포함)을 쓴다. 사용 가능한 구간은 연도별로 K200P 종목-일 중 volume > 0 비율, trading_value 저장값 > 0 비율, 20일 평균 정의 비율을 표로 보고한다.
5. **상위 3업종**: F/H와 같다(K200P, 신호일 6−1개월 시총가중 모멘텀 순위 상위 3개 업종, 신호일 종가 기준).
6. **청산 판단·체결**: 보유 중인 종목마다 매일 종가에 아래 순서로 평가해 먼저 해당하는 사유를 그 거래의 사유로 기록하고(복수 해당 시 이 순서가 라벨 우선순위; 체결은 같다), 다음 거래일 종가에 전량 매도한다: (a) RSI(그날) ≥ 70 → "RSI 과매수", (b) 수정 종가 ≤ 진입 체결일 수정 종가 × 0.90 → "손절", (c) 단기선 < 장기선 → "데드크로스", (d) 판단일 달력 순번 − 진입 체결일 달력 순번 ≥ 120 → "기간". 진입 체결일 당일 종가도 판단일이 될 수 있다(F와 같음). 청산 판단에서 RSI가 정의되지 않으면 (a)는 해당 없음. 진입 체결일 이후 거래일이 아닌 종목은 체결 가능한 첫 행에서 체결(F의 이월 규칙).
7. **I5**: 진입 = 골든크로스 당일(돌파일 경과 0)이면서 그날 RSI(14) ≤ 60(정의돼 있어야 함). 상위 업종·거래량 필터 없음. 청산은 I1과 같다. RSI > 60이면 그날 신호는 버리고 이후 다시 평가하지 않는다(돌파일 하루만 평가).
8. **R1 이웃값(게이트 D)**: 한 번에 하나씩만 바꾼다. RSI 기간 9·21(진입·청산 RSI 모두 해당 기간), 진입 임계 35·45(I1~I4), 청산 임계 65·75·80, 거래량 배수 1.2·2.0(I2·I4만), 이동평균 (40,150)·(60,250), 동시 보유 3·7(진입 20% 고정, 슬롯 수만 변경), 손절 7%·13%, 경과 60·180일(I1~I4). I5에는 해당 없는 항목(진입 임계, 거래량, 경과)을 적용하지 않고, I5에는 RSI 기간·청산 임계·이동평균·동시 보유·손절 이웃값만 쓴다(I5의 RSI ≤ 60은 이웃값을 만들지 않는다). 이웃값 각각의 전 기간 CAGR ≥ 069500 원주가 CAGR이어야 O. 이웃 수: I1·I3 = 2+2+3+2+2+2+2 = 15, I2·I4 = 17, I5 = 2+3+2+2+2 = 11.
9. **R3 무작위 진입일**: H와 같은 방식. 신호 건수 nSig = 해당 후보 기본 설정에서 전 기간(첫 판단일~데이터 끝−1일) 신호 사건 수(슬롯·쿨다운 적용 전). 풀 = 신호 **사건**만 빼고 나머지 조건을 충족한 (종목, 판단일) 쌍(신호 사건 자체도 풀에 포함): I1 = 추세 상태 ∧ 경과 ≤ 120 ∧ RSI(14) 정의됨, I2 = I1 풀 ∧ 거래량 확인, I3 = I1 풀 ∧ 상위 3업종, I4 = I1 풀 ∧ 거래량 확인 ∧ 상위 3업종, I5 = 추세 상태 ∧ RSI ≤ 60. 풀에서 nSig개를 비복원 무작위로 뽑아 진입 후보로 쓰고(같은 날 후보는 시총 큰 순), 슬롯·20% 투입·쿨다운·청산 규칙은 후보와 같다. 1,000회, 난수 = `mulberry32(KSS_R3_SEED = 20261022)`를 후보마다 새로 시작. 후보 CAGR의 백분위(무작위 CAGR 중 더 작은 비율) ≥ 95면 O. 참고로 1 − 0.05/5 = 99 이상 여부도 표시.
10. **R2**: F/H와 같다. (거래 손익 ÷ 진입 시점 계좌 평가액) 상위 3개 거래를 보유 기간 069500 원주가 수익률로 대체해 다시 돌린 전 기간 CAGR.
11. **게이트 B**: 학습·확인·보류 세 구간 중 2개 이상에서 CAGR > 069500 원주가 CAGR ∧ MDD ≤ 069500 MDD + 1e-9. 게이트 A의 MDD도 같은 비교.
12. **추가 보고의 정의**:
    - 진입 건수 = 체결된 진입(구간은 체결일 기준), 청산 건수·승률·손익비·평균 보유일(체결일 간 달력 순번 차)은 닫힌 거래 기준(구간은 청산 체결일 기준, 기간 끝에 열려 있는 거래 제외). 승 = 비용 포함 순수익률 > 0. 손익비 = 이긴 거래 평균 순수익률 ÷ 진 거래 평균 손실률(절댓값).
    - RSI 과매수 청산 직후 20거래일 수익률 = RSI 사유 청산 체결일 종가(수정) 대비 20 거래일 뒤 같은 종목 수정 종가의 변화율(비용 제외, 그 날짜 이하 마지막 행 사용, 20일 뒤가 데이터 끝을 넘으면 제외)의 평균·중앙값, 그 기간의 같은 종목 069500 원주가 대비가 아니라 절대 수익률을 보고한다.
    - 이긴 거래의 반납률 = (진입 후 최고 수정 종가 − 청산 체결일 수정 종가) ÷ (최고 수정 종가 − 진입 체결일 수정 종가). 이긴 거래(순수익률 > 0)만, 평균·중앙값.
    - 거래량 확인 효과: 슬롯·쿨다운 없이 신호마다 가상 거래(다음 거래일 종가 진입, 같은 청산 규칙, 비용 포함 순수익률)를 계산해 I2는 I1 신호 기준, I4는 I3 신호 기준으로 거래량 확인 통과 신호와 걸러낸 신호(거래량 확인 불가 포함)의 가상 수익률을 구간별(신호일 기준)로 보고한다.
    - 상위 10개 거래 비중 = 전 기간 닫힌 거래 중 (손익 ÷ 진입 시점 계좌 평가액)이 큰 상위 10개 합 ÷ 전 거래 합, 그리고 ÷ 이익 거래 합 두 가지를 보고한다.
    - 단일 종목 최대 비중 = 보유가 있는 날의 (최대 보유 종목 평가액 ÷ 계좌 평가액) 평균·최대. 삼성전자(005930)+SK하이닉스(000660) 합산 비중 = 전체 날 평균·최대. 현금 100% 기간 = 보유 종목 0인 거래일 비율. 연 회전율·연 비용은 H와 같은 정의, 2026-10-01~10-15 수익률은 `D_RECENT_FROM`/`D_RECENT_TO` 규칙 그대로(069500 원주가 대조).
13. **시드 모의·최소 필요 금액**: H와 같다. 정수 주(조정 이벤트 반영), 진입 금액 = 계좌 평가액 × 20% 내림, 1주도 못 사면 다음 후보. 최소 필요 금액 = 진입일 원 종가 ÷ 0.20(2024-01 이후 진입)의 중앙값·최대.
14. **신호 건수·진단 보고**(판정에 쓰지 않음): 후보별·구간별 신호 건수, 연도별 K200P 거래량 사용 가능 비율 표, RSI 분포 점검(K200P 종목-일 평균 RSI, RSI ≤ 40 비율).
