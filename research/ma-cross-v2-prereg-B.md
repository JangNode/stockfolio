# [임시 연구 — 병합 금지] 사전 등록 B (진단 직후, 후보 실행 전)

사전 등록 A(커밋 795ae79f950c33810255e18cb2fb0a388987ae2f)는 수정하지 않는다. 이 파일은 추가분이다.
진단 실행: run 38224924294 (R0 재현 3.54% / MDD 55.84% / 승률 30.3% / 손익비 4.16 / 3,949건 — R0 지정값과 일치).
이 시점까지 후보(필터·손절)의 성과 수치는 한 번도 계산하지 않았다.

## B-1. 진단에서 도출된 진입 필터 후보 3개 (A 4항의 "일관" 규칙을 그대로 적용한 결과)

일관으로 판정된 피처는 정확히 3개였다(adx14, rsi14, pos52wHigh). 세 피처 모두 학습 구간 최저 승률 3분위는 T1(낮은 값)이었다.
필터 = "진입일 종가 기준 피처 값이 학습 구간 T1 상한(아래 경계)을 초과하는 진입만 허용"(= T1 제외, 경계값은 진단 출력의 4자리 유효숫자로 고정).

| 후보 | 규칙 | 경계(고정) | 학습 승률 격차(T3−T1) / 확인 |
|---|---|---|---|
| F1 | ADX(14) > 21.49 | 21.49 | 3.8%p / 9.3%p |
| F2 | RSI(14) > 54.53 | 54.53 | 6.4%p / 10.4%p |
| F3 | 종가/52주 고가 − 1 > −0.1829 (52주 = 최근 252거래일 고가) | −0.1829 | 5.5%p / 7.8%p |

주의(정직한 표기): F1은 이전에 시도한 ADX≥20과 같은 피처 계열이고, 세 피처 모두 추세 강도 계열이라 서로 상관이 높다.
ADX≥20은 A의 지시대로 재평가 대상으로 표에만 넣는다(시도 횟수에 세지 않음).

## B-2. 고정 손절 (A와 동일)
S1: 진입가 −15% (종가 기준), S2: 진입가 −25% (종가 기준). 청산 후 다음 골든크로스까지 재진입 없음.

## B-3. 조합 1회 (A 4항의 규칙을 코드로 확정)
학습 구간 Calmar(CAGR÷MDD)가 R0_학습보다 높은 단독 필터 중 최고 1개 + 같은 기준의 손절 중 최고 1개. 해당이 없으면 실행하지 않는다.

## B-4. 학습 선별 기준에 대한 정정(공개) — 후보 결과 확인 전에 등록
A 3항의 학습 선별 기준 중 "승률_학습 ≥ 33%, 손익비_학습 ≥ 3.9"는 사용자 지정 전체 구간 기준을 학습 구간에 그대로 옮긴 것이었다.
진단에서 R0_학습이 승률 25.7%, 손익비 2.50, CAGR −2.26%, MDD 28.79%, 1,603건으로 확인되어, 이 두 조건은 어떤 후보도
학습 구간에서 충족할 수 없는 수준이다(= 선별 단계가 구조적으로 "합격 없음"을 만들게 된다). 이는 후보 성과를 보기 전에 R0 수치만 보고 발견한 설계 오류이므로
다음과 같이 정정한다(결과를 보고 고치는 것이 아님을 명시):
- 학습 선별에서 승률·손익비 절대 기준은 **보고만 하고 요구하지 않는다**. 나머지(CAGR_학습 ≥ R0_학습+1.0%p, MDD_학습 ≤ R0_학습−3%p,
  거래_학습 ≥ 스케일 기준, 슬리피지 0.3%에서 CAGR_학습 ≥ R0_학습(0.3%))는 A 그대로.
- **최종 합격 판정(사용자 지정 기준 전체: 전체 구간 CAGR ≥ 4.5%, MDD ≤ 52.8%, 승률 ≥ 33%, 손익비 ≥ 3.9, 거래 ≥ 1,500, 슬리피지 0.3%에서 R0 이상,
  확인 구간 CAGR ≥ R0_확인·MDD ≤ R0_확인)은 정정하지 않는다.** 선별은 "무엇을 확인 구간에서 평가할지"를 정하는 단계일 뿐이다.
- 선별을 통과한 후보가 없으면 합격 없음으로 보고하고 확인 구간은 평가하지 않는다.

## B-5. 보고 프로토콜 (A 2항의 "확인 구간 1회"와 사용자 보고 요청의 충돌 정리)
- 후보별 학습 구간 수치는 전부 보고한다. 확인 구간(2019~) 수치는 **선별을 통과한 최종 후보 1개에 대해서만** 계산해 보고한다.
  나머지 후보의 확인 구간은 평가하지 않는다(사용자가 원하면 정보 제공용으로 별도 요청 가능하나 판정에는 쓰지 않는다).
- 구현: 하나의 프로세스에서 슬리피지 0.1%와 0.3%를 모두 계산한다(`SLIPPAGE`를 런타임에 전환하는 임시 코드).
