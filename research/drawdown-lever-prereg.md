# 역발상 레버리지 1변형(L1) 사전등록 — 마지막 시도 (누적 시도 119 → 120, 홀드아웃 실행 시 +1)

승인 범위: 사전등록 커밋 → 백테스트 1회. 재실행 금지. 결과를 본 뒤 정의·기준 변경 금지. 다음 라운드 자동 시작 금지.
브랜치 claude/ma-v3-portfolio-cap-run (병합 금지). 외부 요청 0건, DB 읽기만·쓰기 금지.
기존 사전등록 문서에 "069500 낙폭 기준으로 122630 레버리지 비중을 늘리는 규칙"이 있는지 확인함 — 없음(122630이 나오는 문서는 allocation-goals-prereg.md뿐이며 R1은 10개월 이동평균 추세로 122630 100%/114260 100% 전환(:13), R2는 122630 50% + 148070 50% 정적 배분(:14)으로 다른 규칙).

## 사전 고지 (사용자 문안 그대로)
- 이 규칙은 확인 구간(2017~2021) 결과(2020 반등 놓침)를 본 뒤 설계됨. 확인 구간 통과는 독립 검증으로 보기 어려움. 설계자는 2022년 이후 시장 흐름도 알고 있음.
- 통과 시에도 "조건부 후보"로만 기록.

## 데이터·비용
research/vol-target-prereg.md(a7b24da5)와 같은 정제·비용 규칙: 069500, 122630(KODEX 레버리지) 수정주가. 122630은 research/etf-allocation-prereg.md의 2026-06-25 정제 규칙 적용. 편도 수수료 0.015% + 슬리피지 0.05%, 매도세 없음, 세금 미반영.

## 규칙 L1
- 매 거래일 종가에 D = 069500 종가 ÷ 최근 252거래일(당일 포함) 069500 최고 종가 − 1.
- 상태 "평상": 069500 100%. D ≤ −20%가 되면 그날 종가에 069500 50% + 122630 50%로 전환 → 상태 "확대".
- 상태 "확대": 비중은 가격 따라 자연 변동, 중간 리밸런싱 없음. D ≥ −5%가 되면 그날 종가에 069500 100%로 복귀 → "평상".
- 122630 데이터가 없는 날(2010-02 이전)에 확대 신호가 나오면 069500 100% 유지하고 보고.
- 지연 변형: 같은 신호를 다음 거래일 종가에 체결.

## 기간
학습 2010-01-01~2016-12-31, 확인 2017-01-01~2021-12-31, 홀드아웃 2022-01-01~데이터 끝.
비교 B&H = 069500 보유. 참고로 122630 보유, KOSPI 표시.

## 기준 (각 관문 공통, 수익형)
- G1 CAGR > B&H CAGR
- G2 MDD ≤ B&H MDD + 10%p
- G3 CAGR÷MDD ≥ B&H
- G4 지연 시 CAGR 하락 ≤ 1.0%p

## 절차
학습 G1~G4 전부 O일 때만 확인 → 확인 전부 O일 때만 홀드아웃 → 홀드아웃 전부 O일 때만 "조건부 후보". 하나라도 X면 그 단계에서 종료.

## 보고
숫자와 표만, 판정·추천 문장 금지. (a) 중복 확인, 사전등록 해시와 순서 (b) 각 단계 표: L1, B&H, 122630 보유, KOSPI의 CAGR / MDD / 샤프 / CAGR÷MDD / 연변동성 / 확대 상태 일수 비율 / 전환 횟수 / 누적 비용 / 지연 CAGR, G1~G4 O/X (c) 확대 구간 목록(전 기간 아님, 계산한 단계까지만): 진입일, 진입 시 D, 복귀일(또는 미복귀), 기간 일수, 그 구간 L1 수익 vs B&H 수익 (d) 계산한 단계의 연도별 수익률(L1, B&H) (e) Supabase 읽은 행·쓴 행(0), 외부 요청(0), 소요 시간.

## 구현 세부 (결과를 보기 전에 고정하는 해석 — 사용자 문안에 없는 부분)
1. 데이터·정제: 각 자산 자체 거래일 계열에서 원자료 일수익률로 탐지하고 원자료 이웃 가격의 기하평균으로 동시 치환(etf-allocation-prereg.md 규칙; 069500은 같은 날 KOSPI 일수익률(DB, 2010-01-04부터, 없으면 면제 없음)로, 122630은 같은 날 069500 원자료 일수익률로 면제 판정). 달력 = 069500(정제) 거래일. 122630의 그날 행이 없으면 직전 종가를 이월(수익률 0)하고 그런 날 수를 보고한다. 실행 시작일 s0 = 2009년 마지막 거래일(모든 전략·B&H는 s0 종가에 진입, 진입 비용은 창 밖, 창은 s0 다음 거래일부터; 학습 창의 CAGR 기간은 2010-01-01부터). 단일 실행에서 창을 잘라 쓴다. 122630 보유(참고)는 상장 전 구간 수익률 0(미보유).
2. 신호 상태기계는 체결과 독립적으로 매 거래일 종가에 평가한다: D ≤ −0.20이면(수준 조건, 평상 상태에서 매일 검사) 확대, 확대 상태에서 D ≥ −0.05이면 평상. 122630의 첫 행 이전 달력일(상장 전)에는 확대 신호를 무시하고 평상을 유지하며, 무시한 날 수와 첫·마지막 날을 보고한다(상장 후에도 D ≤ −0.20이 유지되면 상장 첫 거래일에 전환). s0 시점에도 같은 규칙으로 초기 상태를 정한다. D의 최고 종가는 당일 포함 최근 252개 달력 거래일의 069500 종가 최댓값(069500 이력은 2008부터라 s0에서 충족).
3. 무지연 포지션 상태 = 같은 날 신호 상태, 지연 포지션 상태 = 전 거래일 신호 상태(s0 진입은 두 변형 모두 s0 신호). 포지션 상태가 바뀌는 날 종가에 체결한다. 평상→확대: 069500 평가액의 절반을 122630으로(합계의 50:50), 비용 = 가치 × (0.015%+0.05%) (매도 50%+매수 50%). 확대→평상: 122630 전량 매도 후 069500 매수, 비용 = 122630 평가액 × 2 × (0.015%+0.05%). 확대 중에는 일별 수익률로 평가절하만 한다.
4. 지표: CAGR = computeCagrPct(총수익률, 창 시작일, 창 종료일; 홀드아웃의 종료일은 달력 마지막 거래일), MDD = computeCumulativeAndMdd, 연변동성 = 일수익률 표본표준편차×√252, 샤프 = (일수익률 % 평균×252)÷(표본표준편차×√252), CAGR÷MDD는 MDD>0일 때, G4의 CAGR 하락 = 무지연 − 지연(같은 창). 확대 상태 일수 비율 = 창 내 거래일 중 종가 체결 후 포지션 상태가 확대인 날의 비율. 전환 횟수 = 창 내 체결일(양방향) 수의 합계(연 환산 아님). 누적 비용 = 창 내 체결 비용/체결 직전 가치의 합(%). KOSPI는 DB 지수 종가 일수익률(2010-01-05부터).
5. (c) 확대 구간(무지연 실행 기준): 포지션 상태가 평상→확대로 바뀐 체결일 e를 진입일, 확대→평상으로 바뀐 체결일 x를 복귀일로 한다. 진입일 e가 계산한 마지막 단계의 창 종료일 이하인 구간만 나열한다. 기간 일수 = e와 x(또는 마지막 계산 단계의 창 종료일) 사이 달력일 수. 구간 수익 = e일부터 x일(또는 마지막 계산 단계의 창 종료일)까지 일수익률의 복리(L1은 비용 포함, B&H는 같은 날들의 069500). 복귀가 마지막 계산 단계의 창 종료일 이후이면 "미복귀(단계 끝 기준)"로 표시하고 그 창 종료일까지로 계산한다.
6. 상수는 lib/drawdownLeverConfig.ts(및 직전의 lib/seasonalityConfig.ts, lib/etfAllocationConfig.ts)에 둔다.
