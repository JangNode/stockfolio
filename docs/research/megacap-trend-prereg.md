# 연구 L — 시총 최상위 대형주 집중 + 200일선 추세 이탈 청산 (L1 = 시도 208, L2 = 시도 209, L3 = 시도 210, 통제군) 사전등록

작성 2026-10-27(사용자 지정). **이 문서는 시험 실행 전 사전등록이며 실행 전에 커밋한다(커밋 해시는 보고에 기록).** 국내 주식과 현금만 쓴다(ETF 매매 금지, 069500은 기준선 전용). 모든 구간 성적은 개발 데이터 내 성적이다. 연구 브랜치 claude/ma-v3-portfolio-cap-run에서만 작업하고 main 병합은 하지 않는다. 시험은 이 문서를 커밋한 뒤 같은 실행에서 세 후보를 각각 한 번만 한다.

## 0. 중복 확인 결과 (읽기 전용, 저장소 docs/research·research·scripts·lib 검색)

"시총 상위 N 집중 보유"와 **같은 정의**(일별 시총 순위 상위 5·10 진입 + 순위 한도 이탈 매도, 종목당 20%·10% 고정, 빈 슬롯 현금, 200일선 위/아래 마감 진입·청산)의 시험은 **없었다.** 비슷하지만 다른 정의의 기존 연구:

| 기존 | 정의 | 이번 시험과의 차이 |
|---|---|---|
| baseline-decomposition D1·D2·D3 (진단, 시도 수에 미포함) | 유니버스(시총 5천억·거래대금 5억, 코스피+코스닥) 시총 상위 20/50, 동일가중·시총가중 | 월말 리밸런싱·비중 드리프트, 추세 규칙 없음, N이 20/50. 이번은 상위 5/10, 일별 순위·청산, 종목당 고정 20%/10%, 코스피만 |
| blend D2 | D2(시총 상위 20 시총가중)를 구성요소로 사용 | 위와 같음 |
| trend-capweight T1·T2·T3 (T88~93) | D4(유니버스 전체 시총가중)에 SMA 224/200 필터(지수 타이밍·종목별 필터) | 전체 유니버스 시총가중(수십~수백 종목)이고 월말 재조정 + 필터 변화일 부분 거래. 이번은 상위 5/10만 일별 순위로 담고 순위 이탈이 청산 규칙 |
| POOL(시총 상위 100 시총 비례) 계열 | 월말 재조정, 틸트·필터의 바탕 | 100종목·월 리밸 |
| F·H·I·J·K 계열(K200P 일별 추세·터틀 등) | 코스피 시총 상위 200 유니버스에서 신호(돌파·RSI·ATR 등)로 개별 종목 진입 | 시총 순위 자체를 신호로 쓰지 않고 상위 200 중 신호 종목을 다수 보유 |

따라서 중복이 아니라고 판단하고 진행한다. 이번 시험의 새 요소는 ① 시총 상위 5/10 집중, ② 시총 순위 이탈(10위·20위 밖)을 청산 규칙으로 하는 일별 보유, ③ 200일선 추세 이탈 청산의 유무 비교(L3 통제군)다.

## 1. 목적

"코스피 시총 최상위 대형주 몇 개(5/10개)만 들고 가되 종가가 200일선 아래로 내려오면 현금으로 피하면, 069500보다 낙폭이 작으면서 수익이 높은가? 그 효과는 추세 규칙 덕분인가(L3 통제군과 비교)?" 삼성전자·SK하이닉스 등 소수 종목 집중 위험을 그대로 안는 구조라 결과 해석 시 집중 위험을 함께 본다.

## 2. 사용자 지정 규칙 (그대로 옮김)

- 시도 번호 208~210(연구 C 시도는 번호를 소진하지 않았으므로 207 다음 번호). 국내 주식과 현금만, ETF 매매 금지. 유니버스: 코스피 보통주(우선주·스팩·리츠 제외), 월말 구성 + 당일 시총(PIT)으로 매일 시총 순위. 신호는 종가, 체결은 다음 거래일 종가, 수정주가, 비용 0.015%/편도 + 매도세, 슬리피지 0.1%, 상장폐지 강제 청산. 기준선 069500 원주가. 구간: 학습 2011~2016 / 확인 2017~2021 / 보류 2022~(200일선 계산 때문에 2011-01 시작). 게이트 A~H 기존 정의 그대로(G 100건 완화 금지, B는 세 구간 중 2개 이상). 결과를 본 뒤 정의 변경 금지, 재실행 금지.
- L1(208): 시총 순위 상위 5위 안이고 종가가 200일 단순이동평균 위일 때 편입(종목당 20%, 빈 슬롯은 현금). 보유 종목은 시총 순위 10위 밖으로 밀리거나 종가가 200일선 아래로 마감하면 다음 거래일 종가에 매도. 같은 종목 재진입은 종가가 다시 200일선 위로 올라온 날부터(별도 쿨다운 없음).
- L2(209): 상위 10위 안, 종목당 10%, 순위 20위 밖 또는 200일선 아래 마감 시 매도. 나머지는 L1과 동일.
- L3(210, 통제군): 추세 규칙 없음. 상위 5위 안이면 편입(20%), 순위 10위 밖이면 매도. 나머지는 L1과 동일.
- 게이트 D(이웃값): L1 이웃 = 이동평균 150/250일, 순위 매도 한도 8/15. L2 이웃 = 이동평균 150/250일, 매도 한도 15/25. L3 이웃 = 매도 한도 8/15. 이웃은 CAGR ≥ 069500이면 통과. 게이트 F 무작위 풀: 편입 가능한 상위 5(L1·L3)/10(L2) 종목, 같은 청산 규칙. 게이트 H: L1과 L2의 기준선은 L3(추세 규칙 없는 대형주 집중), L3는 해당 없음.
- 보고: 후보별 게이트 A~H 표와 탈락 사유, 구간별 CAGR·MDD를 069500과 나란히, 연도별 수익률(2025·2026 포함), 평균 투자 비중과 현금 비중, 보유 종목 구성(삼성전자·SK하이닉스 비중 포함), 진입 건수와 보유 기간 중앙값, 상위 3개 거래 제외 성적, 하루 지연 성적, 2022년과 2026-10 하락 구간 성과. 통과 후보가 나와도 운영 적용·PR 금지, 통과하지 못해도 원인을 더 파지 말고 결과만 보고.

## 3. 구현 정의 (실행 전 고정; "해석"은 지시 문구에 없어 문서화 시 정한 것)

기준값은 lib/megacapTrendConfig.ts, 엔진은 연구 A·B와 같은 공용 슬롯 시뮬레이터(lib/slotSim.ts)와 게이트 도구(scripts/researchGates.ts), 스크립트는 scripts/research-l-megacap.ts다.

1. **입력·비용**: 가격 Parquet 2010~(Actions 캐시), 적용된 조정 이벤트, 월말 시장 목록(Storage 약 0.2 MiB), dart 이름, 업종·ETF 겹침(제외 규칙), 069500 raw. 매수 = 종가 × (1 + 0.1%) × (1 + 0.015%), 매도 = 종가 × (1 − 0.1%) × (1 − 0.015% − 당일 거래세). 현금 이자 0%. 폐지 청산은 기존과 같다(마지막 행이 데이터 끝 − 14일보다 이전이면 그 종목이 처음 행이 없는 날 직전 평가액으로 매도). 외부 요청 0, DB·Storage 쓰기 0.
2. **평가 구간**: 평가 시작 판단일 = 2011-01-01 이후 첫 거래일(2011-01-04, 달력 순번 252). 수익률 집계는 그다음 거래일부터. 구간 = 학습 2011-01-05~2016-12-31 / 확인 2017-01-01~2021-12-31 / 보류 2022-01-01~데이터 끝 / 전체 2011-01-05~. 시작 시점에 포트폴리오는 전량 현금이다.
3. **시총 순위(PIT)**: 판단일 d에 d 행이 있고, 제외 규칙(4c1557a: 우선주·ETF·스팩·리츠)에 걸리지 않으며, d 이하 가장 최근 월말 시장 목록에서 KOSPI인 종목을 d 행 시총(market_cap_eok) 내림차순(동점 코드 오름차순)으로 순위를 매긴다. **해석**: 거래대금·상위 200 제한은 두지 않는다(최상위 소수 종목에는 영향이 없음). 순위는 최대 30위까지 계산하고 그 밖은 "순위 밖"으로 본다.
4. **200일선**: 종목 자신의 수정 종가 행 200개의 단순평균(오늘 포함). 행이 200개 미만이면 정의되지 않으며 "위"도 "아래"도 아니다. **위** = 종가 > SMA, **아래** = 종가 < SMA(같으면 어느 쪽도 아님: 편입하지 않고 보유 종목은 이탈로 보지 않음). 이웃값은 150·250일.
5. **일별 루프**(CAL 인덱스 c, 종가 판단 → 실행일 c + lag, 기본 lag = 1, 지연 변형 lag = 2): (a) 보유 종목 평가, (b) 실행일인 청산 처리(그날 행이 없거나 거래량 0이면 다음 거래일로 순연) 후 진입 처리(행이 없거나 거래량 0이면 그 주문 취소), (c) 판단: 먼저 청산 판단, 이어 진입 판단.
6. **청산 판단**: 보유 종목의 d 시총 순위가 매도 한도(L1·L3 10, L2 20)를 넘으면(밖이면) 또는 L1·L2에서 종가가 200일선 아래이면 청산 주문. **해석**: 판단일에 그 종목 행이 없으면(거래정지 등) 판단하지 않고 보유를 유지한다. 상장폐지는 폐지 청산 규칙. 그 외 청산 사유는 없다(손절·익절 없음).
7. **진입 판단**: 빈 슬롯 수 = 슬롯 수(L1·L3 5, L2 10) − (보유 종목 수, 청산 주문 중 포함) − (이미 낸 매수 주문 수). 편입 후보 = 시총 순위 ≤ 진입 한도(L1·L3 5, L2 10)인 종목 중(L1·L2는 종가가 200일선 위인 종목만), 보유·주문 중이 아닌 종목을 순위 순으로 빈 슬롯 수만큼 주문. **빈 슬롯은 아래 순위에서 채우지 않고 현금으로 둔다.** 쿨다운은 없다(재진입은 후보 조건을 다시 충족한 날부터 가능). 실행일 투입액 = min(계좌 평가액 ÷ 슬롯 수, 현금)(L1·L3 20%, L2 10%)이고 매수 후 비중 조정은 없다(수익 종목은 커지도록 방치).
8. **보유 평가·지표**: 일별 수익률 = 종가 계좌 평가액 ÷ 전일 평가액 − 1(비용은 실행일에 반영). 기간 끝에 열린 거래는 거래 통계에서 제외한다. MDD는 낙폭 크기 %다.

## 5. 게이트 (임의 완화 금지, 기존 정의 그대로 — f-daily-trend-prereg.md 구현 세부 9, r-allcap-fundamentals-prereg.md 단계 2)

기준선 B&H = 069500 원주가(가격 수익만, 비용 없음). MDD 비교는 1e-9 허용.

- **A**: 전 기간 CAGR ≥ B&H CAGR + 2%p 이고 MDD ≤ B&H MDD.
- **B**: 학습·확인·보류 세 구간 중 2개 이상에서 각각 CAGR > B&H CAGR 이고 MDD ≤ B&H MDD.
- **C**: lag = 2 전 기간에서 기본 CAGR − 지연 CAGR ≤ 1%p 이고 지연 MDD − 기본 MDD ≤ 2%p.
- **D(이웃값)**: L1 = 이동평균 150·250일(매도 한도 10 유지), 매도 순위 한도 8·15(이동평균 200 유지). L2 = 이동평균 150·250일, 매도 한도 15·25. L3 = 매도 한도 8·15. 하나씩만 바꾼다. 모든 이웃의 전 기간 CAGR이 B&H CAGR 이상이어야 O.
- **E**: 기본 실행의 닫힌 거래 중 거래 기여 = (매도 대금 − 투입액) ÷ 진입 실행일 V가 큰 상위 3개 거래를 같은 진입·청산 실행일 동안 069500 원주가 일수익률로 바꿔(비용 같음) 전 기간 CAGR을 다시 계산했을 때 B&H CAGR 이상이면 O.
- **F**: 1,000회, 시드 20261022 mulberry32. 신호일마다 실제 매수 주문 수만큼 **그날 편입 가능한 종목(시총 ≤ 5위(L1·L3)/10위(L2), L1·L2는 종가 > 200일선) 중 보유·주문 중이 아닌 종목**에서 무작위로 골라 같은 청산 규칙으로 다시 돌린다. **해석**: 풀이 실제 후보와 거의 같아 무작위성은 "여러 후보 중 어느 것을 먼저 채우나"에서만 생긴다. 백분위 = 전략 전 기간 CAGR보다 작은 회수 ÷ 1,000 × 100이며 ≥ 95여야 O. 참고로 1 − 0.05/3 ≈ 98.3 백분위 이상인지도 표시한다(통과 조건 아님).
- **G**: 전 기간 진입 100건 이상(완화 금지). 시험 전 추정은 하지 않는다(실행 결과로 판정, 번호는 소진).
- **H**: L1·L2 = 기준선 L3(추세 규칙 없는 대형주 집중, 같은 구간). 조건1(CAGR ≥ L3 + 2%p ∧ MDD ≤ L3 + 1%p) 또는 조건2(MDD ≤ L3 − 5%p ∧ CAGR ≥ L3 − 1%p) 중 하나면 O(연구 R의 H와 같은 상수 R_H_*). L3는 해당 없음.
- **통과** = A~G(H가 있으면 H 포함)가 모두 O.
