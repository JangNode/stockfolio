# 계절성 전략 2변형 사전등록 (누적 시도 115 → 117, 홀드아웃 실행 시 +1)

승인 범위: 사전등록 커밋 → 백테스트 1회. 재실행 금지. 결과를 본 뒤 정의·기준·변형·선택 규칙 변경 금지. 다음 라운드 자동 시작 금지.
브랜치 claude/ma-v3-portfolio-cap-run (병합 금지). 외부 요청 0건, DB 읽기만·쓰기 금지.

## 데이터
- etf_daily_prices.adj_close(KIS 수정주가, 분배금 반영): 069500(주식), 114260(국고채3년). 하루짜리 튐 정제는 research/etf-allocation-prereg.md(e0219298)와 같은 규칙.
- 비용: 편도 수수료 0.015% + 슬리피지 0.05%, 매도세 없음, 세금 미반영(한계로 기록). 전환일에 종가 체결, 지연 변형은 다음 거래일 종가.

## 변형 2개
- H1 핼러윈: 10월 마지막 거래일 종가에 069500으로 전환해 4월 마지막 거래일 종가까지 보유, 4월 마지막 거래일 종가에 114260으로 전환해 10월 마지막 거래일까지 보유.
- H2 월말·월초: 매달 마지막 거래일 기준 4거래일 전 종가에 069500으로 전환해 다음 달 3번째 거래일 종가까지 보유, 그 외 기간은 114260.

## 기간
학습 2010-01-01~2016-12-31, 확인 2017-01-01~2021-12-31, 홀드아웃 2022-01-01~데이터 끝.
비교 기준 B&H = 069500 보유(같은 기간). 참고로 114260 보유, KOSPI도 표시.

## 기준 (각 관문 공통)
- G1 CAGR ≥ B&H CAGR − 1.0%p
- G2 샤프(무위험 0, 연환산 평균 일수익 ÷ 연환산 표준편차) > B&H 샤프
- G3 CAGR÷MDD > B&H
- G4 지연 시 CAGR 하락 ≤ 1.0%p

## 절차
학습 G1~G4 전부 O인 것 중 학습 샤프 최대 1개 선택(없으면 종료) → 확인(하나라도 X면 종료, 홀드아웃 미계산) → 홀드아웃(전부 O일 때만 최종 통과). 선택 안 된 변형의 확인·홀드아웃은 계산·보고 금지.

## 보고
숫자와 표만, 판정·추천 문장 금지. (a) 사전등록 해시와 순서 (b) 학습 표: H1, H2, B&H, 114260 보유, KOSPI의 CAGR / MDD / 샤프 / CAGR÷MDD / 연변동성 / 연 전환 횟수 / 누적 비용 / 지연 CAGR, G1~G4 O/X (c) 정보용(학습 구간만): 069500의 11~4월 vs 5~10월 연평균 수익률, 월말·월초 창 vs 나머지 일평균 수익률과 t값 (d) 선택 결과 (e) 확인 표·G1~G4·연도별 수익률(전략, B&H) (f) (해당 시) 홀드아웃 표·G1~G4·연도별 수익률 (g) Supabase 읽은 행·쓴 행(0), 외부 요청(0), 소요 시간.

## 구현 세부 (결과를 보기 전에 고정하는 해석 — 사용자 문안에 없는 부분)
1. 달력 = 두 자산(정제 후) 거래일의 교집합. 정제는 각 자산 자체 계열에서 원자료 수익률로 탐지·원자료 이웃 가격의 기하평균으로 동시 치환하고(마지막 날은 대상 아님), 069500의 KOSPI 면제는 같은 날 KOSPI 일수익률(DB, 2010-01-04부터)이 있을 때만 적용(없으면 면제 없음). 월말 = 달력에서 다음 거래일의 연월이 달라지는 날(데이터 마지막 날은 월말 아님).
2. 실행 시작일 s0 = 2009년 마지막 거래일. 모든 전략·B&H·114260 보유는 s0 종가에 진입한다(진입 비용은 어느 창에도 포함되지 않음 — 창은 s0 다음 거래일부터. 지연 변형도 s0 종가 진입). 학습 창의 CAGR 기간은 2010-01-01부터. 단일 실행에서 창을 잘라 쓴다.
3. 포지션 상태 sig[k] = 종가 k 체결 후 보유 자산(1=069500, 0=114260), 일 수익률 k = (1+그날 보유 자산 수익률)×(1−전환 비용)−1, 전환 비용 = 전환일 종가 체결 시 2×(0.015%+0.05%) (전액 매도+전액 매수). 연 전환 횟수 = 창 내 전환일 수 ÷ 창 연수, 누적 비용 = 창 내 전환 비용의 합(%).
4. H1: s0의 초기 상태 = 계절 규칙(11~4월 구간이므로 s0=12월 말 → 069500). 이후 10월 월말 종가에 1, 4월 월말 종가에 0, 그 외 이월. H2: 월말 인덱스 L마다 sig[L−4..L+2] = 1, sig[L+3]부터 0(다음 월말 L'−4 전까지). 즉 069500 보유 수익률은 L−3…L+3일 7거래일. s0(=12월 말 L)의 초기 상태도 이 규칙(=1). "다음 달 3번째 거래일" = L+3.
5. 지연 변형: 전환 체결을 한 거래일 늦춘다(sigD[k] = sig[k−1], k > s0; 진입은 s0). G4의 CAGR 하락 = 무지연 CAGR − 지연 CAGR(같은 창).
6. 지표: CAGR = computeCagrPct(총수익률, 창 시작일, 창 종료일; 홀드아웃의 종료일은 달력 마지막 거래일), MDD = computeCumulativeAndMdd, 연변동성 = 일수익률 표본표준편차×√252, 샤프 = (일수익률 % 평균×252)÷(표본표준편차×√252), CAGR÷MDD는 MDD>0일 때. KOSPI는 DB 지수 종가 일수익률(2010-01-05부터; 2010-01-04 수익률 없음). 선택 동률은 연 전환 횟수가 적은 쪽.
7. (c) 정보용 통계(학습 창, 069500 정제 일수익률): 연도(2010~2016)별로 해당 연도의 11·12월+1~4월 일수익률을 복리한 값과 5~10월 일수익률을 복리한 값을 구해 연도 평균을 낸다. 월말·월초 창 = H2 보유일(L−3…L+3)의 일수익률, 나머지 = 그 외 모든 일(학습 창 안). 일평균 수익률(%), 표본 수, 두 그룹 평균 차이의 Welch t값 = (m1−m2)/√(s1²/n1+s2²/n2).
8. 상수는 lib/seasonalityConfig.ts(및 직전의 lib/etfAllocationConfig.ts)에 둔다.
