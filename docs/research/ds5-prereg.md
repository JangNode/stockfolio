# 연구 DS5·DS6 — 공시 데이터를 쓰지 않는 DS4 변형 (시도 270·271) 사전등록

작성 2026-11-03(사용자 지정). **이 문서는 시험 실행 전 사전등록이며 후보 실행 전에 커밋한다(커밋 해시는 보고에 기록).** 국내 주식과 현금만 쓴다(ETF 매매 금지, 069500은 기준선으로만 쓴다). 모든 구간 성적은 개발 데이터 내 성적이다. 통과해도 운영 적용·PR은 하지 않고 보고만 한다. 탈락하면 원인을 파고들지 않고 결과만 보고한다. 브랜치 `claude/ma-v3-portfolio-cap-run`, main 병합 금지. 시도 번호는 정식 소진한다(누적 269 → 271, 우연 통과 기대 건수 271 × 0.05 = 13.55).

## 1. 목적과 사용자 방침

사용자 방침: **공시(DART) 데이터를 쓰는 전략은 쓰지 않는다.** DS4의 위성 구성요소 PE4는 영업이익 공시를 쓰므로 제외한다. 코어(시총 상위 2종목)·W3(가격 특성 + 외국인 수급)·LV1(가격)은 공시를 쓰지 않으므로 유지한다. 공시 없는 DS4 변형 둘을 한 번씩 시험한다.

- **DS5 (270)**: DS4에서 PE4만 제거. 코어 40% + 위성 60% = W3 + LV1 최근 250일 변동성 역수 배분. 그 외 규칙(교체 5거래일 확인, 이동 비용 0.25%, 일별 목표 비중 리밸런싱, 워밍업)은 DS4와 같다.
- **DS6 (271)**: 코어 40% + 위성 60% = LV1 단독(가격만 사용, 운영하기 가장 쉬운 형태).

두 시험 모두 정의·숫자를 결과 전에 고정하고, 결과를 본 뒤 바꾸지 않는다.

## 2. 선택 편향 명시 (정직 소진, 보고에도 반드시 넣는다)

- **DS4 결과를 본 뒤에 만든 변형이다.** DS4(코어 40% + PE4 20% 상한 위성)가 모든 게이트를 통과한 것을 본 다음, 그 구성에서 PE4만 빼거나 위성을 LV1 하나로 줄인 것이 DS5·DS6이다. PE4를 뺀 이유는 사용자 방침(공시 미사용)이지 사전 검증된 근거가 아니다. 선택 편향이 있다.
- **DS5는 정의상 연구 DS의 DS2(시도 267)와 같다.** DS2 = 코어 40%(시총 상위 2종목) + 위성 60%(W3 + LV1 변동성 역수, 직전 250거래일, 워밍업 0일) + 이동 비용 0.25% 일별 목표 비율 리밸런싱이고, DS5도 같다. 사전 점검에서도 위성 평균 목표 비중이 W3 48.40% / LV1 51.60%로 DS2 사전 점검 기록과 같다. 따라서 **DS5의 CAGR / MDD, 구간별 성적, 게이트 A·B·C·E·F·G·H는 DS2와 같은 값(전체 14.28 / 35.66, 학습 5.65 / 27.08, 확인 15.01 / 29.82, 보류 19.22 / 35.66, B 탈락)이 나올 것으로 이미 알고 있다.** 새 정보를 주는 시험이 아니라 사용자 지시에 따라 정식 시도로 소진하는 재시험이다. 같은 값이 나오지 않으면 그 차이를 그대로 보고한다(재현 불일치 자체가 구현 변화의 신호). 새로 달라지는 것은 **게이트 D의 위성 구성 이웃(반반 고정, 한쪽 상한)** 뿐이며, 이 이웃들은 DS2 때 계산하지 않았다. 코어/코어 종목 수 이웃(30%·50%·1종목·3종목)은 DS2 때 이미 계산돼 4개 모두 통과했다(DS2 기록).
- **DS6**은 같은 구조의 시도가 없어 이 점에서는 새 시험이다. 다만 LV1 단독 위성(R3 안 구성요소, 연구 CAPREC·IVA에서 단독 6.95 / 46.46)과 코어 40% 조합의 값은 본 적이 없다.
- **PE4를 뺀 이유는 사용자 방침(공시 미사용)이지 사전 검증된 근거가 아니다.** 변형은 DS4 결과를 본 뒤에 선택했다.
- **학습·확인·보류 구간은 이미 오염**돼 있다(앞선 연구들에서 반복해 본 구간).
- **누적 시험 271회** 기준 우연 통과 기대 건수는 271 × 0.05 = 13.55건이다(시험들이 독립이 아니므로 근사).
- **삼성전자·SK하이닉스 의존**: 코어 N=2가 사실상 두 종목이다(코어 40%일 때 두 종목의 계좌 평균 비중이 약 40% 안팎). 아래 진단에서 별도로 본다.

## 6. 정의 (DS4와 같음, 조정 금지)

- **코어 40%**: 판단일 d의 월말 K200P 구성(PIT, 코스피, 제외 규칙) 안 **당일 시총 상위 2종목을 시총 비율로 보유**. 신호는 d 종가, 체결은 d+1 종가. 보유 종목이 상위 2위 밖으로 나간 날을 1일로 세어 **연속 5거래일째에만 교체**(상위 2위 안의 비보유 종목 중 시총 최대로, 돌아오면 카운트 리셋). 처음 편입은 2017-04-03 종가 신호로 2017-04-04 종가에 매수. 비중은 처음 편입과 구성 변경 체결일에만 신호일 시총 비율로 맞추고 그 사이에는 되돌리지 않는다. 비용 = 수수료 0.015% + 거래세(매도) + 슬리피지 0.1%. 거래정지·폐지 처리는 연구 CS와 같다. 사전 점검 이력: 2017-04-04 삼성전자+SK하이닉스, 2022-02-09 SK하이닉스 → LG에너지솔루션, 2023-12-21 LG에너지솔루션 → SK하이닉스(DS4 코어 이력과 같음).
- **위성 60%**:
  - DS5: **W3 + LV1** 일별 순수익률의 직전 250거래일 표본 표준편차 역수에 비례한 비중(연구 IVA와 같은 코드·창). 종가 t에 목표 비중을 계산해 다음 거래일 종가에 고정 금액으로 이동. 사전 점검에서 **워밍업 0일**(두 구성요소 모두 2017 평가 시작 이전 이력 보유)이고, 워밍업 이후 평균 목표 비중은 W3 48.40% / LV1 51.60%이다. 워밍업 규칙은 DS4와 같이 "이력이 250거래일 미만인 구성요소만 있는 동안은 가용 구성요소 균등 비중"이지만 이번에는 적용되는 날이 없다.
  - DS6: **LV1 단독**. 목표 비중 100%. 변동성 역수 배분은 구성요소가 하나라 결과에 영향이 없다.
- **합성**: 초기 배분 2017-04-03 종가(비용 없음). 매일 종가에 목표 비율(코어 40% / 위성 60%)과 현재 비중의 차이를 고정 금액으로 계산해 다음 거래일 종가에 이동하고, 이동 금액의 **0.25%**를 한 번, 들어가는 슬리브가 부담한다(정보용으로 0.50%와 0도 보고).

## 8. 게이트 (기존 정의 그대로, 완화 없음)

A~H는 `scripts/researchGates.ts` 정의를 쓴다. **A = 069500 대비 CAGR +2%p 이상 ∧ MDD 이하, B = 세 구간 중 2개 이상, G = 진입 건수의 합(평가 시작 이후) ≥ 100, 완화 없음.** 해석을 고정하는 항목:

- **C**: 모든 구성요소(위성 W3·LV1과 코어)를 하루 지연(체결 d+2)해 돌린 순수익(변동성 창 이력 포함)으로 같은 합성 규칙을 적용. CAGR 하락 ≤ 1%p ∧ MDD 악화 ≤ 2%p.
- **D (이웃, 평가 구간 전체 CAGR ≥ 069500이면 통과; 모든 이웃이 통과해야 D 통과)**:
  - 공통: 코어 비중 30%·50%, 코어 종목 수 1종목·3종목.
  - DS5 위성 구성 이웃: **(i) W3:LV1 비중을 50:50 고정한 위성**(변동성 역수 대신 상수 반반, 매일 목표 비중으로 이동), **(ii) 한쪽 비중 상한**. 사용자 지정 "한쪽 비중 상한 지정"의 해석을 결과 전에 고정한다: **W3 비중 상한 60%** 이웃과 **LV1 비중 상한 60%** 이웃을 각각 한 개씩(초과분은 나머지 구성요소에 비례해 이동; 연구 DR/PE4 상한과 같은 `capRedistribute`). 따라서 DS5의 이웃은 코어 4개 + 반반 1개 + 상한 2개 = **7개**.
  - DS6 위성 구성 이웃: 변동성 창 120일·500일. **구성요소가 하나뿐이라 창이 결과에 영향을 주지 않는 퇴화 이웃**이며 사전 점검에서 기준과 비트 단위로 동일함을 확인했다. 이웃 수는 코어 4개 + 창 2개 = **6개**이고, 창 이웃 두 개는 기준값과 같은 값으로 통과/탈락이 기준 CAGR과 같게 판정된다(실질 독립 이웃은 4개).
- **E**: **판정은 위성 상위 3거래 대체**다. 위성 구성요소 각각의 평가 구간 닫힌 거래 중 구성요소 계좌 대비 손익 상위 3개를 069500 수익률로 바꾼 위성(같은 배분 규칙)과 **실제 코어**를 합성한 평가 구간 전체 CAGR ≥ 069500. **코어 상위 3개 거래(삼성전자·SK하이닉스 연속 보유 기간 포함, 기간 끝에 열린 보유 포함) 대체와 위성·코어 둘 다 대체한 전체 CAGR은 보고만 하고 판정에 쓰지 않는다.** 결과를 본 뒤 이 해석을 바꾸지 않는다.
- **F**: 위성 구성요소마다 원래 시험의 무작위 대조(같은 신호일·주문 수, 같은 청산 규칙, 시드 20261022, 1,000회)를 같은 번호끼리 같은 배분 규칙으로 합쳐 위성 1,000개를 만들고, 각각을 **실제 코어(고정)** 와 40:60으로 합성한 분포 대비 후보 실제 CAGR의 백분위가 기존 임계(95)를 넘어야 한다. 참고로 DS5는 구성요소 2개 기준 1 − 0.05/2 = 97.50, DS6은 1개 기준 95.00 이상 여부도 표시한다. 코어는 무작위화하지 않는다.
- **G**: 위성 구성요소 진입 건수 + 코어 진입 건수의 합 ≥ 100.
- **H**: **기준선 069500만으로 판정**(조건1 CAGR ≥ 기준선 + 1%p, 또는 조건2 MDD ≤ 기준선 − 3%p ∧ CAGR ≥ 기준선 − 1%p; 연구 PEAD와 같은 상수). CS2·DS2·DS4 대비 결과는 참고 표시이며 판정에 쓰지 않는다.

## 9. 진단 (통과 판정에 사용하지 않음)

- 연도별 DS5·DS6 − 069500 초과수익과 승/패(2017은 04-04부터, 2026은 10-26까지 부분 연도).
- **삼성전자 + SK하이닉스 평균 계좌 비중**(코어 안, 위성 안 보유 포함 전체 계좌 기준).
- **코어에서 두 종목을 뺀 경우 성적**(코어 순위 목록에서 삼성전자·SK하이닉스만 제외, 나머지 규칙·위성·합성은 같음; 새 후보가 아닌 진단).
- **구성요소별 초과 기여**(코어·W3·LV1의 069500 대비 초과수익 기여와 이동·내부 비용 잔여).
