[C] 방어형(주식 아니면 현금).
- C1: 069500 월말 종가가 10개월 이동평균 위면 80:20 전략 100%, 아래면 현금 100%.
- C2: C1과 같되 필터 위일 때 80:20 전략 70% + 현금 30%.
- C3: C1과 같되 주식 부분을 위성 100%(0:100)로.
- C 판정(모든 구간 각각 충족해야 통과): G1 CAGR ≥ 연 5%, G2 일별 MDD ≥ -15%, G3 최악 12개월 수익률 ≥ -15%, G4 매매 하루 지연 버전도 G1~G3 충족, R1 이웃값 8·12개월 이동평균에서도 G1~G3 충족.
- 참고 보고(판정 아님): 069500 원주가 대비 CAGR 차이, 연 변동성, 현금 보유 기간 비율, 필터 전환 횟수.

2. **최악 12개월 수익률**: 일별 평가액 경로에서 기준점 = [구간 시작 직전 거래일(첫 구간은 첫 체결일)] + 구간 안의 월말 거래일. 연속 기준점 i와 i+12 사이 수익률의 최솟값(두 기준점 모두 구간 안). 구간 끝이 월말이 아니면 마지막 미완성 달은 쓰지 않는다.
3. **B 60:40 (시험 146)**: M = mix(S3, 0.4, B&H 가격), 지연 = mix(S3 지연, 0.4).
   - G1 CAGR ≥ B&H 가격 + 0.3%p, G2 MDD ≤ B&H 가격 MDD + 3.0%p, G3 샤프 ≥ B&H 가격 샤프, G4 CAGR − 지연 CAGR ≤ 0.5%p. 학습·확인·보류 각각.
   - R1(전 기간, 60:40): 모멘텀 3·9·12개월, 정리 기준 0.5%·2.0%, 상위 2·4개 업종(하나씩만 바꿈). R2(전 기간): 달력 월별 (60:40 − B&H 가격) 누적수익률 차이가 가장 큰 1개월의 60:40 일수익률을 B&H 가격 일수익률로 바꾼 CAGR. R3: 매 신호일 유효 업종 3개 무작위(시드 20261022, mulberry32, 부분 Fisher–Yates)·업종별 상위 3종목·같은 정리, 1,000회, 60:40 CAGR 백분위(= 60:40보다 작은 회수 ÷ 1,000 × 100).
   - **R 통과 기준(기존 사전등록에 기준이 없어 이번에 새로 정함, 실행 전 고정)**: R1 = 6개 이웃값 모두 전 기간 CAGR > B&H 가격 전 기간 CAGR. R2 = 바꾼 뒤 전 기간 CAGR > B&H 가격 전 기간 CAGR. R3 = 백분위 ≥ 95.
   - **B 통과** = G1~G4가 학습·확인·보류 모두 O(12개) 그리고 R1·R2·R3 모두 O.

4. **C 공통 (시험 147~149)**:
