# 시장 수급 전략 2변형 사전등록 (누적 시도 120 → 122, 홀드아웃 실행 시 +1)

승인 범위: 사전등록 커밋 → 백테스트 1회. 재실행 금지. 결과를 본 뒤 정의·기준·변형·선택 규칙 변경 금지. 다음 라운드 자동 시작 금지.
브랜치 claude/ma-v3-portfolio-cap-run (병합 금지). 외부 요청 0건, DB 읽기만·쓰기 금지.

## 사용자 문안 (원문)
- [데이터] investor_flow_market의 KOSPI 외국인 순매수 금액, 기관 순매수 금액. 가격·정제·비용은 research/vol-target-prereg.md(a7b24da5)와 같음(069500, 114260, 편도 0.015% + 0.05%, 세금 미반영).
- [신호] 매월 마지막 거래일까지의 최근 60거래일 순매수 금액 합 S. 부호만 사용(규모 무관).
- [체결] 신호는 월말 장 마감 후 확정된 것으로 보고, 다음 거래일 종가에 체결. 지연 변형은 그다음 거래일 종가.
  - F1: 외국인 S > 0이면 069500 100%, 아니면 069500 50% + 114260 50%.
  - F2: 외국인 S와 기관 S가 둘 다 < 0일 때만 069500 50% + 114260 50%, 그 외 069500 100%.
- [기간] 학습 2010-01-01~2016-12-31, 확인 2017-01-01~2021-12-31, 홀드아웃 2022-01-01~끝. 비교 B&H = 069500 보유, 참고로 KOSPI.
- [기준(효율형, 각 관문 공통)] G1 CAGR ≥ B&H − 1.0%p / G2 샤프 > B&H / G3 CAGR÷MDD > B&H / G4 지연 시 CAGR 하락 ≤ 1.0%p.
- [절차] 학습 전부 O 중 샤프 최대 1개 → 확인 → 홀드아웃. X면 그 단계에서 종료. 선택 안 된 변형의 확인·홀드아웃 계산 금지.
- [추가 검증, 홀드아웃까지 전부 O일 때만] R1 주변 값: 60일을 40·90일로 바꾼 2개 조합 전 기간 CAGR ≥ B&H 전 기간 CAGR. R2: 50% 축소 구간 중 B&H 대비 초과 수익이 가장 큰 1개 구간을 100%로 바꿔도 전 기간 샤프 > B&H. R3: 같은 개수·길이의 축소 구간을 무작위 월말에 1,000회 배치(시드 20261019), 전 기간 샤프 상위 5% 안. 최종 통과 = 세 관문 + R1~R3.
- [정보용, 학습 구간만] 월말 외국인 S 부호별 다음 달 069500 평균 수익과 표본 수, 차이의 t값. 기관도 같은 표.
- [보고] 숫자와 표만: 사전등록 순서 / 각 단계 표(CAGR, MDD, 샤프, CAGR÷MDD, 연변동성, 축소 상태 월 비율, 전환 횟수, 누적 비용, 지연 CAGR, G1~G4) / 정보용 표 / 계산한 단계의 연도별 수익률(전략, B&H) / 읽은 행·쓴 행(0).

## 구현 세부 (결과를 보기 전에 고정하는 해석 — 사용자 문안에 없는 부분)
1. 가격·정제·달력·월말·실행 시작일 s0는 vol-target-prereg.md 구현 세부 1과 같다(069500·114260 수정주가 etf_daily_prices.adj_close, 정제 규칙 동일, 달력 = 두 자산 정제 후 거래일 교집합, 월말 = 다음 거래일의 연월이 달라지는 날, s0 = 2009년 마지막 거래일, 단일 실행에서 창을 잘라 쓰며 창은 s0 다음 거래일부터, 초기 진입 비용은 창 밖).
2. 투자자 자료: investor_flow_market의 market = 'KOSPI' 행 전부(trade_date, frgn_ntby_amt, orgn_ntby_amt). S(월말 날짜 d) = 이 표에서 trade_date ≤ d인 가장 최근 60개 행의 해당 금액 합(표 자체의 거래일 열을 쓰며 가격 달력과 별개). 그런 행이 60개 미만이거나 금액 값이 비어 있으면 그 월말은 신호 없음 → 직전 상태 유지(s0에서는 069500 100%). 월말 날짜에 해당하는 행이 표에 없는 월말은 개수를 보고한다.
3. 목표 상태: F1 S_외국인 > 0 → 100%(069500 100%), 아니면 축소(069500 50% + 114260 50%). F2 S_외국인 < 0 이고 S_기관 < 0 → 축소, 그 외 100%. S = 0은 부등호 그대로 적용(F1: 0이면 축소, F2: 0이면 축소 조건 불충족).
4. 시작 상태: s0 종가에 069500 100% 진입(B&H와 동일, 진입 비용은 창 밖). s0도 월말이므로 s0 신호가 있으면 s0 다음 거래일 종가에 체결(지연 변형은 그다음 거래일).
5. 체결: 매 월말 신호(월말 인덱스 k) 후 목표 상태가 현재 상태와 다르면 k+1 거래일 종가(지연 변형은 k+2)에 목표 비중(100/0 또는 50/50)으로 맞춘다. 같은 상태면 거래 없음(축소 상태에서 비중은 가격 따라 자연 변동). 비용 = (매수액+매도액)×(0.015%+0.05%), 체결일 가치에서 차감. 체결일이 달력 끝을 넘으면 체결 없음. 일 수익률은 전일 종가 보유 상태로 평가절하한 뒤 체결 비용을 반영(vol-target-prereg.md 구현 세부 4와 같은 방식).
6. 지표: CAGR, MDD, 샤프, CAGR÷MDD, 연변동성, G4의 CAGR 하락(무지연 − 지연), B&H·KOSPI 정의는 vol-target-prereg.md 구현 세부 5(= seasonality-prereg.md 구현 세부 6)와 같다. 선택 동률은 전환 횟수가 적은 쪽.
   - 축소 상태 월 비율 = 창 안에 월말 날짜가 있는 월말 신호 중 목표 상태가 축소인 비율(%; 신호 없음 월말은 직전 상태로 센다). 전환 횟수 = 창 안 체결일 수(s0 제외, 무지연 실행 기준). 누적 비용 = 창 내 체결 비용/체결 직전 가치의 합(%).
7. 정보용(학습 구간만): 월말 d가 s0 이상이고 다음 월말 d′ ≤ 2016-12-31인 모든 쌍에 대해 069500(정제) d 종가 → d′ 종가 수익률(%)을 구해, d의 S가 > 0인 달과 < 0인 달(S = 0은 음 쪽에 포함하지 않고 별도 열이 아니라 양·음 어디에도 넣지 않으며 개수를 보고)로 나누어 평균, 표본 수, 평균 차이(양 − 음)와 Welch t값(분모 = √(s₁²/n₁ + s₂²/n₂))을 외국인·기관 각각 보고한다. 신호 없는 월말은 제외.
8. 추가 검증 R1~R3은 홀드아웃까지 전부 O일 때만 계산한다(코드는 이 경우에만 실행). 전 기간 = 2010-01-01~달력 마지막 거래일(창은 s0 다음 거래일부터).
   - R1: 선택 변형의 S 합산 길이를 40·90거래일로 바꾼 2개 조합(나머지 규칙 동일)의 무지연 전 기간 CAGR이 둘 다 ≥ B&H 전 기간 CAGR이면 O.
   - R2: 선택 변형 기본(60일) 무지연 실행에서 축소 상태 구간 = 연속된 축소 목표 월말 신호들이 만드는 보유 구간(축소 체결일 다음 거래일부터 100% 복귀 체결일까지의 일 수익률). 각 구간의 초과 수익 = 구간 일 수익률 복리(전략) − 같은 날 B&H 복리(%p). 초과 수익이 가장 큰 1개 구간의 월말 신호들을 100%로 바꿔 다시 전체를 시뮬레이션해 전 기간 샤프 > B&H 전 기간 샤프이면 O. 축소 구간이 없으면 N/A.
   - R3: 기본 실행의 축소 구간 개수·각 길이(연속 월말 신호 개수)와 같은 구간들을 월말 신호 위치(s0 포함, 전 기간 마지막 신호 가능 월말까지)에 무작위로 겹침·인접 없이(구간 사이 최소 1개 월말 100%) 배치하는 시도를 1,000회(rng = mulberry32, 시드 20261019; 구간은 길이 내림차순으로 시작 위치를 균등 추출, 조건 위반 시 그 구간만 재추출) 한다. 각 배치로 다시 시뮬레이션해 전 기간 샤프를 구하고, 기본 실행 샤프 이상인 배치 수 ÷ 1,000 ≤ 5%이면 O.
   - 최종 통과 = 홀드아웃까지 G1~G4 전부 O + R1~R3 전부 O.
9. 상수는 lib/flowTimingConfig.ts(및 lib/seasonalityConfig.ts, lib/etfAllocationConfig.ts)에 둔다.
