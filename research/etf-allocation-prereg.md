# ETF 자산 배분 4변형 사전등록 (누적 시도 102 → 106, 홀드아웃 실행 시 +1)

승인 범위: 사전등록 커밋 → 실행 1회. 재실행 금지. 결과를 본 뒤 정의·기준·변형·선택 규칙·정제 규칙 변경 금지.
브랜치 claude/ma-v3-portfolio-cap-run (병합 금지). 외부 요청 0건. DB 읽기만(etf_daily_prices, KOSPI 지수), 쓰기 금지.

## 데이터와 정제 규칙 (실행 전 고정)
- 가격: etf_daily_prices.adj_close(수정주가, 분배금 반영). 자산: 069500(주식), 114260(국고채3년), 148070(국고채10년), 132030(금). 261240, 153130은 쓰지 않는다.
- 하루짜리 튐 정제: 어떤 날 t의 일수익률 |r_t| > 8%이고 다음 날 r_{t+1}의 부호가 반대이며 |(1+r_t)(1+r_{t+1}) − 1| < 2%이면, t의 가격을 t−1과 t+1 가격의 기하평균으로 바꾼다. 단 069500은 같은 날 KOSPI 일수익률 부호가 같고 크기가 절반 이상이면 실제 변동으로 보고 바꾸지 않는다. 바꾼 날짜 목록을 보고.
- 그 외 |r| > 10%인 날은 그대로 두고 목록만 보고(069500은 같은 날 KOSPI 수익률 병기).

## 공통
- 판단·체결: 매월 마지막 거래일 종가에 비중 결정, 같은 종가 체결. 지연 변형은 다음 거래일 종가 체결.
- 비용: 편도 수수료 0.015% + 슬리피지 0.05%, 매도세 없음(ETF). 세금(분배·매매차익 과세)은 반영하지 않으며 한계로 기록.
- 현금은 쓰지 않는다(안전자산은 114260).

## 변형 4개
- A1 정적 혼합: 069500 50%, 148070 30%, 132030 20%, 매월 말 원래 비중으로 재조정.
- A2 추세 전환: 069500 월말 종가 > 최근 10개 월말 종가 평균이면 069500 100%, 아니면 114260 100%.
- A3 듀얼 모멘텀: 069500, 148070, 132030 중 12개월 수익률 최상위 자산을 고르되, 그 수익률이 114260의 12개월 수익률보다 낮으면 114260 100%.
- A4 역변동성: 069500, 148070, 132030 비중을 각 자산의 최근 60거래일 일수익률 표준편차의 역수에 비례하게, 매월 말.

## 기간
학습 2013-01-01~2018-12-31, 확인 2019-01-01~2022-12-31, 홀드아웃 2023-01-01~데이터 끝.
비교 기준 B&H = 069500 단순 보유(같은 기간). 참고로 KOSPI, D4도 같은 기간 표시.

## 기준: 각 관문 공통
- G1 CAGR ≥ B&H CAGR − 2.0%p
- G2 MDD ≤ 0.70 × B&H MDD
- G3 CAGR÷MDD > B&H의 CAGR÷MDD
- G4 체결 1거래일 지연 시 CAGR 하락 ≤ 1.0%p

## 절차
1. 학습: 4변형 G1~G4. 전부 O인 변형 중 학습 CAGR÷MDD 최대 1개 선택(동률이면 연 회전율 낮은 쪽). 없으면 "선택 없음"으로 종료.
2. 확인: 선택된 1개만 G1~G4. 하나라도 X면 "통과 아님"으로 종료, 홀드아웃은 계산하지 않음.
3. 홀드아웃: 확인을 전부 통과한 경우에만. 전부 O일 때만 최종 "통과".
선택되지 않은 변형의 확인·홀드아웃 수치는 계산·보고하지 않는다.

## 보고
숫자와 표만, 판정·추천 문장 금지. (a) 사전등록 해시와 순서 (b) 정제 결과(바꾼 날짜 목록: 종목·날짜·원래·바꾼 가격, |r|>10%로 남긴 날 목록) (c) 학습 표(4변형, B&H, KOSPI, D4의 CAGR / MDD / CAGR÷MDD / 연변동성 / 연 회전율 / 누적 비용, G1~G4 O/X) (d) 선택 결과 (e) 확인 표와 G1~G4 O/X, 연도별 수익률(전략, B&H) (f) (해당 시) 홀드아웃 표와 G1~G4 O/X, 연도별 수익률 (g) 선택 변형의 월별 자산 보유 비중 요약(자산별 평균 비중, A2·A3면 자산별 보유 개월 수) (h) Supabase 읽은 행·쓴 행(0), 외부 요청(0), 소요 시간.

## 구현 세부 (결과를 보기 전에 고정하는, 위 정의의 해석 — 사용자 문안에 없는 부분)
1. 자산 달력 = 4개 자산(정제 후)의 거래일 교집합. 정제는 각 자산 자체 거래일 계열에서, 원자료 수익률로 탐지하고 원자료 이웃 가격의 기하평균으로 동시 치환한다(마지막 날은 t+1이 없어 대상 아님). 069500의 KOSPI 일수익률이 없는 날은 면제 없음. 정제는 전 이력에 적용하고 목록도 전 이력을 보고한다. "|r|>10% 남긴 날"은 정제 후 가격 기준.
2. 월말 = 달력에서 다음 거래일의 연월이 달라지는 날(데이터 마지막 날은 월말로 보지 않음). 첫 결정일 = 2012-12의 마지막 거래일, 이후 매 월말 결정. 단일 실행에서 창을 잘라 쓴다(학습·확인·홀드아웃이 같은 실행의 연속 구간, 포지션 이월).
3. 초기 진입 비용은 첫 결정일(2012-12 말)에 발생해 어느 창에도 포함되지 않는다(지연 변형은 진입이 다음 거래일이라 학습 창에 들어온다 — 한계로 기록, B&H도 진입 비용이 창 밖).
4. A2의 "최근 10개 월말 종가 평균"은 결정일 월말을 포함한 최근 10개 월말의 단순 평균. A3의 12개월 수익률 = 결정일 월말 종가 ÷ 12개월말 전(월말 목록에서 12칸 앞) 월말 종가 − 1(수정주가 기준). 최상위 자산의 수익률 < 114260 수익률이면 114260 100%(같으면 최상위 자산). A4의 표준편차 = 결정일까지 최근 60개 일수익률(달력 기준)의 표본표준편차(n−1), 비중 ∝ 1/σ를 합 1로 정규화.
5. 체결: 보유 포지션은 일별 수익률로 평가절하(드리프트)하고, 체결일 종가에 목표 비중과의 차이만큼 매수/매도한다. 비용 = (매수액 + 매도액) × 0.065% (편도 0.015% + 0.05%), 체결일 가치에서 차감. 연 회전율 = 창 내 체결의 Σ[(매수액+매도액)/2 ÷ 체결 직전 가치] ÷ 창 연수. 누적 비용 = 창 내 체결 비용/체결 직전 가치의 합(%).
6. 지표: CAGR = computeCagrPct(총수익률, 창 시작일, 창 종료일), MDD = computeCumulativeAndMdd, 연변동성 = 일수익률 표본표준편차×√252, 창 종료일은 홀드아웃의 경우 달력 마지막 거래일. CAGR÷MDD는 MDD>0일 때. G4의 CAGR 하락 = (무지연 CAGR − 지연 CAGR), 같은 창.
7. B&H = 069500 정제 수익률(진입 비용은 창 밖). KOSPI = DB KOSPI 지수 종가 일수익률. D4 = scripts/research-audit-peg.ts simulateD4(기존 정의 그대로, Parquet 캐시 사용 — 외부 요청 아님)의 일 수익률을 같은 창으로 자른 것.
8. 연도별 수익률 = 창 내 해당 연도의 일수익률 복리(홀드아웃 마지막 해는 데이터 끝까지의 부분 연도). (g) 비중 요약 = 창 내 결정일의 목표 비중 평균, A2·A3는 목표가 해당 자산 100%인 결정일 수(개월).
9. 상수는 lib/etfAllocationConfig.ts에 둔다.
