# 연구 LTR — 저회전 매매 규칙 (W1 = 시도 251, W2 = 252, W3 = 253) 사전등록

작성 2026-10-28(사용자 지정). **이 문서는 시험 실행 전 사전등록이며 실행 전에 커밋한다(커밋 해시는 보고에 기록).** 국내 주식과 현금만 쓴다(ETF 매매 금지, 069500은 기준선으로만 쓴다). 모든 구간 성적은 개발 데이터 내 성적이다. 연구 브랜치 claude/ma-v3-portfolio-cap-run에서만 작업하고 main에는 병합하지 않는다. 통과해도 운영 적용·PR은 하지 않는다. 누적 시도: 250에서 이어서 **253**, 우연 통과 기대 건수 **253 × 0.05 ≈ 12.65**.

## 1. 목적

연구 WFR(M1~M3, 시도 248~250)에서 학습 모델의 예측 점수가 약하지만 신호를 가졌다(평균 IC 0.04, 상위 10종목의 20일 평균 실제 수익 0.82~1.18% > 유니버스 평균 0.64%, 라벨 셔플 대조보다 훨씬 위). 그러나 매매 규칙이 점수 순위 30위 밖이면 곧바로 파는 구조라 연 회전율 2,091~3,782%, 비용 연 10.1~18.2%가 우위를 지웠다. **같은 점수에 최소 보유일과 느슨한 매도 순위를 더해 회전율을 낮추면 우위가 비용 뒤에도 남는지** 시험한다. 점수·특성·모델은 바꾸지 않는다(모델 재학습 없음).

## 2. 선택 편향 명시 (정식 소진)

**이 규칙들은 M1~M3의 결과를 본 뒤에 고른 것이다.** 결과(IC 0.04, 상위 10종목 20일 평균 수익이 유니버스 평균보다 높지만 높은 회전율과 비용이 우위를 소거)를 본 뒤 저회전 쪽으로 규칙을 바꿨고, 최소 보유일 10~20일·매도 순위 60~100이라는 값도 그 관찰에서 나온 것이다. 따라서 이 시험의 결과는 순수한 사전 가설 검증이 아니라 같은 데이터를 한 번 더 본 탐색이다. 시도 번호 251~253을 정식으로 소진한다.

## 3. 중복 확인 결과 (읽기 전용, 저장소 검색)

점수 상위 종목을 최소 보유일 + 느슨한 매도 순위로 운용하는 저회전 변형을 시험한 적은 **없다**. 가장 가까운 것은 연구 WFR의 M2·M3(최소 보유일 0, 매도 순위 30)이며 같은 점수를 재사용하는 직접 선행이다. 기존 연구 LS(시총 순위 트레일링), LM·LE(모멘텀 순위 유지 한도 keepRank)는 순위 유지 한도라는 아이디어는 같지만 점수가 다르다(모멘텀 순위, 시총 순위). 따라서 세 후보 모두 새로 시험하고 계수한다.

## 5. 사용자 지정 규칙 (그대로 옮김)

- **진입**(기존과 같음): 매일 종가에서 점수 순위 확정, 다음 거래일 종가 체결. 상위 10위 안 신규 종목을 동일가중 10%로 편입, 최대 10종목.

- **평가 구간·기준선**: WFR과 같다(수익 집계 2014-01-02, 학습 2014~2016 / 확인 2017~2021 / 보류 2022~, 069500 새 기준선 전체 9.57 / 42.03).

## 6. 구현 정의 (사용자 정의를 바꾸지 않는 해석, 실행 전 고정)

기준값은 `lib/lowTurnoverConfig.ts`, 코드는 `scripts/research-low-turnover.ts`(연구 WFR의 시뮬레이션 코드와 같은 엔진·게이트).

1. **최소 보유일 계산**: 판단일 c에서 `c − (진입 체결일) ≥ 최소 보유일`이면 (a) 충족. 즉 체결 종가에 산 날부터 센 거래일 수가 최소 보유일 이상인 판단일부터 매도 신호가 가능하고, 매도 체결은 그다음 거래일 종가다(실제 보유 기간 ≥ 최소 보유일 + 1). 최소 보유일 안에서는 순위와 무관하게 유지한다(상장폐지 강제 청산은 엔진이 항상 적용).
2. **매도 순위 (b)**: 판단일 점수 순위(그날 K200P 소속 점수가 있는 종목 중 1부터) > 매도 순위. 그날 점수가 없는 종목(K200P 소속 이탈 등)은 순위 밖으로 보아 최소 보유일이 지났으면 매도("유니버스 이탈"). 그날 행이 없는 보유 종목(거래정지)은 판단을 미룬다.
3. **진입 후보**: 점수 상위 10위 안 종목 중 보유하지 않은 것만(엔진이 보유·이미 신호난 종목을 거름). 상위 10위 안에 신규 종목이 없으면 빈 슬롯은 현금으로 둔다(사용자의 "없으면 현금"). WFR(후보 깊이 40)과 달리 후보를 10위로 제한한 것이 저회전 규칙의 정의다.
4. **엔진 관습**: 매도 신호가 난 종목은 체결일까지 슬롯을 차지하고, 비는 슬롯은 체결 뒤 다음 판단일에 채워진다(연구 L~WFR 전부와 같음). 평가 첫 판단일 2014-01-02(2014년 모델 점수), 직전 거래일은 현금 대기, 수익률 집계는 2014-01-02부터.
5. **게이트 F 무작위 대조**: 실제 실행의 진입 판단일·진입 수와 같게 그날 K200P에서 무작위 종목을 뽑고, 보유 종목은 최소 보유일이 지난 판단일부터 매일 확률 q로 이탈한다. q = (실제 실행의 순위 이탈 청산 건수) ÷ (실제 실행의 "최소 보유일 경과 후 보유 판단일" 합). 1,000회, 기존과 같은 시드. 다중시험 참고선 1 − 0.05 ÷ 3.
6. **게이트 H**: 069500으로 판정(조건1 CAGR ≥ 기준선 + 1%p, 조건2 MDD ≤ 기준선 − 3%p ∧ CAGR ≥ 기준선 − 1%p; 연구 PEAD와 같음). M2·M3(WFR 규칙)와 L3(시총 상위 5 편입·10위 밖 매도, 같은 엔진으로 재계산)는 참고 열이다.
7. **스타일 쏠림 진단**(판정 불사용): 보유 종목의 횡단면 순위 정규화 특성(로그 시총, 60일 변동성, 로그 거래대금; 0 = 그날 K200P 최소, 1 = 최대, 유니버스 평균 0.5)을 보유 평가액 가중으로 평균한다. 비교용으로 WFR 규칙의 M2·M3도 같은 정의로 계산한다.
8. **gross/net**: 비용 제외 실행은 수수료·거래세·슬리피지를 모두 0으로 둔 같은 규칙이다.

## 11. 경고 문구

- **홀드아웃 오염**: 보류 구간(2022~)은 이미 여러 번 본 데이터이고, 학습·확인 구간도 앞선 연구들에서 반복해 본 구간이다. 규칙은 WFR 결과를 본 뒤 정했다(2절).
- **우연 통과**: 누적 시험 253번 중 실력이 없어도 5% 수준 기준 하나를 우연히 넘는 후보가 평균 253 × 0.05 = **12.65개** 나올 것으로 기대된다(시험들이 독립이 아니므로 근사).
- **스타일 요인 의존 가능성**: 모델은 시총·60일 변동성·거래대금 같은 스타일 요인에 크게 의존한다(WFR 특성 중요도 상위). 점수가 종목 선택 능력이 아니라 스타일(예: 저변동·대형주) 노출일 수 있고, 저회전 규칙은 그 노출을 오래 유지한다. 스타일 쏠림 진단(6절 7)을 함께 본다.
- **재무 데이터 미사용**: 가격·거래량·시총·외국인 수급만으로 만든 점수이다.
- **외국인 수급 특성 2개만 사용**: M2·M3의 수급 특성은 외국인 순매수 금액 5·20일 합뿐이다(기관 없음, WFR 사전등록 5절 1).
- 모델 학습 구간 단축(첫 예측 연도 학습 2011~2013), 과적합 위험, 종가 판정·체결 이상화, 슬리피지 가정, 현금 이자 0, 배당락 미조정, 단일 경로 in-sample, 엔진 관습, 저회전 규칙에서는 최소 보유일 동안 손실이 커져도 유지된다(손절 없음).
