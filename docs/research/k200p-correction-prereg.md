## 0. 선택 편향 기록

## 2. 보정값의 출처와 규칙
- **출처**: KRX Open API 일별매매정보(`data-dbg.krx.co.kr/svc/apis/sto/stk_bydd_trd`, 요청 `basDd=YYYYMMDD`, 인증 헤더)의 해당 종목·날짜 **공식 등락률(FLUC_RT, %)**. 기준가격 조정(분할·증자 등)이 반영된 값으로 본다(경제적 등락률).
- **(a)** KRX 등락률의 절댓값이 그날의 가격제한폭(2015-06-14까지 ±15%, 이후 ±30%) + 허용 0.5%p(`lib/dataQualityConfig.ts`의 DQ_LIMIT_*와 같은 기준) **이내**이면 그 값을 그날 수익률로 사용 → 구분 "확인".
- **(b)** KRX 값도 제한폭을 넘거나 조회가 안 되면(응답 없음·종목 없음·오류) 그날 수익률을 **0%**로 처리 → 구분 "미확인".
- **(c)** 대조용 정상일 5건에서 KRX 등락률과 기존 수정 수익률이 **0.1%p를 넘게** 다르면 보정을 **중단하고 보고**한다. 대조 종목·날짜(고정): 삼성전자(005930) 2013-03-15, SK하이닉스(000660) 2017-08-22, 신세계(004170) 2019-05-14, 현대글로비스(086280) 2022-09-06, 고려제강(002240) 2024-02-27. KRX 응답이 비어(휴장 등) 대조가 안 되면 다음 평일로 1일씩 최대 3일 미룬다(날짜 재선정은 이 규칙만).
- **호출 수**: 17건 날짜 17회 + 대조 5회 = 22회(재시도 포함 상한 40회). KIS 호출 없음. KST 14:00~15:40 호출 금지, 호출 사이 0.8초 이상.

## 3. 보정 적용 방식(구현)
- **기존 스냅샷·가격 Parquet·저장소 코드의 기본 동작은 바꾸지 않는다.** 보정은 덮어쓰기 표(종목, 날짜, 보정 수익률, 구분)로 따로 **Supabase Storage `research/corrections/` 아래**에 저장한다(저장소·artifact에는 올리지 않음).
- 스크립트에 옵션을 추가한다: 환경 변수 `PRICE_CORRECTION=k200p17`일 때만 적용(**기본 미적용**, 기존 재현성 유지). 적용 방식: 해당 종목·날짜의 수정 종가가 이벤트 전 행 대비 (1 + 보정 수익률)이 되도록 **이벤트 이전 모든 행의 수정 시가·고가·저가·종가에 같은 계수를 곱한다**(분할 조정과 같은 방식, 이벤트일 이후 가격은 그대로, 원 종가·거래량·시총은 그대로).
- 069500 벤치마크는 보조 파일(ETF 가격)이라 이 보정과 무관하다. 보정 적용·미적용 실행의 069500 기준선 표가 같음을 확인한다.

## 4. 재채점 (이 목록만, 결과를 보고 추가하지 않음)
DS6, DS8, RM1C, MV1C, RT1, RT1F — 선정 이유: 069500보다 연속 CAGR이 높았던 시험(RM1C, MV1C, RT1, RT1F)과 그 기준(DS6, DS8은 DS6 변형).
- **판정 원칙**: 기존 시험의 공식 판정은 그대로 둔다. 재채점은 **정의·관문 A~H·이웃값·난수 시드(20261022)·무작위 횟수(1,000)를 그대로** 두고 수익률 입력(가격)만 바꿔 관문을 다시 계산한다. 모든 관문을 통과하는 시험이 나오면 "오류 수정 후 통과(포워드 확인 필요)"로 표시한다. F는 백분위 95 이상(기존 기준).
- **실행 순서**: ① 보정 미적용으로 DS6 재현(연속 11.70 / 39.15, 구간 1 4.10 / 24.51, 기존 관례) ② 보정값 수집 → 17건 표 ③ 보정 적용으로 069500 기준선이 변하지 않음을 확인 ④ 6개 재채점.
- 시험 번호는 원 시험 번호(DS6 271, DS8 274, RM1C 295, MV1C 303, RT1 306, RT1F 307)를 표지로만 쓰고 누적 시험 횟수에 더하지 않는다. 재현 기록 대조(DS6 기록값 등)는 보정 적용 모드에서는 "달라짐(기대)"로 출력하고 중단하지 않는다.
