# 연구 B — 저변동 + 모멘텀 방어 포트폴리오 (B1 = 시도 206, B2 = 시도 207) 사전등록

작성 2026-10-26(사용자 지정). **이 문서는 시험 실행 전 사전등록이다. 시험 실행은 사용자 승인 후에만 한다.** 개별 주식과 현금만 쓴다(ETF 매매 금지, 069500은 기준선과 신호 참고용). 모든 구간 성적은 개발 데이터 내 성적이다. 보류 구간(2022~)은 이미 여러 번 본 데이터라 순수 검증(홀드아웃)이 아니다.

## 1. 목적

방어형 질문: "낙폭이 큰 시장에서 변동성이 낮고 12-1개월 모멘텀이 양(+)인 대형주 묶음을 일별 규칙(이긴 종목 유지)으로 보유하면, 069500보다 수익이 낮지 않으면서 낙폭이 10%p 이상 작은가?" 낙폭이 줄어든 원인이 단순히 현금 비중 때문인지 구분하기 위해 투자 비중을 반드시 함께 보고한다.

## 3. 구현 정의 (실행 전 고정)

기준값은 lib/lowvolMomentumConfig.ts에 있다. **아래 항목 중 "해석"으로 표시한 것은 사용자 지정 문구에 없어 문서화 시 정한 해석이다 — 승인 시 함께 확인받는다.**

1. **입력·비용**: scripts/research-e-new-goal.ts(75c8b69), docs/research/f-daily-trend-prereg.md 구현 세부 1과 같은 입력·비용을 쓴다(Parquet 2010~, 적용된 조정 이벤트, 월말 시장 목록, dart 이름, 업종, 069500 raw·adj). 매수 = 종가 × (1 + 0.1%) × (1 + 0.015%), 매도 = 종가 × (1 − 0.1%) × (1 − 0.015% − 그날 거래세). 현금 이자 0%. 폐지 청산은 기존과 같다(마지막 행이 데이터 끝 − 14일보다 이전이면 그 종목이 처음 행이 없는 날 직전 평가액으로 매도). 외부 요청 0, DB 쓰기 0, 1회 실행이다.
2. **평가 구간**: 평가 시작 판단일 = 거래일 달력(2010-01-04~) 순번 252의 거래일 **2011-01-04**(12-1개월 모멘텀 이력이 처음 채워지는 날; 연구 A와 같다). 수익률 집계는 그 다음 거래일부터, 시뮬레이션은 평가 시작 판단일에 현금으로 시작한다. 구간 = 학습 평가 시작일~2016-12-31 / 확인 2017-01-01~2021-12-31 / 보류 2022-01-01~데이터 끝, 전 기간은 평가 시작일~데이터 끝이다.
3. **유니버스 K200P(d)**: d 행이 있고, d의 20일 평균 거래대금(당일 제외 직전 20행) ≥ 5억이며 제외 규칙(4c1557a: 우선주·스팩·리츠·ETF)에 걸리지 않는 종목 중, d 이하 가장 최근 월말 시장 목록에서 KOSPI인 종목을 d 시총 내림차순(동점 코드 오름차순) 상위 200개로 한다(f-daily-trend-prereg.md 구현 세부 2와 같다).
4. **점수(종목 자신의 수정 종가 행 순서 기준)**: 행 i가 d일 때,
   - 저변동 점수 σ = 행 i−59..i의 일수익률 60개(= 종가 i−60..i 필요, 수정주가 연속 행의 종가 비율 − 1)의 **표본 표준편차**(n−1). 행이 61개 미만이면 점수 없음.
   - 모멘텀 점수 M = 수정 종가(i−21) ÷ 수정 종가(i−252) − 1. 행이 253개 미만이면 점수 없음.
   - K200P(d) 구성 종목 중 σ, M이 모두 있는 종목만 순위를 매긴다. 저변동 순위 = σ 오름차순(1 = 가장 낮은 변동성), 모멘텀 순위 = M 내림차순(1 = 가장 높음), 동점은 코드 오름차순. 합산 점수 = 두 순위의 평균. **합산 순위** = 합산 점수 오름차순(동점은 σ 오름차순, 그다음 코드 오름차순)으로 1, 2, 3, …을 매긴 값.
   - 후보 = M > 0(엄격)인 종목. 후보 제외는 신규 편입에만 적용한다(해석: 보유 종목은 사용자 지정대로 합산 순위 규칙으로만 매도).
5. **일별 루프**(CAL 인덱스 c, 종가 판단 → 실행일 c + lag, 기본 lag = 1, 지연 변형 lag = 2):
   - (a) 평가: 보유 종목은 그날 행이 있으면 평가가격을 갱신한다.
   - (b) 실행: 오늘 실행일인 청산을 먼저 처리하고(그날 행이 없거나 거래량 0이면 다음 거래일로 미룬다), 이어 진입을 처리한다(그날 행이 없거나 거래량 0이면 그 주문은 취소).
   - (c) 판단(종가): 먼저 매도 판단, 이어 매수 판단.
6. **매도**: 판단일 d에 보유 종목의 합산 순위가 keepRank(B1 30, B2 20)보다 크면(순위 밖) 매도 주문. K200P(d)에서 빠졌거나 점수가 없어 순위가 없는 보유 종목도 순위 밖으로 본다(해석). 상장폐지는 폐지 청산 규칙. 그 외 청산 사유는 없다(손절 없음).
7. **매수**: 빈 슬롯 수 = slots(B1 10, B2 5) − (보유 종목 수, 매도 주문 중인 것 포함) − (이미 낸 매수 주문 수). 후보 중 보유·주문 중이 아닌 종목을 합산 순위 오름차순(1이 최우선)으로 빈 슬롯 수만큼 매수 주문을 낸다. 후보 순위가 상위 slots 안일 필요는 없다(사용자 지정: 후보 중 합산 순위가 가장 높고 보유 중이 아닌 종목). 후보가 모자라면 슬롯을 비워 현금으로 둔다. 쿨다운은 없다(해석: 사용자 지정에 없음).
   - 실행일의 처리: 계좌 평가액 V = 현금 + 보유 평가액(청산 처리 후, 같은 날 진입 전). 투입액 = min(frac × V, 현금)이고 0 이하이면 건너뛴다(frac: B1 0.10, B2 0.20). 매수 후 비중 조정은 없다(수익 종목은 커지도록 방치). 소수 주 허용(연속 비중 판)이고 정수 주 판은 시드 모의.
8. **보유 평가·지표**: 일별 수익률 = 종가 계좌 평가액 ÷ 전일 평가액 − 1(비용은 실행일에 반영). 기간 끝 열린 거래는 거래 통계에서 제외한다. MDD는 낙폭 크기 %다.

## 4. 게이트 (임의 완화 금지, 기존 정의 그대로 — docs/research/f-daily-trend-prereg.md 구현 세부 9, r-allcap-fundamentals-prereg.md 단계 2)

기준선 B&H = 069500 원주가(가격 수익만, 비용 없음). MDD 비교는 1e-9 허용.

- **A_B(방어형, A 대신)**: 전체 구간 CAGR ≥ B&H CAGR **이고** MDD ≤ B&H MDD − 10%p. (게이트 A: CAGR ≥ B&H CAGR + 2%p 이고 MDD ≤ B&H MDD — 참고로만 보고하고 통과 판정에 쓰지 않는다.)
- **B**: 학습·확인·보류 세 구간 중 2개 이상에서 각각 CAGR > B&H CAGR 이고 MDD ≤ B&H MDD.
- **C**: lag = 2(진입·청산 모두 하루 더 늦춤) 전 기간에서 기본 CAGR − 지연 CAGR ≤ 1%p 이고 지연 MDD − 기본 MDD ≤ 2%p.
- **D(이웃값)**: B1 이웃 = 변동성 창 40·90거래일, 순위 유지 한도 20·40(하나씩만 바꿈). 모든 이웃의 전 기간 CAGR이 B&H CAGR 이상이어야 O. B2 이웃(해석: B1과 같은 방식) = 변동성 창 40·90, 순위 유지 한도 10·30.
- **E**: 기본 실행(lag 1) 닫힌 거래 중 거래 기여 = (매도 대금 − 투입액) ÷ 진입 실행일 V가 큰 상위 3개 거래를 고른다. 각 거래를 같은 진입·청산 실행일 동안 069500 원주가 일수익률로 바꿔(비용 같음) 전 기간 CAGR을 다시 계산했을 때 B&H CAGR 이상이면 O.
- **F**: 1,000회, 시드 20261022 mulberry32. **무작위 진입일 대비**: 신호일마다 실제 매수 주문 수만큼, "후보(M > 0)이며 합산 순위가 keepRank 이내이고 보유·주문 중이 아닌 종목" 풀에서 무작위로 골라 같은 청산 규칙(순위 밖 매도)·같은 크기 규칙으로 다시 돌린다(해석: 선택 규칙의 기여를 분리하는 대조). 백분위 = 전략 전 기간 CAGR보다 작은 회수 ÷ 1,000 × 100이며 ≥ 95여야 O. 참고로 1 − 0.05/2 = 97.5 백분위 이상인지도 표시한다(통과 조건 아님).
- **G**: 전 기간 진입 100건 이상(완화 금지).
- **H**: 해당 없음 — 필터 전 대조군이 이 사전등록에 없다(R0·Q1처럼 대조군이 있는 후보에만 적용되는 게이트).
- **통과** = A_B·B·C·D·E·F·G가 모두 O.

## 6. 실행 불가 조건

- 평가 시작일부터 K200P 후보가 slots개 미만인 날이 대부분이어서(현금 100% 비율 90% 초과) 전략이 사실상 투자하지 않는 경우에도 실행은 한다(결과로 보고). 사전에 실행 불가로 정하는 조건은 없다. 게이트 G(진입 100건)는 결과에서 판정한다.
- 데이터 문제(가격 Parquet 캐시 미적중)는 실행하지 않고 보고한다(Parquet cache gate).

## 7. 결과 판정·경고 문구

- 후보별 게이트 O/X 표와 탈락 사유, 구간별 성적, 투자 비중 보고를 낸다. 통과해도 운영 적용·PR 생성은 하지 않고 보고만 한다.
- **경고(홀드아웃 오염)**: 보류 구간(2022~)은 이미 여러 번 본 데이터이고 학습·확인 구간도 앞선 연구들에서 반복해 본 구간이라 순수 검증이 아니다.
- **경고(우연 통과)**: 누적 시험 207번 중 실력이 없어도 5% 수준 기준 하나를 우연히 넘는 후보가 평균 207 × 0.05 ≈ 10.35개 나올 것으로 기대되고, 적어도 하나가 걸릴 확률은 1 − 0.95^207 ≈ 100%다(시험들이 독립이 아니므로 근사). A가 실행 불가로 번호를 소진하지 않으면 누적은 실제 소진한 수로 계산해 보고한다.
