실행 **전에** 커밋한다(커밋 해시는 보고서에 기록). 이후 수정하지 않는다. 판정·추천은 쓰지 않고 숫자와 표만 보고한다. 브랜치 `claude/ma-v3-portfolio-cap-run`, main 변경·병합 없음, DB 쓰기 없음(읽기만).

## 1. 공통 규칙 (사용자 지정)
| 항목 | 규칙 |
|---|---|
| 유니버스 U1 | 기존 PIT 규칙: 직전 거래일 시총 5천억 이상 + 직전 20거래일 평균 거래대금 5억 이상 |
| 유니버스 U2 (F6L 전용) | 월말 직전 거래일 시총 상위 100종목 (거래대금 5억 조건 동일) |
| 가격·비용 | 조정 가격(applied). 편도 수수료 0.015%, 세금 날짜별, 슬리피지 0.1% |

| 평가 기간 | 전체 2017-04-01~, 학습 2017-04-01~2021-12-31, 확인 2022-01-01~. 확인 구간은 후보당 1회만 보고 |
| 동점·난수 | 동점은 종목코드 오름차순. 시드·무작위 없음 |

## 2. 해석 세부 (코딩 전 고정)
1. **리밸런싱일:** 거래일 캘린더(전 종목 거래일 합집합)의 매월 마지막 거래일, 2017-04-28 이후. 마지막 달이 끝나지 않았으면 그 달은 리밸런싱하지 않음. 첫 리밸런싱(2017-04 말) 전까지는 전 전략이 현금(수익 0)이며, 기간 CAGR 분모는 2017-04-01부터다. 체결·비용·드리프트·사라진 종목 청산 규칙은 `research/baseline-decomposition-prereg.md`와 동일(비용은 목표 거래금액 기준 근사, 비중 V/20 기준, 총비용을 목표 비중에 비례 차감).
2. **U1 적격:** 리밸런싱일에 행이 있고, 직전 행의 시총(억) ≥ 5000, `computeTrailingAvgTradingValue`(당일 제외 직전 20거래일) ≥ 5억원. **U2 적격:** 리밸런싱일에 행이 있고 거래대금 조건 충족, 직전 행 시총 내림차순(동점 코드 오름차순) 상위 100.
3. **요인 정의** (재무는 `pickFundamentalsAsOf`가 고른 최신 공시 행 `fund`, 시총 M = 리밸런싱일 당일 행 `market_cap_eok` × 1e8):
   - **F1 낮은 PER:** `fund.net_income_parent > 0`인 종목, PER = M ÷ 순이익, 오름차순.
   - **F2 낮은 PBR:** `fund.equity_parent > 0`, PBR = M ÷ 자기자본, 오름차순.
   - **F3 높은 ROE:** 순이익 > 0 그리고 자기자본 > 0, ROE = 순이익 ÷ 자기자본, 내림차순.
   - **F4 순이익 성장률:** `fund`(최신 공시 회계연도 FY)와 같은 시점에 공시돼 있던 FY−1 행이 모두 있고, 두 순이익 모두 > 0, 두 행의 `fs_div`가 같을 때만 계산. 성장률 = 순이익(FY) ÷ 순이익(FY−1) − 1, 내림차순.
   - **F5 배당수익률:** 최근 365일(리밸런싱일 − 365일 초과 ~ 리밸런싱일) 지급 완료(`pay_date` ≤ 리밸런싱일) 배당의 주당배당금 합 ÷ 당일 **원본(조정 전) 종가**, 합계 > 0인 종목만, 내림차순. (조정 가격은 분할 소급 조정되어 당시 단위의 배당금과 단위가 어긋나므로 원본 종가를 쓴다. 365일 구간 안에 분할이 있으면 수익률이 과소 계산될 수 있다.)
   - **F6 합성:** F1~F4가 **모두** 계산 가능한 U1 종목만 후보. 각 요인에서 후보 안의 순위(1=가장 좋음, 동점은 코드 오름차순 순서대로 서수 순위)를 구해 4개 평균이 작은 순(동점 코드 오름차순).
   - **F7 PEG 순위:** 운영 `computePegLynchStates`와 같은 정의(최신 공시 순이익 > 0, PER = 종가 ÷ (순이익 ÷ 당일 상장주식수), EPS CAGR 5년 — `selectEpsCagrFiscalYears` + `computeEpsCagrFromResolvedShares`, PEG = PER ÷ 성장률%, `PEG_MAX_RATIO`=1.0 이하)을 충족하는 U1 종목 중 PEG 오름차순. 5년 EPS CAGR에는 FY(최신)−5 공시가 필요해 재무 테이블 시작(FY2015) 때문에 첫 후보는 2021-03 이후다(그 전 기간은 후보 0 = 현금).
   - **F6L:** F6과 같은 규칙을 U2에서 적용.
4. 재무 조회 대상은 2016-01-01 이후 한 번이라도 U1 적격이었던 종목이다(운영 배치와 같은 방식으로 종목당 `loadFundamentalsSeriesWithListedShares` 1회, 상장주식수는 시세에서 `pickListedSharesOnOrBefore`). 조회가 실패한 종목은 요인 계산에서 제외한다.

## 3. 기준선 (같은 코드, 2017-04-01 시작으로 새로 계산)
KOSPI(가격지수, 2017-04-01 이후 일별 수익률), 유니버스 동일가중 월리밸(`simulateUniverseMonthlyRebalance`, 시작 2017-04-01, 비용 반영), D1(U1 시총 상위 20 동일가중)·D2(상위 20 시총가중)·D4(U1 전체 시총가중) — `research/baseline-decomposition-prereg.md` 정의, 시작 2017-04-01(첫 리밸런싱 2017-04 말), 상한 없는 v3(진입일 ≥ 2017-04-01 거래만, 기존 규칙), peg_lynch(`runBacktest` 창 시작 2017-04-01, 운영 설정). 참고 점검(게이트 아님): 같은 코드로 2010-01-01 창의 v3(기대 6.36 / 53.31 / 2,335건)와 peg_lynch(기대 5.89 / 29.3 / 약 707건)를 함께 출력한다.

## 4. 지표 (전체/학습/확인)
CAGR, MDD, 연도별 수익률(2017~2026), 연환산 평균 회전율(편도 %), 평균 보유 종목 수, 평균 현금 비중(일평균), 거래 수(주문 건수). 데이터 가용성: 요인별 월별 계산 가능 종목 수(연도별 평균, F1~F5·F7은 U1, F6은 U1, F6L은 U2 기준)와 후보가 20개 미만이라 20종목을 못 채운 달 수.

## 5. 사전 통과 기준 (전략별 O/X 표로만)
| 코드 | O 조건 |
|---|---|
| C1 | 전체 CAGR ≥ 같은 기간 KOSPI와 D4 CAGR 중 큰 값 |
| C2 | 전체 MDD ≤ 같은 기간 KOSPI MDD |
| C3 | 학습·확인 각각 CAGR ≥ 같은 기간 D4 CAGR |

C1·C2·C3 모두 O여야 "통과". **통과가 여럿이면 학습 구간 CAGR이 큰 쪽을 후보로 한다.**
**정보가치 기준(백필 결정용, 별도 표):** I1 = 8개 중 C3를 만족하는 전략 수, I2 = 8개 중 C2를 만족하는 전략 수.
