## 구현 세부 (실행 전 고정)

1. **기본**: research/satellite-v1_1-prereg.md(472cc3d) 구현 세부와 같다. 코드는 scripts/research-satellite-v1_1.ts(8baf393)를 복사해 아래만 바꾼다. 시도 번호: v1.2a = 139, v1.2b = 140.
2. **제외 규칙(공통)**: 우선주(코드 끝자리 ≠ '0')·ETF·스팩(v1과 같음) + 부동산·인프라: dart_corp_codes.corp_name(앞뒤 공백 제거)이 "리츠"로 끝남, 또는 stock_industry_classification.induty_code가 "642"·"681"로 시작, 또는 코드 088980·415640·094800. 표의 **v1.1 행은 이 수정된 제외 규칙으로 v1.1 규칙을 다시 계산한 값**이다(472cc3d 실행의 v1.1 숫자는 이전 보고에 있다). PEW = 수정된 제외 후 유니버스 전부 동일가중.
3. **업종 그룹**: induty_code 앞 2자리, 없으면 "미분류"(한 그룹, 상한도 같이 적용).
4. **업종 상한 선정(v1.2a·v1.2b)**: v1.1과 같이 점수 순위를 매기고, (1) 직전 목표 목록에 있고 순위 ≤ 40인 유지 후보를 점수 순으로 보며 그 업종 수가 상한 미만이면 넣는다(상한에 걸린 유지 후보는 뺀다), (2) 남은 자리를 유지 후보가 아닌 종목으로 점수 순으로 채우되 업종 수가 상한에 닿은 업종은 건너뛴다. 20개를 못 채우면 채운 만큼만(1/n′ 동일가중).
5. **v1.2b 유니버스 U_b(d)**: 제외 규칙을 적용하기 전 ELIG(d)의 시총 상위 100(POOL과 같은 정렬) 중 제외 규칙에 걸리지 않는 종목. C1·VOL 둘 다 있는 종목만 후보, 상위 1/3 제외·점수 순위·버퍼·매수 지연 순위 모집단 모두 U_b(d) 기준. **PEW100** = POOL(d) 100종목(제외 규칙 미적용) 동일가중, 같은 분기 리밸런싱·비용.
6. **조합**: v1.2a·v1.2b 각각 v1.1과 같은 7개 비중·되돌림·비용·선택 규칙(학습 CAGR ≥ B&H − 0.5, MDD ≤ B&H + 1e-9, 학습 샤프 최대, 없으면 P80).
7. **R1**: 보유 15·30(유지 순위 = 보유 × 2), VOL 창 40·90, 업종 상한 3·5, 하나씩만 바꿈. 전 기간 CAGR·샤프·MDD.
8. **R2**: v1.1과 같은 방식, 비교 기준은 v1.2a = PEW, v1.2b = POOL.
9. **R3**: 매 분기 해당 유니버스(v1.2a = U(d), v1.2b = U_b(d), C1·VOL 유무 무관)를 무작위로 섞은 순서로 업종 상한 4를 지키며 20종목(못 채우면 채운 만큼) 동일가중. 유지 버퍼·매수 지연 없음. 1,000회씩, 시드 20261021 mulberry32(v1.2a와 v1.2b 각각 새 생성기), 회차 → 분기 순서로 Fisher–Yates 전체 섞기. 무작위 중앙값·95분위·최대, 위성 이상 회수, 백분위 = 위성보다 작은 회수 ÷ 1,000 × 100.
10. 참고 기준 O/X는 이번 요청 보고 항목에 없으므로 표시하지 않는다. 외부 요청 0, DB 쓰기 0, 1회 실행.
