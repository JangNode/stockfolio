## 3. ROE 정의 (결과를 보기 전에 고정, `lib/qualityRoe.ts`)
- **ROE = TTM 당기순이익 ÷ 자본총계(해당 보고서 기말)**. 당기순이익은 연결 포괄이 아니라 DART 주요계정 "당기순이익"(비지배 포함), 자본총계는 비지배 포함(지배주주지분이 없어 PBR과 같은 한계).
- **TTM**: 직전 보고서 F가 사업보고서(11011)면 F의 당기. 1분기(11013)면 직전 사업연도 사업보고서 당기 + F의 당기 − F의 전기(전년 동기). 반기(11012)·3분기(11014)면 직전 사업연도 사업보고서 당기 + F의 당기누적 − F의 전기누적. 즉 **사업보고서 값 + 올해 누적 − 전년 같은 기간 누적**.
- **계산 불가 → 제외(대체 금지)**: 보고서 없음, F 접수 후 400일 초과, 직전 사업연도 사업보고서(접수일 < 신호일 ∧ < F 접수일) 없음, 필요한 값 null이면 그 종목-월은 후보에서 빠진다. 최근 사업보고서 값으로 대체하지 않는다.
- **연결 우선, 없으면 별도**(사업연도·보고서 단위). **직전 보고서** = 접수일 < 신호일(접수일 다음 거래일부터 반영)인 보고서 중 기간이 가장 늦은 것(늦게 접수된 과거 기간 정정본이 최신으로 보이는 것을 막음). 정정본은 정정 접수일부터 사용(정정 전 원본 없음 — VB와 같은 한계).
- **자본총계 ≤ 0 또는 TTM ≤ 0이면 제외.**
