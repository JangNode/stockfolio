# 연구 A — 우선주 괴리 회귀 (A1 = 시도 204, A2 = 시도 205) 사전등록

작성 2026-10-26(사용자 지정). **이 문서는 시험 실행 전 사전등록이다. 시험 실행은 사용자 승인 후에만 한다.** 개별 주식(우선주)과 현금만 쓴다(ETF 매매 금지, 069500은 기준선 전용). 모든 구간 성적은 개발 데이터 내 성적이다. 보류 구간(2022~)은 이미 여러 번 본 데이터라 순수 검증(홀드아웃)이 아니다.

## 1. 목적

같은 회사의 보통주·우선주 쌍에서 우선주가 보통주 대비 평소(직전 250거래일)보다 유난히 싸진 날 우선주를 사서 괴리가 평균으로 되돌아올 때(z ≥ 0) 파는 평균회귀 규칙이 069500보다 수익이 높은지 본다. 이론적 되돌림에 기대는 전략이라 유동성이 낮은 우선주에서 체결 가능성과 표본 수가 핵심 위험이다 — 사전 점검(아래 0단계)으로 표본 상한을 먼저 확인했다.

## 2. 사용자 지정 규칙 (그대로 옮김)

- 정의: 보통주와 우선주 쌍(같은 회사). 괴리 s = ln(우선주 수정주가 / 보통주 수정주가). z = (s − 직전 250거래일 평균) / 직전 250거래일 표준편차. 우선주가 보통주 대비 평소보다 싸질수록 z가 낮아짐.
- A1(204): z ≤ −2.0이면 우선주 매수, z ≥ 0이면 매도. A2(205): z ≤ −1.5 매수, z ≥ 0 매도. 손절: 매수가 대비 −20% 또는 z ≤ −4(둘 중 먼저). 최대 보유 없음(되돌림을 기다림), 단 보통주 또는 우선주 상장폐지·거래정지 시 강제 청산.
- 대상 제한: 우선주 20일 평균 거래대금 2억 원 이상인 날만 진입 가능. 직전 250거래일 중 거래 없는 날이 10% 초과인 쌍은 제외. 동일 종목 재진입은 20거래일 금지.
- 게이트 D(이웃값): A1의 이웃 = 창 200/300거래일, 진입 z −1.75/−2.25. 전부 069500 CAGR 이상이어야 통과.
- 종목 수 상한 5개. 비용·슬리피지: 0.015%/편도 + 매도세, 슬리피지 우선주 0.2%(소형과 같음). 신호는 종가, 체결은 다음 거래일 종가. 수정주가, PIT 유니버스, 상장폐지 강제 청산은 기존과 동일.
- 시도 번호는 204부터 이어서(R4 번호 미소진): A1 = 204, A2 = 205. 누적 시험 207번(B 포함) 기준 우연 통과 기대 건수(207 × 0.05 ≈ 10.35) 경고를 보고에 포함한다.
- 구간: 학습 2010~2016 / 확인 2017~2021 / 보류 2022~. 기준선: 069500 원주가(가격 수익만). 게이트 A~H 정의는 기존 사전등록 문서 정의를 그대로 가져오되 임의 완화 금지. 게이트 G(진입 100건 이상)도 낮추지 않는다.
- 결과를 본 뒤 정의·기준·파라미터를 바꾸지 않는다(논리 결함만 고치고 사유를 기록). 재실행 금지. 연구 DB 쓰기 0(Storage Parquet만). 14:00~15:40 KST KRX·KIS 호출 금지. 키 값 출력 금지.
- 사전 점검(읽기 전용, 수익률 계산 금지): 연도별로 조건을 만족하는 우선주 쌍의 수, 평균 거래대금, 2010~ 보통주·우선주 시세가 모두 있는 쌍 수, 이론상 가능한 진입 기회의 상한을 보고한다. 상한이 100건 미만이면 그 후보는 "실행 불가"로 기록하고 번호를 소진하지 않는다(게이트 G 완화 금지).

## 4. 구현 정의 (실행 전 고정)

기준값은 lib/prefSpreadConfig.ts에 있다. **"해석"으로 표시한 항목은 사용자 지정 문구에 없어 정한 해석이며, 승인 시 함께 확인받는다.**

1. **입력·비용**: scripts/research-e-new-goal.ts(75c8b69), docs/research/f-daily-trend-prereg.md 구현 세부 1과 같은 입력·비용(Parquet 2010~, 적용된 조정 이벤트, 069500 raw·adj). 매수 = 종가 × (1 + 0.2%) × (1 + 0.015%), 매도 = 종가 × (1 − 0.2%) × (1 − 0.015% − 그날 거래세)(우선주 슬리피지 0.2%). 현금 이자 0%. 폐지 청산은 기존과 같다. 외부 요청 0, DB 쓰기 0, 1회 실행이다.
2. **평가 구간**: 평가 시작 판단일 2011-01-04(달력 순번 252)에 현금으로 시작, 수익률 집계는 다음 거래일부터. 구간 = 학습 평가 시작일~2016-12-31 / 확인 2017-01-01~2021-12-31 / 보류 2022-01-01~데이터 끝. 전 기간은 평가 시작일~데이터 끝이다.
3. **쌍**: 우선주 = 6자리 코드의 마지막 자리가 '0'이 아닌 종목, 보통주 = 앞 5자리 + '0'. 둘 다 Parquet(2010~)에 시세가 있어야 한다(해석: 코드 규칙으로만 쌍을 만들고 종목명으로 검증하지 않는다).
4. **괴리·z**: 날 t에 두 종목이 모두 체결(수정 종가 > 0, 거래량 > 0)된 날만 s_t = ln(우선주 수정 종가 / 보통주 수정 종가)가 있다. z_t = (s_t − μ) / σ, μ·σ = 직전 W거래일(당일 제외, 거래일 달력 기준)에 있는 s의 평균·**표본 표준편차**(n−1), W 기본 250(이웃 200·300). 창 안 s가 ⌈0.9W⌉개 미만이거나 σ = 0이면 z 없음(해석).
5. **진입 자격(판단일 d 종가)**: ① z_d 계산 가능, ② 우선주 20일 평균 거래대금(당일 제외 직전 20행) ≥ 2억 원, ③ 직전 250거래일 중 s가 없는 날(어느 한쪽이라도 체결 없음) 비율 ≤ 10%, ④ 현재 보유·주문 중이 아님, ⑤ 직전 청산 실행일 e에 대해 d − e ≥ 20(달력 순번 차이). 자격이 있고 z_d ≤ 진입 z(A1 −2.0, A2 −1.5)이면 후보.
6. **슬롯·크기**: 동시 최대 5종목(쌍당 1포지션, 우선주 매수만). 같은 날 후보가 빈 슬롯보다 많으면 z 낮은 순(동점 우선주 코드 오름차순)으로 채우고 남은 후보는 이월하지 않는다(해석). 신규 진입 투입액 = min(0.20 × V, 현금)(V = 청산 처리 후 계좌 평가액; 해석: 5슬롯 균등 20%), 이후 비중 조정 없음. 소수 주 허용(연속 비중 판), 정수 주 판은 시드 모의.
7. **체결·일별 루프**: f-daily-trend-prereg.md 구현 세부 5와 같다 — 종가 판단 → 실행일 c + lag(기본 1, 지연 변형 2), 실행일에 청산을 먼저, 이어 진입. 실행일에 우선주 행이 없거나 거래량 0이면 진입 주문은 취소, 청산 주문은 다음 거래일로 순연한다.
8. **청산(판단일 d 종가)**: 다음 중 먼저 오는 것. ① z_d ≥ 0, ② 손절: 우선주 수정 종가 ≤ 진입 실행일 수정 종가 × 0.80 또는 z_d ≤ −4, ③ 강제 청산: d에 보통주 또는 우선주의 행이 없는 날(거래정지; 해석) 또는 상장폐지(폐지 청산 규칙). 최대 보유 기간은 없다. 청산 실행일을 쿨다운 기준 e로 쓴다.
9. **보유 평가·지표**: 일별 수익률 = 종가 계좌 평가액 ÷ 전일 평가액 − 1(비용은 실행일에 반영). 기간 끝 열린 거래는 거래 통계에서 제외한다. MDD는 낙폭 크기 %다.

## 5. 게이트 (임의 완화 금지, 기존 정의 그대로 — f-daily-trend-prereg.md 구현 세부 9, r-allcap-fundamentals-prereg.md 단계 2)

기준선 B&H = 069500 원주가(가격 수익만, 비용 없음). MDD 비교는 1e-9 허용.

- **A**: 전 기간 CAGR ≥ B&H CAGR + 2%p 이고 MDD ≤ B&H MDD.
- **B**: 학습·확인·보류 세 구간 중 2개 이상에서 각각 CAGR > B&H CAGR 이고 MDD ≤ B&H MDD.
- **C**: lag = 2 전 기간에서 기본 CAGR − 지연 CAGR ≤ 1%p 이고 지연 MDD − 기본 MDD ≤ 2%p.
- **D(이웃값)**: A1 이웃 = 창 200·300(진입 z −2.0 유지), 진입 z −1.75·−2.25(창 250 유지) — 하나씩만 바꿈. 모든 이웃의 전 기간 CAGR이 B&H CAGR 이상이어야 O. A2 이웃(해석: A1과 같은 방식) = 창 200·300(진입 z −1.5 유지), 진입 z −1.25·−1.75(창 250 유지).
- **E**: 기본 실행의 닫힌 거래 중 거래 기여 = (매도 대금 − 투입액) ÷ 진입 실행일 V가 큰 상위 3개 거래를 같은 진입·청산 실행일 동안 069500 원주가 일수익률로 바꿔(비용 같음) 전 기간 CAGR을 다시 계산했을 때 B&H CAGR 이상이면 O.
- **F**: 1,000회, 시드 20261022 mulberry32. **무작위 진입일 대비**: 신호일마다 실제 진입 주문 수만큼, "자격 조건(5의 ①~⑤ 중 z ≤ 진입 z만 제외)을 충족하고 z_d < 0인 쌍" 풀에서 무작위로 골라 같은 청산·크기·슬롯 규칙으로 다시 돌린다(해석: z ≥ 0이면 즉시 청산이라 무의미하므로 z < 0으로 제한). 백분위 = 전략 전 기간 CAGR보다 작은 회수 ÷ 1,000 × 100이며 ≥ 95여야 O. 참고로 1 − 0.05/2 = 97.5 백분위 이상인지도 표시한다(통과 조건 아님).
- **G**: 전 기간 진입 100건 이상(완화 금지).
- **H**: 해당 없음 — 필터 전 대조군이 이 사전등록에 없다(R0·Q1처럼 대조군이 있는 후보에만 적용되는 게이트).

## 7. 실행 불가 조건

- 사전 점검의 이론상 진입 기회 상한(에피소드 수)이 100건 미만이면 그 후보는 실행 불가로 기록하고 번호를 소진하지 않는다(**점검 결과 A1 1,783, A2 2,736 → 해당 없음**).
- 실행 시 게이트 G(전 기간 진입 100건)에 못 미치면 탈락으로 판정한다(번호는 소진 — 실행한 시험).
- 가격 Parquet 캐시 미적중이면 실행하지 않고 보고한다.

## 8. 결과 판정·경고 문구

- 후보별 게이트 O/X 표와 탈락 사유, 구간별 성적을 낸다. 통과해도 운영 적용·PR 생성은 하지 않고 보고만 한다.
- **경고(홀드아웃 오염)**: 보류 구간(2022~)은 이미 여러 번 본 데이터이고 학습·확인 구간도 앞선 연구들에서 반복해 본 구간이라 순수 검증이 아니다.
- **경고(우연 통과)**: 누적 시험 207번 중 실력이 없어도 5% 수준 기준 하나를 우연히 넘는 후보가 평균 207 × 0.05 ≈ 10.35개 나올 것으로 기대되고, 적어도 하나가 걸릴 확률은 1 − 0.95^207 ≈ 100%다(시험들이 독립이 아니므로 근사). 실제 소진한 시험 수가 207보다 적으면 그 수로 계산해 보고한다.
- **경고(체결 가능성)**: 우선주는 거래대금이 작고 호가 간격이 커서 종가 체결 가정이 낙관적일 수 있다. 슬리피지 0.2%는 그 영향을 일부만 반영한다.
