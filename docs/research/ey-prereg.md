# 이익수익률 사전등록 (EY1 327 · EY1C 328)

연구 브랜치 `claude/ma-v3-portfolio-cap-run` 전용. main 병합·변경·운영 적용·PR·pg_cron 등록 없음. **기존 보유 데이터만 사용**(순이익 TTM, 시가총액, 가격). 연구 DB 쓰기 0, DART 신규 호출 0, 외부 호출 0, 키 값 출력 없음, 데이터 파일 artifact 없음. 사전 점검 전에 이 문서를 먼저 커밋하며, **이후 정의·값·변형·이웃값·재시험을 바꾸거나 추가하지 않는다**(구현의 논리 결함만 사유를 기록하고 고친다). 시험 전에 EY1·EY1C의 결과 숫자를 보지 않는다(사전 점검은 성과를 계산·출력하지 않는다). 구현은 `scripts/research-batch5.ts`(ALLOC_MODE `epre`·`etest`·`einfo`), 기준값은 `lib/eyConfig.ts`.

## 0. 선택 편향 고지 (문서 첫머리)
**이 가설은 VB1(311)·VB1C(313)의 가치 요인 결과와 ROE 시험(Q1·QV1·QV1C, 320~322)의 결과(ROE 상위가 자본이 극단적으로 작은 종목에 쏠림, 가치 함정 낙폭)를 본 뒤 만든 것이며 선택 편향이 있다.** 통과해도 **포워드 확인 대상일 뿐 확정이 아니다.** 시험 구간(2012~2026)은 이미 반복해서 본 오염된 구간이다. 누적 시험 326 → **328**, 우연 통과 기대 328 × 0.05 = **16.40건**(근사).

## 1. 정의 (사용자 지정)
- **유니버스**: 전 종목 PIT, **VB1과 같은 기준** = BS1 적격 종목(`B5_BS_P0`: 우선주·ETF·SPAC·리츠 제외, 신호일 행 있음 등 앞선 VB1·QV1과 같음).
- **이익수익률(EY)** = TTM 순이익 ÷ 시가총액. TTM 순이익은 **ROE 시험과 같은 정의**(`lib/qualityRoe.ts`, 변경 없음): 사업보고서면 그 해 순이익, 아니면 직전 사업연도 사업보고서 순이익 + 올해 누적 − 전년 같은 기간 누적, 연결 우선·없으면 별도, **접수일 < 신호일**(접수일 다음 거래일부터 반영), **접수 후 400일 초과 제외**, 계산 불가는 대체 없이 제외. **TTM 계산 불가·순이익(TTM) ≤ 0·자본총계 ≤ 0 종목은 제외**(자본 ≤ 0 제외는 ROE 정의의 자본 판정과 같다). 시가총액은 PBR 계산과 같은 신호일 시가총액(`mcapRow` × 1억원).
- **EY1 (327)**: 매월 말 종가 기준 이익수익률 **상위 30종목 동일 비중(1/30)**. 기존 보유는 **순위 60위 이내면 유지**, 빈자리만 순위 순으로 채움. 신호일 다음 거래일 종가 체결, 전량 투자(후보가 30개 미만이면 있는 만큼). 같으면 종목코드 순. 이웃값(D): 종목 수 20(유지 순위 40)·40(유지 순위 80), 종목 수 30 고정에서 유지 순위 45·90.
- **EY1C (328)**: DS6 코어 40%(같은 코드·같은 캐시) + EY1 60%, **월 리밸런스(HM1C와 같은 방식: 월말 종가에 목표 금액 계산 → 다음 거래일 종가에 이동, 이동 비용 0.25%)**. 앞선 VB1C·RM1C·QV1C의 일별 재조정과 다르다.
- **공통 비용 규칙**: 앞선 VB·VL·Q·HM·TC 시험과 같다 — 수수료 0.015%/편도, 매도세 시기별, 슬리피지 신호일 K200P 구성원 0.1%·그 밖 0.2%, 현금 이자 0, 수정주가, 벤치마크 069500 원주가, 소멸 종목 처리 `vbVanishLoss`(마지막 종가 청산하되 직전 20거래일 중 거래정지 5일 이상이거나 마지막 종가 1,000원 미만이면 전액 손실). **데이터 표준**: K200P 17건 보정(`correct=k200p17`) + 의심 종목-일 0% 처리 794건(`zero=1`), 처리 없음은 정보용.

## 2. 평가 (사용자 지정)
- **시작일 2012-04-30**(ROE 시험과 같음, 첫 체결 2012-05-02). **연속 + 2구간**(2012-05~2021-12 / 2022-01~2026-10-26). **게이트 B는 두 구간 모두 069500을 이길 때만 통과**(`V_FORCE_C2`, 시작일이 2016-05-31 이전이어도 두 구간 규칙).
- 기준 069500 원주가. DS6·DS13L·VB1(같은 시작일로 다시 계산)·QV1과 나란히 비교. 관문 A~H는 기존 정의·구현 그대로(기계 판정, F는 백분위 95 이상, 참고선 1 − 0.05 ÷ 2 = 97.50). 탈락이면 부족한 폭 표기. 이 두 가지만 시험하고 추가 변형·재시험 금지(누적 328에서 종료).

## 4. 사전 점검(`epre`, 성과 미계산)
DS6 재현(연속 11.70 / 39.15, 불일치면 중단) · 보정·의심 종목-일 0% 처리 적용 확인 · TTM 순이익 독립 재계산(ROE 시험과 같은 보고서 자료에서 따로 짠 직접 계산과 비교, 접수일 < 신호일·400일 규칙 포함) · 이익수익률 정렬 독립 재계산(전 종목 직접 훑기, 월말 20개) · 보유 ≤ 30 · 첫 체결 = 신호일 다음 거래일 · 후보 수 · VB1 재현(10.07 / 64.17, 시작 2011-05-31) · TTM 계산 가능 비율 60% 이상 유지(시작일 이후 매 월말) · EY1C 날짜 축·월 재조정 경로(combineN 매일 ↔ combine2 일치, 월 신호일 = EY1 신호일) · 소멸 관례. 하나라도 어긋나면 시험하지 않고 보고한다.

## 5. 중복 확인
`docs/research/guru-composite-prereg.md`(연구 C)의 V 항목이 이익수익률(TTM 순이익 ÷ 시총)을 종합 점수의 한 요소로 쓴다. 이번 EY1은 **이익수익률 단독 상위 30 동일 비중 + 순위 유지 완충**이며 종합 점수·다른 요인과 합치지 않는 별개 정의다. ROE 시험(QV1)은 PBR 하위와 ROE 상위의 백분위 합이라 이익수익률(= ROE ÷ PBR에 해당)과 정의가 다르다(관련 있음: EY = ROE ÷ PBR이므로 QV1과 높은 상관이 예상된다).

## 6. 한계(미리 공개)
자본총계(비지배지분 포함)와 연결 포괄이 아닌 DART 주요계정 순이익(비지배 포함)을 쓰는 한계는 ROE 시험과 같다, 정정 전 원본 없음(정정본은 정정 접수일부터), 일회성 이익(자산 매각 등)으로 이익수익률이 높아진 종목이 섞일 수 있다, 금융주 비중이 클 수 있다(VB1 23.66%), 선택 편향.
