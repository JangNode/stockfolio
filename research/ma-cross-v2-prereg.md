# [임시 연구 — 병합 금지] ma_cross v2(50/200) 강화 연구 사전 등록

작성: 2026-10-12 (KST). 이 파일은 어떤 결과도 보기 전에 커밋한다(커밋 해시를 보고서에 기록).
이후 이 파일의 "사전 등록 A" 구역은 수정하지 않는다. 후보는 진단(2단계) 직후·후보 실행 전에
"사전 등록 B" 구역으로 **추가만** 한다(별도 커밋). 모든 결과는 in-sample이다.

## 1. 기준선 R0 (사용자 지정)

5천억 PIT 시총 + 20일 평균 거래대금 5억, 비용 반영(수수료 0.015%/편, 슬리피지 0.1%/편, 거래세 일정표),
점수 게이트 없음, 2010-01-01~, ma_cross v2 50/200(골든크로스 진입 / 데드크로스 청산, 종목당 단일 포지션).

| 항목 | R0 (사용자 지정) |
|---|---|
| CAGR | 3.5% |
| MDD | 55.8% |
| 승률 | 30.4% |
| 손익비 | 4.17 |
| 거래 | 3,949건 |

연구용 하네스가 R0를 재현한 값(구간별 포함)은 보고서에 병기한다. 구간별(2010~2018, 2019~) 기준선과
슬리피지 0.3% 기준선은 같은 하네스의 R0 재현값을 쓴다(사용자 지정값에는 구간별 값이 없으므로).

## 2. 구간 정의

- 학습: 2010-01-01 ~ 2018-12-31. 확인: 2019-01-01 ~ 실행일. 전체: 2010-01-01 ~ 실행일.
- 구간은 **하나의 연속 실행**을 자른 것이다(포지션을 구간 경계에서 다시 시작하지 않는다).
  구간 CAGR·MDD는 해당 구간의 일별 수익률 시계열만으로 계산하고, 승률·손익비·거래 수는 진입일이
  구간에 속한 거래로 센다. CAGR 분모는 구간 시작일(위 날짜)부터 구간 종료일까지다(현금 기간 포함,
  기존 배치와 동일 관례).
- 선택(후보 순위·임계값)은 학습 구간 수치로만 한다. 확인 구간은 최종 후보 1개에 대해 1회만 평가한다.

## 3. 합격 기준 (모두 충족)

전체 구간(2010~) 기준, 사용자 지정:
1. CAGR ≥ R0 + 1.0%p  (= 4.5% 이상)
2. MDD ≤ R0 − 3%p  (= 52.8% 이하)
3. 승률 ≥ 33% (목표 35%)
4. 손익비 ≥ 3.9
5. 거래 ≥ 1,500건
6. 슬리피지 0.3%(편도)에서도 R0 이상 — 해석: **같은 슬리피지 0.3% 조건의 R0 재현 CAGR 이상**
   (참고로 R0@0.1%(3.5%)와의 비교도 병기하되 기준으로 쓰지 않는다)
7. 확인 구간(2019~)에서 CAGR ≥ R0(2019~) 이고 MDD ≤ R0(2019~)

### 학습 구간 선별 기준 (최종 후보 1개를 고르는 데만 사용)

후보는 학습 구간(2010~2018)에서 아래를 모두 충족해야 최종 후보 자격이 있다.
- CAGR_학습 ≥ R0_학습 + 1.0%p, MDD_학습 ≤ R0_학습 − 3%p, 승률_학습 ≥ 33%, 손익비_학습 ≥ 3.9
- 거래_학습 ≥ 1,500 × (R0의 진입일 ≤2018 거래 수 ÷ R0 전체 거래 수)
- 슬리피지 0.3%에서 CAGR_학습 ≥ R0_학습(0.3%)
자격 후보가 여럿이면 학습 구간 Calmar(CAGR ÷ MDD)가 가장 높은 1개, 동률이면 규칙이 단순한(조건 수가 적은) 쪽.
자격 후보가 없으면 "합격 없음"으로 보고하고 확인 구간은 평가하지 않는다(참고용 표시는 하되 판정에 쓰지 않음).

## 4. 후보 규칙 (사전 등록 A에서 고정되는 것)

- 진입 필터 후보: 진단(2단계)에서 도출, 최대 3개. 필터 형태는 "학습 구간 3분위 경계로 계산한 최저 승률
  3분위(구간)에 속한 진입을 제외"한다. 경계값은 학습 구간 R0 거래의 피처 분포에서만 계산해 고정한다.
  - 필터 후보가 되려면 피처가 "일관"해야 한다. 일관 = 학습·확인 두 구간 모두에서 (3분위 최상−최하) 승률 격차와
    평균수익률 격차의 부호가 같고 그 크기 방향이 동일하며, 두 구간 모두 승률 격차 절댓값 ≥ 3%p.
  - 일관한 피처가 4개 이상이면 학습 구간 승률 격차 절댓값이 큰 순서로 3개.
- 고정 손절 2개: 진입가 대비 종가 기준 −15%, −25%. 종가가 진입가×(1−x) 이하가 된 첫 날 종가로 청산.
  청산 후에는 다음 골든크로스 때까지 재진입하지 않는다(기존 데드크로스 청산 규칙은 그대로 병행).
- 조합 1회: 학습 구간 Calmar가 R0_학습보다 높은 단독 필터 중 최고 1개 + 같은 기준의 손절 중 최고 1개를 동시에 적용.
  해당하는 필터나 손절이 없으면 조합은 실행하지 않는다.
- ADX≥20: 재평가 대상으로 표에만 포함(위 시도 횟수에 세지 않음).
- 이미 탈락한 시도(트레일링 스톱, 200일선 이탈 청산, 거래량 확인, 동시보유 상한)는 반복하지 않는다.
- "골든크로스 후 5·10일 유지 여부"는 진입일 이후 정보라 **진입 필터로 쓸 수 없다**. 진단에서는 "5·10거래일 뒤에도
  골든 상태인 경우에만 그날 종가로 지연 진입"하는 규칙으로만 계산해 별도 표시하고(진입가가 달라짐),
  후보로 선택되면 지연 진입 규칙(진입일 = 골든크로스+N거래일, 그날 종가까지의 정보만 사용)으로 실행한다.

## 5. 시도 횟수와 확인 구간 오염 (보고서에 그대로 표기)

- 이 데이터로 이미 10번 시도했다(사용자 집계): 전용 실험 스크립트 기준 R0 + 9개 변형 =
  ADX≥20 1, 골든크로스일 거래량 1, 트레일링 스톱 3(−20/−25/−30%), 200일선 이탈 청산 2(3·5일 연속),
  동시보유 상한 2(20·30종목) 및 기타 이전 탐색. 이 5종(ADX, 거래량, 트레일링, 200일선 이탈, 동시보유 상한)은
  2019~ 구간 결과를 이미 본 것이라 **2019~ 확인 구간은 깨끗하지 않다.**
- 이번 연구에서 새로 세는 시도: 진입 필터 ≤3 + 손절 2 + 조합 ≤1 = 최대 6회. 누적 최대 16회.
- 사용자 지시에 따라 후보 피처를 고를 때 학습·확인 두 구간의 일관성을 함께 보므로 확인 구간이 피처 선택에도
  부분적으로 쓰인다(지시 간 충돌: "선택은 학습에서만" vs "두 구간 모두 일관된 피처"). 임계값과 순위는 학습 구간만 쓰고,
  확인 구간은 일관성 확인(부호·최소 격차)에만 쓴다. 이 점 때문에 2019~ 평가는 홀드아웃이 아니다.

## 6. 금지/제약

- 사전 등록 후 기준·임계값 변경 금지. 확인 구간 결과를 보고 규칙을 바꾸지 않는다.
- 임시 브랜치(`claude/ma-v2-research`)에서 읽기 전용 실행. DB 쓰기·병합·운영 코드 변경 없음
  (슬리피지 민감도용으로 `lib/transactionCostConfig.ts`에 환경변수 오버라이드를 임시 브랜치에서만 추가).
- 진입일 종가까지의 정보만 사용(미래 누수 금지). 합격이 없으면 없다고 보고한다.
- 규칙 교체가 필요한 경우의 후속 작업(구 규칙 행 처리, 규칙 버전 표식)은 목록으로만 정리하고 구현하지 않는다.
