# [임시 연구 — 병합 금지] 전략 조합 + 위험조정 점검 사전 등록 (새 신호 없음, 판정 없음)

실행 **전에** 커밋한다(커밋 해시는 보고서에 기록). 이후 수정하지 않는다. 판정·추천은 쓰지 않고 숫자와 표만 보고한다. 브랜치 `claude/ma-v3-portfolio-cap-run`, main 변경·병합 없음, DB 쓰기 없음(읽기만). **누적 시도: 기존 62 + 6 = 68회.**

## 1. 구성요소 (이미 비용 반영된 일별 수익률 시계열 재사용)
평가 기간 2017-04-01~, 학습 2017-04-01~2021-12-31, 확인 2022-01-01~. 구성요소 8개: KOSPI(가격지수), D4(U1 시총가중), D2(U1 시총 상위 20 시총가중), v3(상한 없는 v3, 2017-04-01 이후 진입분), peg_lynch(창 시작 2017-04-01), F5(배당수익률 순위), F1(낮은 PER 순위), F4(순이익 성장률 순위). 정의는 `research/factor-strategies-prereg.md`·`research/baseline-decomposition-prereg.md`와 같고, 이번 실행에서 **같은 코드(`scripts/research-factor-strategies.ts`, 반환값만 추가)로 다시 계산**한다(재무 테이블·지수 읽기 포함). 각 구성요소는 자체 거래비용이 이미 반영돼 있다.

## 2. 조합 (6개, 이 외는 시험하지 않는다)
| ID | 구성 (가중치 %) |
|---|---|
| B1 | D4 70 + peg_lynch 30 |
| B2 | D4 50 + peg_lynch 50 |
| B3 | D2 70 + peg_lynch 30 |
| B4 | D4 50 + v3 25 + peg_lynch 25 |
| B5 | v3 33.3 + peg_lynch 33.3 + F5 33.3 (각 1/3) |
| B6 | D4 60 + F5 20 + peg_lynch 20 |

- 조합 계산: 2017-04-01에 가중치대로 배분(자본 1)하고, 이후 구성요소별 일별 수익률로 슬리브 평가액을 굴린다. 매월 마지막 거래일(마지막 달이 끝나지 않았으면 제외) 종가에서 가중치로 재배분한다. **조합 리밸런싱 비용은 반영하지 않는다**(구성요소 자체 비용만 반영) — 따라서 조합 수치는 조합 리밸런싱 비용만큼 낙관적이다.
- 일별 수익률은 CAL(전 종목 거래일 합집합) 날짜 기준, KOSPI 등 해당 날짜에 값이 없는 구성요소는 그날 0으로 둔다.

## 3. 지표 (전체 / 학습 / 확인)
- CAGR(기존 `computeCagrPct`), MDD(기존 `computeCumulativeAndMdd`), CAGR÷MDD, 연변동성 = 일별 수익률 표준편차(표본) × √252, 샤프(무위험 0) = (일별 평균 × 252) ÷ (일별 표준편차 × √252), 최악 12개월 수익률 = 연속 12개 달력월 복리 수익률의 최소값(완결 달력월 2017-04~2026-09만 사용, 구간 내 12개월 미만이면 "-"), 연도별 수익률(2017~2026).
- 구성요소 간 월 수익률 상관 행렬: 완결 달력월 2017-04~2026-09의 월 복리 수익률 피어슨 상관(8×8).
- peg_lynch: 구간별 평균 동시 보유 종목 수(2021-03~2021-12, 2022~2026 연도별, 학습·확인·전체) 및 2021년 수익 기여 종목 상위 5개 — 기여 = 2021년 거래일마다 (그 종목 일별 수익률 ÷ 그날 보유 종목 수)의 합(포트폴리오 기여 %p, 일별 수익률은 단순 합), 표에는 코드, 2021년 보유 거래일 수, 그 종목의 2021년 보유 구간 복리 수익률(%)을 함께 적는다.

## 4. 사전 통과 기준 (O/X 표로만)
| 코드 | O 조건 |
|---|---|
| C1 | 전체 CAGR ≥ D4 전체 CAGR − 1.5%p |
| C2 | 전체 MDD ≤ 35% |
| C3 | 학습·확인 각각 CAGR÷MDD ≥ 같은 구간 KOSPI의 CAGR÷MDD |

세 개 모두 O면 "통과". **통과가 여럿이면 전체 CAGR÷MDD가 큰 쪽을 후보로 한다.**

## 5. 실행·중단 규칙
워크플로 1회만, 재실행 금지. 17개 Parquet 연도 파일이 전부 캐시에 없으면 실행 전에 보고. `[parquet-cache]` 줄과 Supabase 다운로드 MB, 재무 테이블 읽은 행 수를 그대로 보고.

## 6. 한계 (미리 공개)
in-sample 단일 경로, 평가 기간 약 9.5년, 조합 리밸런싱 비용 미반영(낙관적), 구성요소 중 D4·D2·F5 등은 첫 리밸런싱(2017-04-28)까지 현금이고 KOSPI는 2017-04-03부터 지수 수익률이 반영됨, peg_lynch는 2021-03 전에 신호가 없어 해당 슬리브가 현금, 월 수익률 표본이 약 114개라 상관·최악 12개월 추정 오차가 큼, 판정·추천 없음.
