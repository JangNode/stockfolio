개별 주식과 현금만 쓴다(ETF 매수 금지, 069500은 비교·신호 계산에만). 모든 구간 성적은 개발 데이터 내 성적이다. 보류 구간(2022~)은 이미 여러 번 본 데이터라 순수 검증이 아니다.

## 사용자 지정 규칙 (그대로 옮김)

## 0단계 사전 확인 결과 (실행 전)

- MACD·다이버전스·주봉 임펄스를 쓴 기존 시험은 research/·docs/research/에 **없다**(전수 검색: macd, 다이버전스, divergence, 임펄스, impulse, 엘더).
- reversal_breakout(lib/reversalBreakout.ts, lib/reversalBreakoutConfig.ts)은 운영 스크리닝 규칙이다. 신호는 "역배열 이력(20·60·112·244·448 이평 정렬 비율) → 최근 20일 내 매집봉(거래량 3배·양봉) → 5일 내 MA20 돌파"로, 거래량·시가를 쓰고 MACD·히스토그램·주봉을 쓰지 않는다. 같은 시험이 아니다.
- H1은 F 연구의 G4(b4378c4 사전등록, run 39728013417)에 임펄스 필터만 더한 것이다. G4 값(전 기간 CAGR 7.87 / MDD 40.51, 학습 4.96 / 21.35, 확인 9.17 / 40.51, 보류 10.58 / 26.64)은 이미 있으므로 재계수하지 않는다. 이번 실행에서 같은 엔진으로 G4를 다시 계산해 위 값과 일치하는지 **재현 확인**하고, H1 표 옆에 나란히 적는다(이 계산은 시험 횟수에 넣지 않는다).
- 따라서 H1~H4 4개 모두 새로 실행하고 계수한다. 시험 번호는 H1 = 162, H2 = 163, H3 = 164, H4 = 165(누적 161 + 4 = 165)다.

## 사용자 문안에서 해석을 정한 곳 (결과를 보기 전에 고정)

1. **H1 이웃값의 트레일링**: 원문 "트레일링 −20·−30%"는 G4의 기본값(−30%)과 겹친다. F 사전등록에서 정한 대로 "G4 이웃값 규칙"을 그대로 쓰므로 트레일링 이웃값은 **−25%·−35%**다(기본값 ±5%p).
2. **"직전 완결 주봉"**: 판단일 d가 속한 주(월요일 시작)보다 앞선 주의 주봉만 쓴다. 금요일처럼 d가 그 주의 마지막 거래일이어도 그 주 주봉은 쓰지 않는다(보수적 해석, 최대 1주 지연).
3. **임펄스 계산 불가**: 주봉이 36개 미만이라 임펄스를 계산할 수 없으면 "빨강 아님"을 확인할 수 없으므로 진입하지 않는다.
4. **A·C 간격**: 간격 = C 런의 첫 행 인덱스 − A 런의 마지막 행 인덱스(종목 자신의 행 수, 거래일). R1에서 40·80.
5. **다이버전스는 런당 한 번만 평가**: C 런에서 히스토그램이 처음 전일보다 오른 날 하루만 조건을 평가한다. 그날 조건을 못 채우면 그 런에서는 신호가 없다(이후 다시 오르는 날은 평가하지 않는다). 그날까지의 C 런 데이터(종가 최저값·히스토그램 최저값)만 쓴다.
6. **일봉 EMA13**: 정의는 하되 H1~H4 어디에도 쓰이지 않는다(일봉 EMA26만 목표 채널에 쓴다).
7. **R3 무작위 진입일(H1~H4 공통)**: 후보의 모든 조건에서 "신호 사건"만 무작위로 대체한다. 아래 구현 세부 8항.
8. **H2~H4 "중 먼저 오는 것"의 동시 발생**: 같은 판단일에 (a)(b)(c)가 겹치면 사유 표기는 손절 > 목표 > 시간 순이다(체결은 같다).

## 구현 세부 (실행 전 고정)

1. **입력·비용**: scripts/research-f-daily-trend.ts(94afefb)와 같은 입력·엔진·비용을 쓴다. Parquet 2010~, 적용된 조정 이벤트, 월말 시장 목록, dart 이름, 업종, 069500 raw·adj, 하루짜리 튐 정제를 포함한다.
   - 주식 매수 = 종가 × (1 + 0.1%) × (1 + 0.015%), 매도 = 종가 × (1 − 0.1%) × (1 − 0.015% − 그날 거래세). 폐지 청산도 F와 같다.
   - K200P(d), 일별 업종 모멘텀 순위(상위 3업종), 50/200 골든크로스 신호, 슬롯·진입 20%·쿨다운 20거래일·판단일 종가 → 실행일 종가(기본 lag 1, 지연 lag 2)도 F와 같다.
   - 구간: 학습 2010-07-01~2016-12-31, 확인 2017-01-01~2021-12-31, 보류 2022-01-01~데이터 끝, 전 기간 2010-07-01~데이터 끝. 외부 요청 0, DB 쓰기 0, 1회 실행.
2. **일봉 지표**(종목 자신의 수정 종가 행, 모든 행): EMA_N(i) = α·종가(i) + (1 − α)·EMA_N(i−1), α = 2/(N+1), 종목의 첫 행 종가로 시작한다. MACD = EMA12 − EMA26, 시그널 = MACD의 EMA9(첫 MACD로 시작), 히스토그램 = MACD − 시그널. **행 인덱스 60 미만은 값을 쓰지 않는다**(초기값 영향 제거, 지표 미정의).
3. **주봉 지표**(종목별):
   - 주(월요일 시작)마다 그 주의 마지막 행 종가가 주봉 종가다. 그 주에 행이 없으면 그 주 주봉도 없다.
   - 주봉 종가 열에 위 2항과 같은 EMA13, MACD(12,26,9) 히스토그램을 쓴다. 주봉 인덱스(0부터) 35 미만은 임펄스가 없다.
   - 임펄스(주 w) = EMA13(w) < EMA13(w−1)이고 히스토그램(w) < 히스토그램(w−1)이면 빨강, 둘 다 >이면 초록, 그 외(같은 경우 포함)는 파랑이다.
   - 일봉 행 i의 "직전 완결 주 임펄스" = 그 종목 주봉 중 주 시작일이 행 i가 속한 주 시작일보다 앞서는 마지막 주의 임펄스다. 없으면 계산 불가다. "빨강 아님" = 파랑 또는 초록이다.
4. **음수 런·다이버전스**(종목별, 행 인덱스 60 이상에서만):
   - 히스토그램 < 0인 연속 행이 음수 런이다. 히스토그램 ≥ 0인 행에서 런이 끝난다. 히스토그램 > 0인 행이 "양수 런" 행이다.
   - 런 C의 행 i에서 (i가 C의 첫 행이 아니고, 히스토그램(i) > 히스토그램(i−1), 그 런에서 처음)이면 신호 후보다.
   - 조건은 모두 같은 날까지의 C 런 데이터로 본다. A는 C 바로 앞 음수 런이고 이미 끝나 있다. (1) C의 최저 종가(행 i까지) < A의 최저 종가. (2) C의 최저 히스토그램(행 i까지) > A의 최저 히스토그램. (3) A의 마지막 행 이후 C의 첫 행 이전에 히스토그램 > 0인 행이 하나 이상 있다. (4) C의 첫 행 인덱스 − A의 마지막 행 인덱스 ≤ 간격(기본 60).
   - 신호일 = 행 i의 날짜다. C 런 종가 최저값 Cmin = C 런의 행 i까지 최저 종가(수정 종가)다.
5. **후보 정의**(판단일 d, 종목은 K200P(d), 시총 내림차순·동점 코드 오름차순):
   - H1: d가 50/200 골든크로스일 ∩ d의 상위 3업종 소속 ∩ 임펄스(3항) 빨강 아님. 청산은 G4 그대로(손절 max(진입가×0.90, 진입 후 최고 종가×0.70) 이하 또는 데드크로스).
   - H2: d가 다이버전스 신호일 ∩ 임펄스 빨강 아님.
   - H3: H2 ∩ d의 상위 3업종 소속. H4: H3 ∩ 종목이 d에 50일선 > 200일선(`above`)인 상태.
   - H2~H4 청산: 판단일 d의 종가 P(수정 종가)에 대해 (a) P < Cmin(손절, 신호 때 정한 Cmin 고정, 같으면 손절 아님), (b) P ≥ 일봉 EMA26(d) × (1 + 목표 채널), 목표 채널 기본 0.06, (c) d − (진입 실행일) ≥ 60(CAL 인덱스), 시간 기본 60. 하나라도 맞으면 d + lag 종가에 전량 매도한다. 데드크로스·트레일링은 H2~H4에 없다. 폐지 청산은 F와 같다.
6. **판정** (MDD는 낙폭 크기 %): A·B·C·E는 F 사전등록(b4378c4) 9항과 정의가 같다. 비교 기준은 069500 원주가(B&H 가격)다.
   - A: 전 기간 CAGR ≥ B&H 가격 + 2이고 MDD ≤ B&H 가격 MDD(1e-9 허용).
   - B: 학습·확인·보류 중 CAGR > B&H 가격이고 MDD ≤ B&H 가격 MDD(1e-9 허용)인 구간이 2개 이상.
   - C: 지연(lag 2)의 전 기간에서 기본 CAGR − 지연 CAGR ≤ 1이고 지연 MDD − 기본 MDD ≤ 2.
   - D(R1): 이웃값마다 전 기간 CAGR ≥ B&H 가격 전 기간 CAGR이어야 하고 모두 O여야 한다. 하나씩만 바꾼다.
     - H1: 이동평균 (40,150)·(60,250), 상위 업종 2·4, 동시 보유 3·7, 손절 0.07·0.13, 트레일링 0.25·0.35(임펄스 필터는 항상 적용).
     - H2~H4: 목표 채널 0.05·0.07, 시간 청산 40·80, 동시 보유 3·7, 간격 40·80.
   - E(R2): 기본 실행(lag 1)의 닫힌 거래 중 (매도 대금 − 투입액) ÷ 진입 실행일 계좌 평가액이 큰 상위 3개 거래를 같은 진입·청산 실행일 동안 069500 원주가(B&H 가격) 일수익률로 평가하도록 바꾸고 전체를 다시 계산한 전 기간 CAGR ≥ B&H 가격 전 기간 CAGR이어야 O다.

7. **임펄스 필터의 효과(추가 보고)**: 임펄스를 제외한 후보 조건을 모두 충족하는 (종목, 판단일) 신호를 "걸러낸 신호"(임펄스가 빨강 또는 계산 불가)와 "통과 신호"(빨강 아님)로 나눠, 슬롯·쿨다운 없이 신호마다 따로 가상 거래를 만든다.
   - 진입 = 판단일 + 1 거래일(CAL) 종가(그날 행이 없으면 가상 거래 없음). 청산 규칙은 그 후보의 청산 규칙(H1은 G4, H2~H4는 5항)이고 체결은 판단일 + 1 거래일 종가다. 순수익률 = (청산 수정 종가 ÷ 진입 수정 종가) ÷ 매수 배수 × (1 − 매도 비용률) − 1이다. 데이터 끝에 열린 거래는 제외한다.
   - 보고: 구간(판단일 기준)별 걸러낸 신호 수, 가상 거래 수, 평균·중앙값 순수익률 %, 승률 %, 통과 신호도 같은 열로 적는다. 걸러낸 신호의 평균 수익률이 통과 신호보다 낮으면 필터가 도움이 된 것으로 읽는다(판정 문장은 쓰지 않고 숫자만).
